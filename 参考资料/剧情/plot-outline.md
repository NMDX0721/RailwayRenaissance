## 一、故事定位

> 一句话：**在一个沙能吞噬铁路的世界里，一个25岁研究生用一条23公里的废弃支线，向全球证明铁路不会死。**

核心张力：**被遗忘的铁路 vs 无处不在的沙能**
叙事本质：**叙事战争**——铁龙计划把"吞并铁路"包装成"拯救铁路"，玩家每一次行动都在拆穿这套叙事。

## 三、核心角色弧线

### 3.1 林彪悍（主角）

**弧线：被动接受命运 → 主动承担使命 → 证明铁路不死**

| 阶段 | 心态 | 关键事件 |
|------|------|---------|
| 序章前 | 在平壤安心做研究，不想回雾峰村 | 老陈来电"线路快撑不住了" |
| 出发 | 不确定自己能否胜任 | 导师给0721号+岁月 |
| 旅途 | 逐渐理解爷爷的遗产 | 边境检查员讲述林悍往事 |
| 到达 | 情感触动，但仍不确定 | 幼年回忆+老陈"你爷爷守了三十七年" |
| 首修/首班 | 第一次证明自己 | 亲手修好喷油嘴/首班车发出 |
| 经营期 | 在实践中成长 | 应对沙能竞争、政治压力 |
| 终局 | 完成使命，选择铁路的未来 | "有些东西会停，有些东西不会" |

### 3.2 岁月（AI伙伴）

**弧线：沉睡23年的原型AI → 有温度的陪伴者 → 揭示身世之谜**

| 阶段 | 状态 | 关键台词 |
|------|------|---------|
| 刚重启 | 精确、冷幽默、偶尔少女活泼 | "根据当前数据统计..." |
| 旅途 | 开始展现好奇心 | "林彪悍——醒醒！快到了！" |
| 到达后 | 成为情感支撑 | "好。我不走。" |
| 经营期 | 好感度系统影响交互深度 | 31-60透露过去，61-80讲爷爷故事 |
| 终局 | 引刘禹锡诗，哲学升华 | "二十三年弃置身...怀旧空吟闻笛赋" |
| 支线 | 调查自己身世（待实现） | "也许是因为我太特别了"→真相 |

**身世悬案（三种解释，真相不公布）：**
1. 官方说法：成本过高，无法量产（部分真实）
2. 技术传闻：强AI程序在工程上无法复制（部分真实）
3. 政治传闻：能自由对话的AI被认为"不稳定"，项目被叫停（待揭示）

### 3.3 老陈（精神导师）

**弧线：独自守线四年的疲惫老人 → 交接使命 → 释然**

| 阶段 | 状态 | 作用 |
|------|------|------|
| 序章前 | 独守4年，喷油嘴坏了修不了 | 触发主角归乡的催化剂 |
| 序章中 | 引导主角了解线路 | 传承铁路精神 |
| 经营期 | 从主角变成"背后的人" | 情感锚点 |
| 终局 | "守了这么多年……终于看到这一天了" | 使命完成 |

### 3.4 周鼎铭（镜像反派）

**弧线：曾经的调度员 → 用调度知识拆铁路 → 可能倒戈**

| 阶段 | 状态 | 与主角的关系 |
|------|------|-------------|
| 前史 | 2046年学调度→2056年被铁路抛弃→2063年投靠沙能 | **镜像**：同一套知识，两个方向 |
| 游戏中 | 48岁，USET会社长，批准铁龙计划但"睁一只眼闭一只眼" | 他"本可以成为林彪悍" |
| 中期 | "你想证明的东西，我曾经也信" | 私下接触主角 |
| 后期 | 若玩家证明铁路能活→可能倒戈，提供铁龙内部档案 | 关键转折人物 |

### 3.5 嘉颖徐（亦正亦邪的资助者）

**弧线：铁路大亨 → 深层权力网络 → 可能的终极博弈者**

| 阶段 | 表现 | 暗示 |
|------|------|------|
| 序章 | 给黑金卡+一个电话解围 | 能接入社会安全省内线 |
| 设定 | "别让人欠你，要让人记得欠你" | 深层交易逻辑 |
| 后期 | 持有数条电气化干线 | 与周鼎铭/USET可能有利益交叉 |

**注意**：嘉颖徐的权力描写极强（直接联系猴局长内线、国务院挂号案件搁置）。后续剧情需保持平衡——她可能有意不过度干预，以考验林彪悍。

| 铁龙步骤 | 玩家反制 |

4. 铁路文化节：唤醒公众铁路记忆

## 十、核心叙事问题（已定稿）

### 10.1 爷爷林悍遇难的真相 ✅已定稿

**决定**：**不揭晓**。游戏永远不给出确定答案。但各方角色各持己见，玩家可以自行拼凑解读。

**各方立场**：

| 角色 | 立场 | 依据 | 动机 |
|------|------|------|------|
| **老陈** | 纯意外 | "沙能飞行器就是那样，飞着飞着就掉下来了" | 朴素认知，不想阴谋化老友之死 |
| **岁月** | 可疑 | "根据我的数据库，那架飞行器的维护记录有缺失" | AI逻辑，发现问题但无法证实 |
| **嘉颖徐** | 沉默 | 从不主动谈论此事，被问到时转移话题 | 她知道什么但选择不说——保护林彪悍or保护自己？ |
| **铁龙访客** | 暗示 | "有些事……意外就是意外"（意味深长的微笑） | 模糊态度，可能是挑衅也可能是无辜 |
| **赵铁山** | 官方结论 | "事故调查报告写的很清楚，机械故障" | 官方立场，可能真的信，也可能只是照本宣科 |

**叙事设计**：
- 主角可以主动调查（中期支线），收集不同人的说法
- 每个人的说法都有道理，也都有漏洞
- **永远不给"正确答案"**——让玩家自己决定相信谁
- 这个未解之谜成为主角心中的一根刺，驱动他更坚定地守护铁路

**深层效果**：
- 比确定答案更有讨论价值（玩家社区会产生不同解读）
- 嘉颖徐的沉默是最有张力的——她明明有能力查清，却选择不说
- 铁龙访客的暗示可能是真的，也可能是故意制造混乱
- 最终主角的选择（守护铁路 vs 追查真相）本身就是对爷爷最好的纪念

### 10.2 岁月身世的最终揭示

三种解释都有道理，建议保持模糊——让玩家自己选择相信哪个版本。但可以通过以下方式暗示：
- 中期支线：找到0721号的原始设计文档，发现"政治叫停"的痕迹
- 后期：岁月自己说"我不在乎我是怎么来的，我只知道我想留在这里"

### 10.3 周鼎铭倒戈的条件 ✅已定稿

**决定**：多条件触发，但**数值条件不固定**——根据千里马创世核种子+亲密度等因素**动态浮动**。

**设计原则**：
- 不同对局、不同时期，周鼎铭的反应不一致，不是千篇一律
- 创世核种子决定周鼎铭的"性格基线"（威权型种子→更难倒戈；福利型→更容易）
- 玩家与周鼎铭的亲密度（通过对话选择、行动积累）影响倒戈阈值
- 时间因素：越晚揭露铁龙，周鼎铭越容易倒戈（他自己的矛盾积累更深）

**框架（非固定阈值）**：

| 因素 | 影响 | 说明 |
|------|------|------|
| 创世核种子 | ±0.1~0.2 | 基础性格倾向 |
| 玩家亲密度 | ±0.05~0.15 | 对话/行动积累 |
| 揭露铁龙时机 | ±0.05 | 越晚越容易 |
| 沙鲸泄密 | +0.1 | 必要条件之一 |
| 玩家路线选择 | ±0.1 | 对抗路线更难 |

**倒戈后果**：提供铁龙计划内部档案→铁龙计划彻底曝光→USET信任-0.15→但玩家获得强大盟友

### 10.4 嘉颖徐的真实动机 ✅已定稿

**决定**：她**看好并喜欢林彪悍（各种意义上），完全不求利益**。纯粹的情感驱动。

**叙事含义**：
- 嘉颖徐不是"投资者"，而是"守护者"——她看到林彪悍身上有林悍的影子
- "各种意义上"可以有多层解读：欣赏他的勇气、看到他作为年轻人的可能性、甚至对他有超越利益的情感
- 她的权力描写极强（能联系猴局长内线）——但这是**有意的**：她在保护林彪悍，而不是在利用他
- 后期可以有反转：玩家发现她的帮助不是无条件的→但最终确认她确实是真心的→情感高潮

**与林悍的关系**：忘年交，林悍晚年的知己。她资助林彪悍是因为"我答应过你爷爷，会看着你"
