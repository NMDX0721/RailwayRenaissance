# 旅客支线剧情计划

> 版本：v1.0

---

## 一、设计理念

借鉴《爱上火车》等铁路题材作品的旅客互动叙事，让旅客不只是数字，而是有身份、有故事、有温度的角色。

**核心原则：**
- 每个有名有姓的旅客都有好感度
- 支线剧情围绕具体物品/事件展开
- 玩家的选择影响好感度和后续剧情
- 支线奖励与游戏核心数值挂钩

---

## 二、旅客身份系统

| 类型 | 触发场景 | 叙事功能 |
|------|---------|---------|
| 行商老人 | 通勤线随机 | 展现铁路的货运价值 |
| 返乡学生 | 大学城线解锁后 | 展现铁路对年轻人的意义 |
| 退休铁路工人 | 运营>20天 | 传承铁路精神 |
| 记者 | 信任>60%时随机 | 媒体事件，短期客流提升 |
| 市长秘书 | 政治事件相关 | 传递政治情报 |
| 沙能公司员工 | 沙能渗透>40% | 对抗剧情 |
| 小镇少年 | 解锁第2条线 | 青春活力 |
| 母女旅客 | 任意线路 | 日常温暖 |

---

## 三、好感度系统

| 操作 | 好感度变化 |
|------|-----------|
| 完成支线 | +10 |
| 正确选择 | +5 |
| 错误选择 | -3 |
| 赠送礼物 | +5 |
| 忽视旅客 | -2 |
