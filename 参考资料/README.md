## 📊 系统概览

### 游戏核心

- **名称**：铁路复兴：沙能冲击
- **引擎**：Unity 6000.4.6f1
- **平台**：Windows + Android
- **风格**：2D像素风模拟经营

### 核心系统

1. **经济系统**：基于2026年真实数据 + Flow理论平衡 + 跨系统联动公式 + 概率波动
2. **员工系统**：国际铁路职级标准 + 独立成长曲线 + 潜力上限 + 疲劳管理
3. **车辆系统**：NF-5耕牛（参考东风4型）+ 状态损耗 + 维护正反馈
4. **线路系统**：23公里，42分钟单程，2趟往返/天
5. **补贴系统**：条件补贴（基础+客运+准点+安全+政策）
6. **里程碑系统**：短期/中期/长期目标 + 功能性奖励
7. **成就系统**：荣誉成就 + 功能性奖励
8. **随机事件系统**：经济/运营/人物/剧情（6:4正面偏置）+ 概率波动
9. **AI对话系统**：支持MiMo 2.5 + 自定义API + 玩家自由输入

### 关键参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 柴油价格 | 15沙币/升 | 基于真实推算 |
| 油耗 | 58.5L/100km | 与世界观一致 |
| 票价 | 35沙币/人 | 23公里单程 |
| 司机工资 | 30,000沙币/月 | 基于真实+稀缺溢价 |
| 初始月亏损 | 约11万 | Flow=1.2，有挑战但有希望 |
| 扭亏时间 | 2-4个月 | 更快的正反馈 |
| 盈亏平衡 | 4节车厢，60%上座率 | 普通难度 |
| 成长曲线 | 难度递增 | 10/20/40/80/150天 |

2. **深入**：再读 `沙本位经济核.md`、`角色设定.md`、`世界观与车辆设定.md`
3. **细节**：最后读其他系统设计文档

## 🔧 与MiMo Code协作

### 协作流程

1. 发现问题 → 向MiMo Code提问
2. MiMo Code回答 → 分析技术细节
3. 提出解决方案 → 与用户确认
4. 用户确认 → 写最终提示词
5. 发送给MiMo Code → 等待实现

### 提示词格式

```
当前值：[当前状态]
目标值：[期望状态]
约束：[限制条件]
```

### 注意事项

- 不知道当前值时，必须先询问获取
- 分阶段交付，不要一次给太多
- 提示词描述需求，不写代码
