# 术语系统设定

> 版本：v1.0

---

## 一、设计理念

采用"角色对话"模式，由老陈、林彪悍、张工等角色以符合其性格的方式互相补充解释术语，而非罗列定义。

---

## 二、术语JSON格式

```json
{
  "terms": [
    {
      "id": "sand_energy",
      "name": "沙能科技",
      "explanations": [
        {"speaker": "老陈", "text": "这玩意儿就是用沙子当燃料的技术。"},
        {"speaker": "林彪悍", "text": "理论上是把沙子微粒转化为驱动能源。"}
      ]
    }
  ]
}
```

---

## 三、显示效果

| 状态 | 样式 |
|------|------|
| 正常 | 黄色加粗 |
| hover | 黄色下划线 |
| 点击 | 弹出解释窗口 |

---

## 四、角色分工

| 角色 | 解释风格 |
|------|---------|
| 老陈 | 日常经验、朴实口语 |
| 林彪悍 | 学术理论、专业术语 |
| 张工 | 机械维修、实际操作 |
| 岁月 | 沙能科技、精确数据 |
