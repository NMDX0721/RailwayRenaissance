## 一、数据来源与推算方法

### 1.1 基准数据（2026年）

| 项目 | 真实数据 | 来源 |
|------|----------|------|
| 柴油价格 | 6.6-6.8元/升 | 国内成品油价格（2026年7月） |

| CPI通胀率 | 0.9% | 高盛预测 |
| PPI通胀率 | 0.8% | 高盛预测 |

### 1.2 推算假设（2026→2076，50年）

| 假设项 | 数值 | 说明 |
|--------|------|------|
| 年均通胀率 | 2.5% | 考虑经济波动，取中值 |
| 年均经济增长率 | 3.0% | 保守估计 |
| 技术进步系数 | 0.8% | 效率提升抵消部分通胀 |

**推算公式**：
```
2076年价格 = 2026年价格 × (1 + 通胀率 - 技术进步)^50
           = 2026年价格 × (1 + 0.025 - 0.008)^50
           = 2026年价格 × (1.017)^50
           = 2026年价格 × 2.29
```

### 7.2 剧情补贴机制（硬核设计核心）

> **设计原则**：前期纯运营必然亏损，玩家必须通过推进剧情、完成序章任务来获取资金注入。

| 补贴类型 | 触发条件 | 金额 | 说明 |
|----------|----------|------|------|
| 序章剧情补贴 | 完成序章Day 0-4 | 30,000沙币 | 老陈筹集的启动资金 |
| 修复机车补贴 | 完成机车修复任务 | 15,000沙币 | 政府扶持基金 |
| 首次发车奖励 | 成功发出第一班列车 | 8,000沙币 | 村民自发集资 |
| 线路巡视 | 完成线路巡视任务 | 5,000沙币 | 地方维护费 |
| 员工集结 | 召齐5名员工 | 5,000沙币 | 社区志愿者补贴 |
| 月度剧情事件 | 每月触发1-2次 | 5,000-15,000沙币 | 随机剧情奖励 |

**初期资金流模型**：
```
第1个月：纯运营-106,875 + 序章剧情补贴63,000 = -43,875沙币
  + 初始资金40,000 = 第1月末余额 -3,875沙币（需继续推进剧情）

第2个月：纯运营-106,875 + 月度剧情10,000 + 补贴12,500 = -84,375沙币
  + 第1月余额(-3,875) + 新剧情线注入 = 继续亏损但可控

约第4-5个月：上座率提升+多节车厢+持续剧情 = 亏损收窄至约-50,000
约第8-10个月：接近盈亏平衡
```

> ⚠️ 硬核提示：不推进剧情只靠纯运营，玩家一定破产。**剧情是经济的生命线**。

### 7.3 盈亏平衡路径（硬核剧情版）

**设计目标**：
- 初期纯运营必然亏损，**剧情补贴是生存关键**
- 中期成长带来掌控感，亏损收窄
- 后期享受成就，实现真正盈利

---

**阶段1：求生期（第1-2个月）** ⭐ Flow=1.2
- 目标：推进剧情，争取补贴活下来
- 配置：2节车厢，30%上座率
- 纯运营亏损：约-106,875沙币/月
- 剧情补贴：约63,000沙币（序章任务）+ 10,000-20,000/月（支线）
- **实际净亏损（含剧情）：约-23,000 ~ -43,000沙币/月**
- 初始资金40,000 + 剧情补贴 = 可撑至第2-3个月
- **关键**：第1个月内必须完成序章剧情任务，否则破产
- **里程碑1**：成功运营第一个月

---

**阶段2：稳定期（第3-4个月）** ⭐ Flow=1.0
- 目标：提升服务质量，推进支线剧情
- 变化：上座率提升至40%
- 纯运营亏损：约-95,000沙币/月
- 剧情补贴：约15,000-25,000沙币/月
- **实际净亏损：约-70,000 ~ -80,000沙币/月**
- **里程碑2**：连续30天无事故

---

**阶段3：成长期（第5-8个月）** ⭐ Flow=0.9

### 7.5 剧情补贴设计原则

1. **不可替代性**：剧情补贴是前期生存关键，不是可选项
2. **递减性**：随游戏进程，补贴占比逐渐降低（从60%→10%）
3. **任务绑定**：补贴与具体剧情任务绑定，不是自动发放
4. **叙事驱动**：补贴有情节支撑（老陈筹款、政府扶持、村民集资等）
5. **硬核底线**：即使有剧情补贴，第1个月仍处于亏损状态，玩家必须精打细算

## 八、随机事件系统（保持游戏新鲜感）

### 8.0 设计原则（概率波动）

**避免硬编码**：所有数值添加概率波动
- **高波动参数**（±30%）：客运量、上座率、乘客满意度
- **中波动参数**（±15%）：油价、维护成本、事故概率
- **低波动参数**（±5%）：工资、基础补贴、燃料消耗

**波动公式**：
```
实际值 = 基础值 × (1 + 随机波动)
随机波动 = 随机数(-波动范围, +波动范围)
```

**示例**：
- 客运量基础值100人，波动范围±30%
- 实际值 = 100 × (1 + 随机数(-0.3, +0.3)) = 70-130人

## 十三、跨系统联动公式

### 事故概率计算

```
事故概率 = 基础概率(5%) × 车辆老化系数 × 司机专长系数 × 维护系数

其中：
- 车辆老化系数 = 1 + (100 - 车辆状态) / 50
- 司机专长系数 = 1 - (司机等级 × 0.15)
- 维护系数 = 1 - (最近7天维护次数 × 0.1)

示例：
- 车辆状态70，司机3级，最近维护2次
- 事故概率 = 5% × 1.6 × 0.55 × 0.8 = 3.52%
```

### 维护成本计算

```
实际维护费 = 基础维护费 × 车辆损耗系数 × 机械师专长系数

其中：
- 车辆损耗系数 = 1 + (100 - 车辆状态) / 100
- 机械师专长系数 = 1 - (机械师等级 × 0.1)

示例：
- 基础维护费15,000，车辆状态60，机械师5级
- 实际维护费 = 15,000 × 1.4 × 0.5 = 10,500沙币
```

### 乘客满意度计算

```
满意度 = 基础分(60) × 准点率系数 × 服务系数 × 车辆舒适度系数

其中：
- 准点率系数 = 0.8 + (准点率 × 0.4)
- 服务系数 = 1 + (乘务员等级 × 0.05)
- 车辆舒适度系数 = 0.7 + (车辆状态 / 200)

示例：
- 准点率90%，乘务员4级，车辆状态70
- 满意度 = 60 × 1.16 × 1.2 × 1.05 = 87.7分
```

### 燃料成本修正

```
实际燃料费 = 基础燃料费 × 车辆状态系数

其中：
- 车辆状态系数 = 1 + (100 - 车辆状态) / 200

示例：
- 基础燃料费24,225，车辆状态70
- 实际燃料费 = 24,225 × 1.15 = 27,859沙币
```
