# 铁路复兴：沙能冲击 — 角色音色设计（Gemini Speech Generation）

> 工具：**Gemini Speech Generation**（Google AI Studio / Gemini API）
> 模型：`gemini-3.1-flash-tts-preview`（另有 `gemini-2.5-flash-preview-tts`、`gemini-2.5-pro-preview-tts` 备选）
> 文档：https://ai.google.dev/gemini-api/docs/speech-generation
> 试听：https://aistudio.google.com/generate-speech
> 批量生成：`tools/generate_voice.py`（需环境变量 `GEMINI_API_KEY`，输出到 `Assets/Resources/Voice/`，音色映射 `tools/voice_map.json`）
> 迁移记录：2026-09-25 由 ElevenLabs Voice Design 迁移到 Gemini（ElevenLabs 无自定义音色创建，Gemini 用 30 个预设音色 + 风格提示词）

## 🔊 全局语言策略

**配音语言：全日语。** 所有角色统一日语配音，中文字幕 + 英文字幕分别发布。

**理由：** 二次元立绘与 VN 表现更贴日配习惯；统一语言避免同框对话语码切换的割裂感；多语言字幕翻译即可，配音管线不变。世界观语言（朝鲜语/汉语）保留在剧本与字幕层，不进配音轨。

**角色音色底色**：底层文化背景（老陈的"乡村温暖"、张工的"东北爽朗"）保留在风格提示词中，作为性格特征，不改变语言。

**年龄锚定（强制）**：风格提示词中年龄必须与 `设定/角色设定.md` 一致，写死实际岁数，禁止过宽区间拉老/拉幼：岁月 **13** / 林彪悍 **25** / 老陈 **68** / 嘉颖徐 **24**；配角见速查表。

**生成工具链**：主力 **Gemini Speech Generation**（AI Studio 试听 + API 批产）；兜底 Edge-TTS（ja-JP 神经音色）。

**Gemini 关键约束**（来自官方文档）：
- 输出 **PCM16 / 24kHz / 单声道**，脚本自动封装为 wav
- 单次输入 **≤500 字符**（我们的台词最长约 190 字，安全）
- 语言自动检测，日语（`ja`）在支持列表内
- 情感控制两种方式：**风格提示词**（Style/Pace/Accent 指令）+ **音频标签**（`[laughs]` `[sighs]` `[whispers]` 等，非英语台词也用英语标签）
- 30 个预设音色，**无自定义音色创建**——选型即用 `voice_map.json` 映射

## 二、岁月（Suiyue）— AI 伙伴

**角色定位**：0721号搭载的 AI 原型，2053 年制造，沉睡 23 年至 2076。以 **13 岁二次元少女形态**随时全息投影陪伴主角。清亮认真的少女音，好奇爱碎碎念，但骨子里冷静精准——"23 年无人对话"的孤独藏在少女外壳下。

**【音色】** `Leda`（Youthful）

**【风格提示词】**
```
Native Japanese, standard Tokyo accent. Female, exactly 13 years old — a young anime hologram girl, not an adult woman. Bright, curious, watchfully precise; brisk natural pace with genuine wonder in questions, deadpan dry humor when stating facts. Clear youthful timbre with a light, faintly synthetic sheen, like a schoolgirl speaking through a soft speaker. When serious, slows and sharpens without losing the girl register.
```

**【Preview Text】（AI Studio 试听用，含音频标签）**

## 七、多语言发布说明

配音管线统一输出**日语 wav**。不同语言版本通过字幕切换实现：

| 版本 | 配音 | 字幕 | 处理方式 |
|------|------|------|---------|
| **中文版** | 日语 | 中文字幕 | 台词表内嵌中文翻译 → 字幕文件 |
| **英文版** | 日语 | 英文字幕 | 台词表翻译英文 → 字幕文件 |

Gemini TTS 输出的日语 wav 直接复用，跨语言版本零重生成。

## 八、生成与测试流程（Gemini 版）

1. **音色试听**：AI Studio（aistudio.google.com/generate-speech）选音色 → 各角色贴【Preview Text】试听，确认年龄听感
2. **年龄验收**：听感必须贴「实际年龄」；林彪悍不得偏少年，嘉颖徐不得母辈，岁月不得成人化——不符就改风格提示词里的年龄句
3. **情感测试**：Preview Text 已内嵌 `[calm]` `[tired]` `[sharp]` `[gentle]` 等标签，逐段回放确认情感区分度
4. **选型定稿**：每角色确认音色后写入 `tools/voice_map.json`（音色 + 风格提示词）
5. **批量生成**：跑 `tools/generate_voice.py`（见下节），抽样回放
6. **效果不满意时**：优先改**风格提示词**（Style/Pace 描述越具体越好，官方建议像"导演笔记"），其次**换音色**，再次加**音频标签**；日语文本里的标签用英语写
7. **单句重生成**：删掉对应 wav 重跑（脚本跳过已存在文件）

## 九、批量生成脚本

```powershell
# 环境变量（Google AI Studio → Get API key）
$env:GEMINI_API_KEY = "你的key"

# 干跑：列出将生成哪些文件（不调 API）
python tools/generate_voice.py --dry-run

# 只生成序章前 10 条试效果
python tools/generate_voice.py --limit 10

# 全量（已有 wav 自动跳过，可反复续跑）
python tools/generate_voice.py
```

- 输入：`Assets/Resources/Scripts/*.json` 中 `t=n/d` 的台词（旁白与对话）
- 输出：`Assets/Resources/Voice/{script_id}/s{场景:02d}_d{序号:03d}.wav`
- 跳过类型：`c/scroll/boot/cg/special/loc`（不进对话框的不配音）
- 节流 1.5s/条 + 429/5xx 自动重试 3 次
