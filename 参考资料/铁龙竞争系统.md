## 一、神话典故：天马与龙

> **《汉书·礼乐志》· 天马歌**  
> *"太一况，天马下，沾赤汗，沫流赭。志俶傥，精权奇，籋浮云，晻上驰。体容与，迣万里，**今安匹，龙为友**。"*

汉武帝时期，西域大宛国进贡汗血宝马，武帝作《天马歌》。歌中说：天马腾云驾雾，奔驰万里，**世间谁能与之匹敌？唯有龙可以作它的朋友**。

在中国神话体系中，**天马（千里马）与龙**是对等的存在：
- 天马行空，龙行天下
- 一在天，一在地
- 一为神骏，一为灵兽

两者不是敌对关系，而是**镜像对立**——天马是飞驰的、自由的、可见的；龙是潜伏的、深沉的、不可测的。

## 二、游戏世界观中的千里马

### 2.1 千里马是什么

**千里马（Chollima）**在游戏世界观中是**朝鲜的国产品牌**，由 USET（联合沙能科技）持有。

| 维度 | 内容 |
|------|------|
| 品牌归属 | USET（联合沙能科技） |
| 产地 | 朝鲜平壤 |
| 产品线 | 飞猪号（民用飞行器）、沙驴号（通勤）、沙鸡号（紧凑型）、沙牛号（货运）、沙熊号（SUV） |
| 品牌形象 | 高速、现代、朝鲜科技实力的象征 |
| 真实原型 | 朝鲜"千里马"电脑品牌 + 千里马运动神话 |

在游戏中，**千里马是沙能科技的旗帜**，是 USET 摆在明面上的品牌——老百姓看到的是"千里马牌飞行器"，是那个时代的标志。

### 2.2 千里马与游戏系统的关系

| 系统 | 关系 |
|------|------|
| **千里马创世核** | 世界生成系统，以"千里马"命名寓意世界从神话中诞生 |
| **铁龙竞争系统** | 控制 USET 的竞争行为，铁龙是 USET 的暗面计划 |

> 两个系统同名"千里马/铁龙"，但不是同一个东西——**千里马创世核是生成世界的工具**，**铁龙竞争系统是控制对手行为的 AI**。一个造世界，一个管对手，名字呼应但功能独立。

## 三、铁龙计划：USET 的暗面

### 3.1 铁龙计划是什么

**铁龙计划**（Iron Dragon Project）是 USET 内部的一个**秘密子计划**。

| 维度 | 内容 |
|------|------|
| 名义目标 | 以"保护铁路文化遗产"为名，创立铁路保护组织，扶持濒危线路 |
| 实际目标 | 恶性收购铁道，以保护之名行吞并之实 |
| 执行方 | USET 战略收购部 |
| 公开形象 | 非营利铁路保护基金会 |
| 真实面目 | 沙能垄断的最后一块拼图 |

**铁龙计划的精髓**：USET 知道直接消灭铁路会引起社会反弹。于是他们成立了一个"铁路保护组织"——表面上帮助铁路，实际上以低价收购经营困难的线路。等铁路意识到这是个陷阱时，路网已经攥在 USET 手里了。

### 3.2 铁龙计划的操作方式

```
1. 筛选目标：寻找经营困难的线路（玩家初期）
2. 接触：以"铁路保护基金会"名义提供援助
3. 渗透：在援助协议中埋入收购条款
4. 施压：通过沙能渗透率加速线路亏损
5. 收购：当线路无法独立运营时，提出收购要约
6. 吞并：收购成功后，拆除铁轨，改为沙能航线
```

### 3.3 铁龙计划与游戏系统的关系

**铁龙竞争系统**控制的就是 USET 在铁龙计划框架下的所有行动——包括明面的市场竞争（沙能渗透）和暗面的收购操作。

```
铁龙竞争系统控制：
  ├── 明面策略：沙能渗透（广告、试乘、价格战）
  │   ├── 千里马品牌推广
  │   └── 市场份额争夺
  │
  └── 暗面策略：铁龙计划（收购、吞并）
      ├── 铁路保护基金会接触
      ├── 收购要约
      └── 线路吞并
```

## 五、沙能公司行为模型

### 5.1 沙能渗透率（核心变量）

每城市独立维护 `penetration[city]`，范围 0-1。

```
初始值：0.15（大废线4年后，沙能已占据大部分市场）
自然增长：+0.0015/天（约0.045/月，0.54/年）
自然衰减：-0.0005/天（沙能自身事故/口碑下降）
```

#### 惯性原则（v2.0 新增）

沙能渗透的惯性系数为 **0.20**——所有系统中最高，因为 USET 一旦扎根，很难驱逐。

```
当日渗透变化 = 理论变化 × (1 - 0.20) + 30天渗透均值 × 0.20
```

**遗留问题——USET 营业点**：

当渗透率 > 0.60 持续 15 天，USET 在该城市建立营业点（永久竞争据点）：
- 即使后续渗透率降至 0.60 以下，营业点仍在
- USET 可随时从营业点低成本重启竞争（行动成本 -50%）
- 玩家需通过特殊剧情事件（"揭露铁龙真相"）才能拆除营业点
- 营业点存在时，该城市自然增长倍率 ×2（USET 的本地影响力）

**设计意图**：沙能渗透不是"按个按钮就能降下来"的数值——USET 的竞争行为有持久影响。玩家早期忽视竞争，后期即使加大投入，也很难快速扭转局面。这正是"承担过去的选择"。

### 5.2 沙能 AI 决策树

每 30 天执行一次"沙能行动轮"：

**Step 1: 评估全局态势**
- 计算每个城市的渗透率
- 计算玩家在每个城市的"铁路健康度"（信任+车况+服务）
- 识别"薄弱城市"（渗透率低但玩家健康度也低）
- 识别"关键城市"（渗透率高或玩家健康度高）

**Step 2: 选择策略**

| 条件 | 策略 | 类型 | 效果 |
|------|------|------|------|
| 全局渗透 < 0.30 | 广告攻势 | 明面 | 渗透+0.05，信任-0.03 |
| 渗透 0.30-0.50 | 免费试乘 | 明面 | 渗透+0.03，客流-10%（7天） |
| 渗透 > 0.50 | 价格战 | 明面 | 收入-15%（14天） |
| 玩家连续3次反击 | 收购试探 | 暗面 | 触发收购事件 |
| 玩家资金紧张 | 铁龙接触 | 暗面 | 以"保护"名义提供援助 |

**Step 3: 执行行动**
- 更新渗透率
- 触发对应的叙事事件
- 记录本次行动，供下次决策参考

## 六、对抗手段

### 6.1 公关手段

| 手段 | 成本 | 效果 | 冷却 |
|------|------|------|------|
| 社区宣传 | 200沙币 | 信任+0.02，渗透-0.005 | 7天 |
| 媒体合作 | 500沙币 | 信任+0.05，渗透-0.02 | 14天 |
| 政治游说 | 1,000沙币 | 政治压力-0.05 | 30天 |
| 铁路文化节 | 2,000沙币 | 信任+0.08，客流+20%（7天） | 60天 |

### 6.2 运营手段

| 手段 | 效果 | 副作用 |
|------|------|--------|
| 降价竞争 | 客流+15%，渗透-0.01 | 收入-20% |
| 提升服务 | 信任+0.03/天，渗透-0.005/天 | 成本+15% |
| 接驳合作 | 客流+5%，渗透-0.005 | 渗透速度+50%（长期代价） |
| 差异化定位 | 避开正面竞争 | 市场增长受限 |

### 6.3 反铁龙手段（剧情解锁）

| 手段 | 解锁条件 | 效果 |
|------|----------|------|
| 揭露铁龙真相 | 收集铁龙计划文件 | 铁龙计划曝光，USET 信任-0.15 |
| 媒体曝光 | 获得记者支持 | 收购行动暂停60天 |
| 铁路联盟 | 连接3个以上城市 | 联合抵制收购，谈判筹码增加 |
| 政治庇护 | 争取市长支持 | 铁龙计划在该城市被禁止 |
