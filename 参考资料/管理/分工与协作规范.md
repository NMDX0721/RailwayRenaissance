# 分工与协作规范

> 版本：v1.0  
> 角色：文职统筹（我） ↔ 编码助手（AI）

---

## 一、角色定义

### 文职统筹（我）

**职责**：
- 制定开发路线图和任务优先级
- 编写详细的设计文档和规格说明
- 给编码助手提供精确的任务指令（含文件路径、代码模板、参考文档）
- 验收编码助手的交付物
- 管理项目进度和版本控制
- 处理文档维护、矛盾修复、版本同步

**不负责**：
- 写C#代码（除非是示例片段）
- 调试Unity编译错误
- 生成图片/音频资产

### 编码助手（AI）

**职责**：
- 根据任务指令编写C#代码
- 创建和修改Unity脚本（.cs文件）
- 创建和修改JSON数据文件
- 运行编译验证（检查Editor.log）
- 报告实现中的问题和偏差

**不负责**：
- 设计决策（遵循已有设计文档）
- 美术资产生成
- 项目管理和版本规划

**JSON格式要求**（与prologue_04_arrival.json一致）：
```json
{
  "id": "prologue_07_first_repair",
  "scenes": [
    {
      "bg": "depot_morning",
      "bgm": "morning",
      "transition": "fade",
      "d": [
        {"t": "n", "text": "旁白文本"},
        {"t": "d", "s": "老陈", "text": "对话内容"},
```

### 任务T3: 经济系统实现

**参考文档**: `docs/compose/specs/跨系统联动公式.md` 全部

**目标文件**:
- 修改: `Assets/Scripts/GameData.cs`（重构约200行）

**核心公式实现**（关键代码）：
```csharp
// 每日结算
public DayResult AdvanceDay()
{
    InitializeIfNeeded();
    int startMoney = Money;
    int startTrust = Trust;

    // 1. 计算客流
    float seasonModifier = 1.0f; // 可扩展
    float sandPenetration = 0.15f; // 从沙能系统读取
    int conductorLevel = GetConductorLevel();
    int dailyPassengers = Mathf.FloorToInt(
        populationFactor * 0.001f * 
        (0.5f + Trust * 0.005f) * 
        seasonModifier * 
        (1f - sandPenetration) * 
        (1f + conductorLevel * 0.03f)
    );
    ExpectedPassengers = dailyPassengers;

    // 2. 收入
    int dailyIncome = dailyPassengers * 35 * 4; // 4趟单程

    // 3. 燃料费
    float dailyFuel = 58.5f * 92f / 100f * (1f + (100f - TrainCondition) / 200f);
    int dailyFuelCost = Mathf.RoundToInt(dailyFuel * 15f);

    // 4. 工资（安全优先配置）
    int dailySalary = 90000 / 30;

    // 5. 维护费
    int maintenanceCost = GetMaintenanceCost();

    // 6. 净收入
    int netIncome = dailyIncome - dailyFuelCost - maintenanceCost - dailySalary;
    Money += netIncome;

    // 7. 信任变化
    Trust += 1; // 日微增
    Trust = Mathf.Clamp(Trust, 0, 100);

    // 8. 车况变化
    TrainCondition -= 1; // 日损耗
    TrainCondition = Mathf.Clamp(TrainCondition, 0, 100);

    // 9. 事件触发
    DailyEvent evt = TriggerDailyEvent();
    if (evt != null) ApplyEvent(evt);

    DailyMoneyChange = Money - startMoney;
    DailyTrustChange = Trust - startTrust;
    Day++;
    RefreshBoards(BuildDailyTone());

    return new DayResult { /* ... */ };
}
```

**保持现有接口**：
- `AdvanceDay()` 返回 `DayResult`
- 保留 `CycleDispatchPlan()`, `CycleMaintenanceStrategy()` 等循环方法
- 保留 `GetCurrentDispatchPlan()`, `GetCurrentStaffAllocation()` 等获取方法

**验证**：连续调用AdvanceDay() 30次，观察资金变化趋势是否符合预期（初期亏损~3,000/天）
