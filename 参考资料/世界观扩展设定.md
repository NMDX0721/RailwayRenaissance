## 一、联合沙能科学技术会社（沙能会社）企业史

### 1.1 会社沿革

> **官方全称**：联合沙能科学技术会社（简称"沙能会社"，媒体通称"联合沙能科技公司"）  
> **社训**：「沙能千里马，前进再前进」——取自千里马运动精神，悬挂于平壤总部大厅  
> **英文登记名**：United Sand Energy Technology（USET），对外财报与国际报道使用

| 时间 | 事件 |
|------|------|
| 2050年 | 英国工程师团队发明沙能原理，注册"积极能源实验室" |
| 2051年 | 朝鲜民主主义人民共和国收购该实验室全部专利与团队，在平壤组建**联合沙能科学技术会社**——名义上的国际合资，实为朝鲜国家资本控股 |
| 2053年 | 首款产品"沙子飞猪号"量产（千里马牌）；同年"金正恩大沙子型"坦克下线，军用产品线成立 |
| 2056年 | 民用载具首次使全球铁路客运量下降34% |
| 2063年 | 第二代载具矩阵发布：沙驴号（通勤）、沙鸡号（紧凑）、沙牛号（货运）、沙熊号（SUV）——"让每个家庭都买得起沙能车"运动 |
| 2068年 | 借助铁路私有化浪潮，收购全球17家濒临破产的铁路客运运营商资产 |
| 2072年 | 全球铁路停运后，宣布沙能覆盖率达95%，成为事实上的全球交通垄断企业 |
| 2076年 | 现任CEO周鼎铭（会社长），48岁；第三代载具"沙鲸计划"研发中 |

### 1.2 企业结构与子母公司体系

**合资结构**——USET 是实打实的国际合资企业，有明确的朝、外两个股东（这正是它能以"国际合资"身份开展全球业务的法律基础）：

```
【登记股权（工商/财报口径）】
  ↙                                        ↘
卢森堡控股平台（名义控股·登记51%）     白头山动力总会社（朝方股东·登记49%）
（按普通跨国企业口径登记，                 （朝鲜国资委下设法人，朝鲜风味命名，
 国际制裁名单无法直接点名）                 出技术/出沙子/出政策通道）
        ↘                                        ↙
      联合沙能科学技术会社（USET）— 合资产物，国际运营层
        │
        └─【实际控制（不写入任何工商文件）】
            朝方通过三重协议掌握实质控制权：
            ① 管理协议——CEO 与各部要职由朝方委派/核准
            ② 技术授权——沙能核心专利由朝鲜本体独占授权，违约可单方终止
            ③ 沙子独家供应契约——全球补给站的沙子只从朝鲜体系采购
```

- **登记与实控分离**：账面上 USET 是"外资控股的卢森堡公司"（登记51%），朝方只占49%——西方监管与制裁体系无法直接点名朝鲜，沙能才能以普通跨国企业身份展开全球业务。而实际控制权，通过①管理②技术③沙子三份不公开的协议，牢牢握在白头山动力总会社手里。"名义联合、实为国策"从此有了法律与实务的双重基础。
- **白沙洲效应**：如果把 USET 比作一艘船，它挂的是卢森堡的旗，舵手却是平壤的人——这就是"一号会社"体系最核心的生存术。

**对外（国际）架构**——USET 及其子公司的国际运营层，国际报道只见此层：

```
联合沙能科学技术会社（USET）
├── 千里马民品公司（国际分部）  ← 飞猪号/沙驴号/沙鸡号/沙牛号/沙熊号
├── USET Defence（国际军工出面壳）← 对外军贸商标；实际生产在朝鲜本土
├── 沙能保障总局（补给网络事业部）← 全球2.3万座补给站，含游戏内补给站
├── USET 亚洲研究分院           ← 与金日成综合大学有合作历史的学术窗口
└── 对外宣传部（全球营销）       ← 广告攻势、免费试乘、价格战的实际执行者
```

**对内（朝鲜本土）关联体系**——白头山动力总会社体系下、不写在国际财报上的独立法人：

```
白头山动力总会社（朝方股东/合资方）
│  持股（通过"一号会社"国资体系）
├── 先军国防公社（独立法人）     ← 沙能坦克"金正恩大沙子型"、沙能装甲车
│                                   出厂即移交国防工业体系，境外采购走USET Defence壳
├── 沙能科学研究院（独立法人）   ← 第三代"沙鲸计划"；理事长即平壤总部技术总管
└── 沙能保障总局（国内后勤段）   ← 与补给网络事业部是"两个牌子、一套系统"
```

> **命名解释**：国际层使用通用企业名（民品/Defence/研究院），对内层使用朝鲜惯例名（先军/公社/科学院/保障总局）。"先军国防公社"是朝鲜军工体系的内部建制名，绝不会出现在国际公开架构中——境外看到的是"USET Defence"商标。合资架构（白头山动力总会社 + 卢森堡控股平台）让"国际合资"在法律上成立，而 51% 的朝方控股保证了"实为国策"——两张皮各司其职。

## 二、铁龙计划（USET 的暗面）

### 2.1 名称来源：天马与龙

> **《汉书·礼乐志》· 天马歌**：*"太一况，天马下……体容与，迣万里，**今安匹，龙为友**。"*
> 在中国神话体系中，天马（千里马）与龙是对等的镜像存在——天马行空，龙行天下。

USET 内部以"铁龙"命名此计划，用意微妙：对外宣称"铁龙"是铁路的象征（取"钢铁巨龙"之意），暗示自己是铁路的守护者；对内则心知肚明——**龙潜伏于渊，吞万物于无声**。铁龙计划不是龙与马的较量，而是龙对马的吞噬。

### 2.2 计划定义

| 维度 | 内容 |
|------|------|
| 计划代号 | 铁龙计划（Iron Dragon Project） |
| 前身 | 2068年周鼎铭主导收购17家铁路运营商资产（无名的试点） |
| 正式立项 | 2072年全球停运后（有明确收购目标与法律空间） |
| 主管单位 | USET 战略收购部（国际层，不挂钩朝鲜本土建制） |
| 公开形态 | "国际铁路遗产保护基金会"（非营利组织脸面） |
| 实际性质 | 以保护为名、收购为实的铁路资产吞并工程 |
| 核心逻辑 | 直接消灭铁路会引发社会反弹；让铁路"自己活不下去"，再以拯救者身份收购 |

### 2.3 立意：为什么是"保护"

USET 在2068年评估过两条消灭铁路的路线：

| 路线 | 做法 | 结果 |
|------|------|------|
| 武路线 | 立法禁运、强制拆除 | 民众反弹，沙能载具遭抵制，政治代价极高 |
| **文路线（铁龙计划）** | 扶持"铁路保护组织"，收购经营困难线路 | 舆论站在 USET 一边：*"连铁路爱好者都在买下线路保护它们，我们是在帮忙"* |

铁龙计划的本质是**叙事战争**：把"吞并铁路"包装成"拯救铁路"。玩家在游戏中的每一次抗议，都是在拆穿这套叙事。

### 2.4 内部结构

```
USET 战略收购部（铁龙计划指挥层）
├── 国际铁路遗产保护基金会（公开壳）
│     ├── 各地区"铁路抢救小组"    ← 派驻目标线路的代理人
│     ├── 遗产保护巡回展          ← 舆论工具，淡化收购色彩
│     └── 志愿者招募计划          ← 吸纳真铁路爱好者，增加可信度
├── 收购执行处（实际收购操作）
│     ├── 财务组：估值、压价、信贷施压
│     ├── 法务组：在援助协议中埋设收购条款
│     └── 运营组：接管后的"改造评估"（实为拆轨论证）
└── 情报联络处（与对外宣传部/沙能保障总局联动）
      ├── 加密渗透数据：各线路亏损台账
      └── 与千里马品牌营销联动：先降价抢客流，再"善意"收购
```

### 2.5 收购流程（标准剧本）

```
Step 1 筛选目标：锁定客流下滑、补贴依赖度高的线路（玩家初期状态）
Step 2 接触：基金会上门，以"保护铁路文化遗产"名义提出援助
Step 3 渗透：援助协议中埋入"经营不善时基金会可接管运营"条款
Step 4 施压：关联千里马品牌在目标城市加大渗透，加速线路亏损
Step 5 收购：线路无法独立运营后，按预先条款提出收购要约
Step 6 吞并：收购成功后"遗产化"处理——停运、评估、论证改建沙能航线
```

> 关键细节：铁龙计划**从不强迫**。它只创造一个"除了卖给你别无选择"的环境。这在世界观上与"沙能六大弱点"形成对照——沙能赢不了铁路的正面，但赢得了时间的侧面。

## 三、沙币货币体系（沙本位制）

### 3.1 货币起源

沙能时代前，世界通行以贵金属锚定的货币体系。2053年沙能商业化后，沙子从普通资源变为战略性能源。2076年，**沙子已成为全球最重要的能源与战略资源**，货币体系随之重构。

### 3.2 沙本位制

> **沙币（Sand Yuan / 沙）**：以沙子为价值锚定的法定货币。1沙币的法定购买力对应于10公斤标准工业沙的标准兑换价值（由国家质量标准局定期发布）。

**兑换关系**：游戏内补给站"1500公斤沙子 = 150沙币"，即1沙币 = 10公斤沙子——这并非打折，而是**沙币与沙子的官方挂钩标准**（1500公斤 ÷ 150沙币 = 10公斤/沙币）。

### 3.3 体系特征

| 特征 | 说明 |
|------|------|
| 发行方 | 朝鲜人民银行（世界最大沙子储量国） |
| 锚定物 | 标准工业沙（国标SB-62） |
| 汇率 | 随季节与开采成本小幅波动（对应经济系统"沙子价格倍率"） |
| 衍生 | 大额沙币（万沙）：1万沙 = 10,000沙，大宗交易专用 |
| 前景 | 早期设定中的"朝币"（1朝币≈50沙）为过渡期货币，2076年已退出流通 |

### 3.3.1 全球沙子供应链（补给站的沙子从哪来）

**问题**：沙能载具依赖沙子补给，全球2.3万座补给站（沙能保障总局）需要源源不断的沙子——如果这些沙子全部从朝鲜海运，既不经济也受制裁限制。

**答案**：沙能消耗的不是"稀缺沙子"，而是**标准工业沙（国标SB-62）的可兑换凭证**：

```
沙能载具的真正燃料 = 沙子 + 提炼权（sand quota）

体系设计：
1. 全球2.3万座补给站就近采购/储存本地沙子（就地取材，无需跨国运输）
2. 每一座补给站必须持有"沙能提炼权配额"（sand quota）——该配额由
   沙能保障总局按年发放，是沙币结算链的关键一环
3. 配额的本质：载具用掉的每一公斤沙子，都对应一笔沙币回流朝鲜——
   无论沙子挖自延边还是撒哈拉，财务上都记在朝鲜人民银行账上
```

**供应链闭环**：

```
朝鲜人民银行发行沙币 ↔ 锚定标准工业沙
      ↕（记账）                     ↕（实物）
沙能保障总局发放提炼权配额 ←→ 全球补给站就地消耗本地沙子
      ↕
白山头动力总会社/朝鲜 = 全球沙子金融的最终结算地
```

**对游戏的影响**：
- 补给站"1500公斤沙子 = 150沙币"是**全球统一官价**——无论在哪补给，价格一致
- "沙子价格倍率"难度参数 = 提炼权配额发放量波动（配额收紧→沙子涨价）
- 后期经济危机事件候选："某国扣留沙能提炼权配额"（地缘博弈）/"撒哈拉沙子耗尽"（资源恐慌）
- **"沙之诺"阴谋**：有人怀疑全球补给站的沙子实际被替换为普通沙而与国标不符——流言关乎沙能体系的可靠性，可作为叙事事件（伏笔：沙能事故的另一种解释）

### 3.4 对游戏的影响

- 解释了为何油价、工资都以"沙币"计价——沙能时代的经济皆以沙为锚
- "沙子价格倍率"难度参数：影响补给站价格，进而影响燃料/补给成本
- 后期经济危机事件可设计为"沙子开采成本暴涨/暴跌"，冲击全系统

## 四、雾峰村的过去

### 4.1 村庄概况

雾峰村位于**中国中部偏东的山区（约浙江一带的地形地貌）**，常年多雾，村名由此而来。村庄以东为矿区山脉，以西为丘陵茶园。铁路是村庄与外界唯一的现代交通联系。

> **地域定位**：雾峰村非边境城镇，而是中国内陆的典型南方山村——雾气缭绕的山谷、梯田茶园、小型矿区。主角林彪悍在此长大，后赴平壤金日成综合大学留学（荣誉研究生），2076年学成归来。

### 4.2 线路历史

| 1960-70年代 | 铁路带动山区开发，茶山站周边发展为茶叶集散地，矿区站成为煤炭枢纽 |

| 2050年代 | 沙能载具出现，沿线客流开始流失 |

## 五、大废线后的铁路私营化法案

### 5.1 法律背景

2072年全球铁路停运后，各国政府面临同一问题：**大量废弃线路无法维持国有运营**。各国先后通过立法，将铁路资产"还权于民"。

> **时间差说明（2068 vs 2073）**：故事线时间轴中"2068年91国解体国有铁路系统"是**政治层面的宣布与资产剥离**（国有铁路公司解散、路网转归国家所有但不再运营）；而《铁路委托运营条例》这类**委托运营立法**是2073年起各国陆续落地的法律配套——先解体重组、后立法放权，间隔数年符合现实（国铁解体是行政决定，委托运营法需要议会程序）。玩家身份的法律基础是后者，不影响前者。

### 5.2 《铁路委托运营条例》（2073年）

**民情背景**：大废线后国家把铁路承包给了个人——这是玩家身份的法律基础。

| 条款 | 内容 |
|------|------|
| 第一条 | 废弃铁路线可申请委托运营，申请人自负盈亏 |
| 第三条 | 委托运营期间，线路资产所有权归国家，运营权归受托人 |
| 第五条 | 国家提供基础运营补贴（对应"基础补贴"8,000沙/月） |
| 第七条 | 连续90天无运营记录的委托将被撤销 |
| 第九条 | 受托人享有线路广告、站台商业等衍生收益 |

### 5.3 政治含义（对应政治系统）

- 市长（陈鹤年）、铁路监督员（赵铁山）是条例的实际执行者与监督者
- 补贴金额与运营评估挂钩——市长的政治倾向（威权/市场/福利）直接影响评估标准
- "线路被政府征收/转包"是不可逆事件的法律依据（政治压力>0.70时触发）

### 5.4 国际对照

| 国家 | 处理方式 |
|------|---------|
| 朝鲜 | 《铁路委托运营条例》，个人可承包废线 |
| 日本 | 各都道府县铁路公司解体，38县亏损后转为地方委托 |
| 欧洲 | DB/SNCF将乡村线路承包给私人运营商 |
| 英国 | 早在20世纪末完成私有化，成为此轮浪潮的模板 |
