## 一、联合沙能科学技术会社（沙能会社）企业史

### 1.1 会社沿革

> **官方全称**：联合沙能科学技术会社（简称"沙能会社"，媒体通称"联合沙能科技公司"）  
> **社训**：「沙能千里马，前进再前进」——取自千里马运动精神，悬挂于平壤总部大厅  
> **英文登记名**：United Sand Energy Technology（USET），对外财报与国际报道使用

| 时间 | 事件 |
|------|------|
| 2050年 | 英国工程师团队发明沙能原理，注册"积极能源实验室" |
| 2051年 | 朝鲜民主主义人民共和国收购该实验室全部专利与团队，在平壤组建**联合沙能科学技术会社**——名义上的国际合资，实为朝鲜国家资本控股 |
| 2053年 | 首款产品"沙子飞猪号"量产（千里马牌）；同年"金正恩大沙子型"坦克下线，军用产品线成立 |
| 2056年 | 民用载具首次使全球铁路客运量下降34% |
| 2063年 | 第二代载具矩阵发布：沙驴号（通勤）、沙鸡号（紧凑）、沙牛号（货运）、沙熊号（SUV）——"让每个家庭都买得起沙能车"运动 |
| 2068年 | 借助铁路私有化浪潮，收购全球17家濒临破产的铁路客运运营商资产 |
| 2072年 | 全球铁路停运后，宣布沙能覆盖率达95%，成为事实上的全球交通垄断企业 |
| 2076年 | 现任CEO周鼎铭（会社长），48岁；第三代载具"沙鲸计划"研发中 |

### 1.2 企业结构与子母公司体系

**对外（国际）架构**——注册地为卢森堡→后迁平壤的国际控股层，国际报道只见此层：

```
联合沙能科学技术会社（USET，名义国际合资，实际朝鲜国家资本控股）
├── 千里马民品公司（国际分部）  ← 飞猪号/沙驴号/沙鸡号/沙牛号/沙熊号
├── USET Defence（国际军工出面壳）← 对外军贸商标；实际生产在朝鲜本土
├── 沙能保障总局（补给网络事业部）← 全球2.3万座补给站，含游戏内补给站
├── USET 亚洲研究分院           ← 与金日成综合大学有合作历史的学术窗口
└── 对外宣传部（全球营销）       ← 广告攻势、免费试乘、价格战的实际执行者
```

**对内（朝鲜本土）关联体系**——由朝鲜国资平台（"一号会社"基金）间接控制的独立法人，不写在国际财报上：

```
联合沙能科学技术会社（国际控股层）
│  持股（通过朝鲜国资平台）
├── 先军国防公社（独立法人）     ← 沙能坦克"金正恩大沙子型"、沙能装甲车
│                                   出厂即移交国防工业体系，境外采购走USET Defence壳
├── 沙能科学研究院（独立法人）   ← 第三代"沙鲸计划"；理事长即平壤总部技术总管
└── 沙能保障总局（国内后勤段）   ← 与补给网络事业部是"两个牌子、一套系统"
```

> **命名解释**：国际层使用通用企业名（民品/Defence/研究院），对内层使用朝鲜惯例名（先军/公社/科学院/保障总局）。"先军国防公社"是朝鲜军工体系的内部建制名，绝不会出现在国际公开架构中——境外看到的是"USET Defence"商标。这一内/外两套体系，正是"名义联合、实为国策"的实体印证。

### 1.3 垄断手段（对应游戏机制）

| 手段 | 游戏表现 |
|------|---------|
| 广告攻势 | 沙能竞争系统"ad_campaign"事件（对外宣传部执行） |
| 免费试乘 | "free_trial"事件，渗透率+3%（对外宣传部执行） |

### 1.4 隐藏设定

- 周鼎铭（会社长）对铁路有私人感情（角色设定：内心有旧铁路记忆）——他可能是收购铁路资产最多的人，也是唯一真心为铁路衰落感到复杂的人。
- 沙能会社名义上是"联合会社"（国际合资），但控股方为朝鲜国家资本——对外宣称"联合"，实际是国策企业。会社内部员工私下称其为"一号会社"。

## 二、沙币货币体系（沙本位制）

### 2.1 货币起源

沙能时代前，世界通行以贵金属锚定的货币体系。2053年沙能商业化后，沙子从普通资源变为战略性能源。2076年，**沙子已成为全球最重要的能源与战略资源**，货币体系随之重构。

### 2.2 沙本位制

> **沙币（Sand Yuan / 沙）**：以沙子为价值锚定的法定货币。1沙币的法定购买力对应于10公斤标准工业沙的标准兑换价值（由国家质量标准局定期发布）。

**兑换关系**：游戏内补给站"1500公斤沙子 = 150沙币"，即1沙币 = 10公斤沙子——这并非打折，而是**沙币与沙子的官方挂钩标准**（1500公斤 ÷ 150沙币 = 10公斤/沙币）。

### 2.3 体系特征

| 特征 | 说明 |
|------|------|
| 发行方 | 朝鲜人民银行（世界最大沙子储量国） |
| 锚定物 | 标准工业沙（国标SB-62） |
| 汇率 | 随季节与开采成本小幅波动（对应经济系统"沙子价格倍率"） |
| 衍生 | 大额沙币（万沙）：1万沙 = 10,000沙，大宗交易专用 |
| 前景 | 早期设定中的"朝币"（1朝币≈50沙）为过渡期货币，2076年已退出流通 |

### 2.4 对游戏的影响

- 解释了为何油价、工资都以"沙币"计价——沙能时代的经济皆以沙为锚
- "沙子价格倍率"难度参数：影响补给站价格，进而影响燃料/补给成本
- 后期经济危机事件可设计为"沙子开采成本暴涨/暴跌"，冲击全系统

## 三、雾峰村的过去

### 3.1 村庄概况

雾峰村位于山谷之中，常年多雾，村名由此而来。村庄以东为矿区山脉，以西为丘陵茶园。铁路是村庄与外界唯一的现代交通联系。

### 3.2 线路历史

| 时间 | 事件 |
|------|------|
| 1950年代 | 雾峰村-矿区线建成通车，最初为矿区运输专线 |
| 1960-70年代 | 铁路带动山区开发，茶山站周边发展为茶叶集散地，矿区站成为煤炭枢纽 |
| 1980-2000年代 | 松桥站扩建为会让站，线路高峰期日开行10对列车 |
| 2050年代 | 沙能载具出现，沿线客流开始流失 |
| 2071年9月13日 | 站长林悍（林彪悍的爷爷）因沙能飞行器事故遇难 |
| 2072年 | 全球铁路停运，线路勉强维持至2076年初，正式停运 |
| 2076年 | 林彪悍接手，故事开始 |

### 3.3 沿线四站（支线剧情基础）

| 车站 | 里程 | 特色 | 故事潜力 |
|------|------|------|---------|
| 雾峰村站 | 0km | 始发站，村庄口 | 主角故乡、老陈驻地 |
| 茶山站 | 8km | 茶叶集散地 | 茶农（老人C在松桥站等车运茶）、季节采摘加班车 |
| 松桥站 | 15km | 会让站，已废弃 | 通勤主线、老人晒太阳、茶叶运输受阻的痛点 |
| 矿区站 | 23km | 煤炭/矿石枢纽 | 矿工上下班、货运需求、沙能竞争最激烈处 |

### 3.4 产业

- **茶叶**：雾峰村山谷梯田茶园，春季采茶季客流高峰；茶农是客流基本盘（对应季节系数公式）
- **矿区**：小型煤矿与石矿，货运需求来源；矿业受沙能载具（沙牛号）冲击最大
- **人口**：约8,000人，老龄化严重（年轻人多已外出——对应"代际断层"机制）

### 3.5 爷爷林悍

> 林悍，雾峰村末代站长。曾在2070年铁路事故频发期，以个人名义为线路安全担保，使雾峰村线免于被强制停运。2071年，在一次沙能飞行器事故中遇难（设定中未详述——可留作后期剧情悬念）。遗愿：守护雾峰村铁路线。

## 四、大废线后的铁路私营化法案

### 4.1 法律背景

2072年全球铁路停运后，各国政府面临同一问题：**大量废弃线路无法维持国有运营**。各国先后通过立法，将铁路资产"还权于民"。

### 4.2 《铁路委托运营条例》（2073年）

**民情背景**：大废线后国家把铁路承包给了个人——这是玩家身份的法律基础。

| 条款 | 内容 |
|------|------|
| 第一条 | 废弃铁路线可申请委托运营，申请人自负盈亏 |
| 第三条 | 委托运营期间，线路资产所有权归国家，运营权归受托人 |
| 第五条 | 国家提供基础运营补贴（对应"基础补贴"8,000沙/月） |
| 第七条 | 连续90天无运营记录的委托将被撤销 |
| 第九条 | 受托人享有线路广告、站台商业等衍生收益 |

### 4.3 政治含义（对应政治系统）

- 市长（陈鹤年）、铁路监督员（赵铁山）是条例的实际执行者与监督者
- 补贴金额与运营评估挂钩——市长的政治倾向（威权/市场/福利）直接影响评估标准
- "线路被政府征收/转包"是不可逆事件的法律依据（政治压力>0.70时触发）

### 4.4 国际对照

| 国家 | 处理方式 |
|------|---------|
| 朝鲜 | 《铁路委托运营条例》，个人可承包废线 |
| 日本 | 各都道府县铁路公司解体，38县亏损后转为地方委托 |
| 欧洲 | DB/SNCF将乡村线路承包给私人运营商 |
| 英国 | 早在20世纪末完成私有化，成为此轮浪潮的模板 |

## 五、岁月AI的技术悬案

### 5.1 现已知事实

- 0721号沙子飞猪号搭载的AI原型，2053年制造，沉睡23年
- 量产版沙能车只有基础导航功能，无法对话
- 岁月自己说："也许是因为成本太高，也许是因为人们不需要会聊天的车，也许是因为我太特别了"

### 5.2 悬案设定（存档为长期伏笔）

关于"为何全世界只有一台会聊天的AI"，存在三种解释，真相不公布：

| 版本 | 内容 | 真相度 |
|------|------|--------|
| 官方说法 | 成本过高，无法量产 | 部分真实 |
| 技术传闻 | 强AI程序在工程上无法复制——岁月是偶然的突破 | 部分真实 |
| 政治传闻 | 能自由对话的AI被认为"不稳定"，项目被叫停，岁月被封存而非销毁 | 待揭示 |

### 5.3 关键悬念

- 被封存的岁月是"特批保留"——当年研发团队中有人顶住压力保住了它
- 0721号被保留给金日成综合大学做研究，23年后恰好被主角继承——**巧合与否，未定**
- 后期路线：岁月可能成为玩家对抗沙能、竞逐"第三代AI交通运输"的智力资本

### 5.4 游戏影响

- 岁月是VN系统的AI角色，也是玩家最忠诚的"配角"
- 中期可触发"岁月的记忆"支线：调查自己的身世
- 终极目标之一"改变世界历史走向"可与岁月身世之谜绑定

## 六、铁路文化传承

### 6.1 背景

在铁路衰落的大时代里，仍有少数人坚守铁路文化。他们是玩家的精神盟友与后期内容来源。

### 6.2 文化组织

| 组织 | 国家 | 活动 | 游戏影响 |
|------|------|------|---------|
| 铁路浪漫协会 | 日本 | 保留旧线路摄影、铁道迷集会 | 提高乘客美感/旅游线客流 |
| 国际铁路遗产联盟 | 欧洲 | 旧车收藏、博物馆运营 | 解锁"铁路博物馆"终极目标 |
| 老铁路工人联合会 | 全球 | 技术传承、事故记忆 | 培训加成、安全文化 |
| 铁路之友协会 | 雾峰村 | 村民自发支持铁路 | 剧情补贴来源（+5,000/次） |

### 6.3 铁路博物馆（终极目标）

> 条件：好感度>90解锁。将雾峰村站改造为铁路博物馆，收藏：NF-5耕牛（准文物）、历史时刻表、林悍站长遗物、铁路浪漫协会捐赠的旧车厢。博物馆本身提供持续的文化收入与声望——这是玩家重建铁路文化地位的最高成就之一。

### 6.4 对应机制

- 经济系统"文化传承"终极目标（好感度>90解锁铁路博物馆）
- 旅客支线剧情：退休铁路工人（运营>20天触发）传授铁路精神
- 新闻事件：媒体正面报道（好感度>80时10%概率）

## 七、第三代沙能载具伏笔

### 7.1 新闻宣发

> 2072年朝中社：第三代沙能载具正在研制中，预计将于近期发布。

### 7.2 伏笔设定

| 要素 | 内容 |
|------|------|
| 研发代号 | "沙鲸计划"（Project Sand Whale） |
| 已知功能 | 官方宣称解决"重载运输能力有限"与"长途续航不足"两大弱点 |
| 未公开信息 | ①试车事故指标高于宣传水平；②依赖战略级沙子储备——对储量小的国家是隐患；③成本极高，仅规划军用与干线货运 |
| 预计面市 | 2077年（游戏时间一年后） |

### 7.3 对游戏的影响

- **时间压力**：第三代载具若成功，将彻底封死铁路复兴的最后空间——玩家需在2077年前建立铁路的不可替代性（完成区域扩张/科技树分支）
- **中期事件**：可设计"沙鲸计划泄密""试车事故"等剧情，动摇公众对沙能的信任
- **弱点延续**：即使第三代载具面市，其"夜间运行效率低""依赖沙子供应"弱点仍在——铁路仍有生存窗口
- **终极博弈**：玩家终极目标"沙能渗透率<30%改变世界历史走向"，可与沙鲸计划的成败形成对照
