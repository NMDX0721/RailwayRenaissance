# ATO 第一阶段 3D 试验线路制作要求

2026-11-05。第一阶段建议采用下列制作规格，供李海宣制作轨道、Codex 接入控制与验证。尺寸来自现有模型及源码，线路布局为本轮建议。

列车的尺寸、装配坐标、活动层级和操纵件要求见 [列车模型接入要求](ATO列车模型接入要求.md)。

## 首版布局

采用水平单线直轨，里程范围建议 s=-60 至 s=1200 米。车辆任务起点为 s=0，目标停车点为 s=900，终点之后保留 300 米。模型可分为 25 或 50 米的重复模块，避免把整条线及轨枕做成大量独立活动物体。

首版不设置坡度、超高、道岔。后续曲线、坡度实验需要同步提供路线数据，并接入模拟环境输入。

## 尺寸与坐标

| 项目 | 制作要求 |
| --- | --- |
| 单位 | 导入 Unity 后 1 单位等于 1 米，根节点缩放为 (1,1,1) |
| 轨距 | 两轨内侧净距 1.435 米 |
| 现有轨头宽度 | 0.065 米，对应两轨中心距 1.500 米 |
| 模块原点 | 起点轨道中心线、轨顶面，局部 Y=0 |
| 模块正向 | 局部 -Z，里程随前进增加；+Y 向上，X 为横向 |
| 轨顶 | 两轨等高，轨腰、轨底、轨枕和道床向下制作 |
| 参考轨枕 | 现有生成器采用长 2.6 米、沿线宽 0.24 米、高 0.106 米、间隔 0.6 米，可先沿用 |
| 层级 | 轨道、轨枕、道床、站台、标志、里程参考点分别组织 |
| 材质 | 提供轨钢、轨枕、道床独立材质槽，便于统一 Unity 材质 |

现有车辆使用约 0.461222 米有效滚动半径。当前检查线轨顶世界 Y=-1.3612222，里程零附近还有 Z=8.6 的模型偏移。这些属于旧检查场景的装配坐标。新模块按上述局部原点交付，由程序接入时进行坐标换算。

## 标记与交付

提供 FBX 或 Unity Prefab，以及以下空节点或同名清单。

- RouteStart，任务起点 s=0。
- StopTarget，目标 s=900，第一阶段用模拟后端 PositionM 所表示的车辆参考点对齐，车头停车标的外观位置另行换算。
- RouteEnd，s=1200。
- 里程标记 s=250、650、900，便于核对运行录像和日志。

标准任务现有分段限速为 0–250 米 12 m/s（43.2 km/h）、250–650 米 18 m/s（64.8 km/h）、650–900 米 10 m/s（36 km/h）。标牌用于对应任务数据。实际速度限制由控制和模拟逻辑执行。

第一版可先交付轨道和标记，站台及沿线景观随后补充。站台尺寸需结合车辆轮廓、登车结构和停车参考点单独检查后确定。

## 程序接入与验收

当前 CabReviewTrack 的生成区间为 -60 至 500 米，CabRailMotion 会根据该终点请求紧急制动，NF5KRailMotionReview 的道床生成还包含固定 560 米长度。新线接入需要同步处理采样区间、网格区间、道床长度与末端保护，并将路线中心线作为车辆循迹和轨道几何的共同来源。

验收至少完成以下检查。

1. 后端有符号 PositionM 驱动车体、转向架与车轮，停稳后轮相位固定，恢复检查点后位置一致。
2. 正常逐帧 Play 运行 900 米任务，末端保护没有在 500 米附近错误介入。
3. 记录三种控制目标的停车误差、速度违规、普通制动切换间隔、人工干预及实际停车位置。
4. 实际操作人工接管、暂停、恢复，核对界面、日志和车辆状态。
5. 检查轮轨贴合、车辆与站台净空及跟随视角，保存截图或录像。

既有自动化测试中的 Advance 循环用于验证固定步模拟和检查点。完整 3D 接入验收还需要正常帧循环覆盖 LateUpdate 的姿态投影与末端保护。
