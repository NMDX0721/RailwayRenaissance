# 登车梯收纳与站台接驳

2026-10-22。用户要求登车梯可收起并适配站台。当前为待实现的机构与系统设计，不代表已具备收纳、站台检测、桥板或行车联锁。

| 状态 | 设计要求 |
|---|---|
| 地面登车 | 停稳后展开梯级，提供连续握持位置，锁定后才允许攀登 |
| 行车收纳 | 收进预定包络并机械锁定，确认到位后允许牵引 |
| 高站台接驳 | 收起可能与站台干涉的下部梯子，检查门槛高差与横向间隙，再使用门槛或接驳板 |
| 低站台接驳 | 按实际台面高度选择梯级/桥板，检查展开路径与人员通道 |
| 故障/位置未知 | 反馈阻断原因，不能以动画播放结束代替锁止信号 |

先选定折叠或伸缩机构、铰点/导轨、驱动及锁止，再验证实际收纳空间。不能直接把梯子转进车体或隐藏网格冒充收纳。车壳、转向架摆动与站台限界共同约束外伸范围。

站台侧别、轨面/台面高度、车门里程、横向间隙与停车误差由线路/站台数据提供。高/低站台相对于车辆地板及机构行程判断，不硬编码所有站台的统一高度。没有站台数据时不得假定接驳可用。

展开/收起/接驳接入既有场景交互面板；提示阻断原因，快捷键可选。小黄鼠未来代操作也必须经过停稳、侧别、扫掠与到位锁止检查，并记录驾驶事件。

本轮只修正固定展开状态的四级攀登梯、扶手和靴子空间。它需要面向车体攀登，不能当作普通直立步行楼梯。完整上下梯动画、身体/手脚IK、不同身材可达性、结构强度、收纳扫掠和真实站台验收仍未完成。
