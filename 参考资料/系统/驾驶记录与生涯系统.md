# 驾驶记录、行程回顾与生涯

2026-10-21：用户确认需要记录驾驶数据，驾驶结束展示回顾面板，计入生涯；参考《模拟火车世界6》。本文是待实现规格，不表示已有记录器、面板或生涯存档。

## 参考范围

[TSW6 官方 FAQ](https://support.dovetailgames.com/hc/en-us/articles/29015339200914-Train-Sim-World-6-FAQ)介绍训练、情景、时刻表与 Journey Mode 的驾驶生涯组织方式；[2026年7月官方更新](https://live.dovetailgames.com/news/train-sim-world-6-patch-notes-july-2026)包含部分线路白金奖牌评分更新。参考其行程表现与长期进度的组织思路，不宣称下列字段、公式或面板与 TSW6 完全相同。

## 一、驾驶数据

- 身份：唯一行程ID、存档/生涯ID、世界种子、线路与车次、车辆/编组、模拟与规则版本、开始/结束游戏时间、结束原因。
- 运行：模拟驾驶时长、暂停之外的运行/停车时间、绝对累计里程、线路位置、速度、加速度、牵引/制动指令及实际作用、转速、气压、温度、耗油。未来电力车型单独记录耗电及回馈，不把机械输出能量当作购电量。
- 任务：各站计划/实际到发时刻、停车误差、停站完成状态；限速、超速持续时间及幅度、信号违规、故障与处置。没有线路/时刻表/信号判据时标记“暂不可评价”，不能生成虚假满分。
- 辅助：提示开关、辅助等级变化，动作发起者（玩家/小黄鼠/岁月/自动保护）、委托和接管时刻；自动保护与主动委托分别统计。
- 事件精确记录模拟tick；曲线以候选5Hz采样并保留关键事件前后数据，采样频率后续按性能评估。不要每帧写盘。暂停不增加驾驶时长；倍速按模拟时间积分，现实游玩时长另记。

## 二、结束后的回顾面板

1. 总览：完成/中断/失败、路线、车辆、里程、时长及辅助使用情况。
2. 运行曲线：速度与当时限速叠加，可切换牵引、制动和气压；点击事件定位到对应时间，非承诺3D录像回放。
3. 站点明细：准点、停准、停站及旅客作业；容差来自任务规则，不统一硬编码。
4. 驾驶评价：安全、准点、平稳、节能和操作规范分别说明依据。紧急制动按事件原因解读，不因使用一次直接扣分；平稳性采用过滤后的加速度变化，阈值待标定。
5. 岁月复盘：用真实事件给出少量可执行建议；文字模型不得编造数据或决定计分。
6. 生涯变化：本次新增里程、经验/资历、车型和线路熟练度、里程碑，数值规则另行确认。

## 三、生涯与经营

生涯归属规则待确认，首选随角色/存档隔离，训练记录可另设个人档案。累计完成班次、驾驶里程、时长、线路与车型经历，保存历史行程与成长趋势。辅助模式同样记录贡献，并明确辅助条件；不默认把简单模式经验清零，也不混排不同辅助条件的技术成绩。

一次行程仅结算一次。行程ID去重、原子落盘；中断记录保留，继续驾驶沿用原行程ID。读检查点产生明确恢复分支，只将最终采用分支入账，禁止重复加载累加里程/经验。回顾页再次打开不得再次结算。

驾驶结果可向经营层提交已完成服务事实，但车票收入、燃油成本和每日结算的归属必须统一，避免与 GameData.AdvanceDay 重复记账。不得外显政治压力或线路老化数值。开发审阅场景、调试速度、测试行程不计正式生涯。

## 四、对现有后端的接入计划

现有 CabSimulation 是20ms固定步长内核，已具备速度、位移、绝对里程、气压、温度和燃油等状态，但没有完整驾驶日志。后续在固定步完成后采集只读状态，控制入口记录命令与来源，任务层补充站点/限速/信号事件。

分为记录器、行程报告、确定性评价器和生涯仓储；报告保留评价规则版本及原始依据。先实现测试行程录制和基础回顾，再接正式任务与生涯保存。状态曲线、确定性输入回放和完整场景录像是三种不同能力，不混称已支持。

验收覆盖：不同帧率统计一致、暂停/倍速正确、存读档连续、辅助接管归因、缺失判据显示不可评价、中断与完成区分、重复结算幂等、恢复分支不重复记账、记录损坏不覆盖正常生涯、测试场景不污染正式存档。
