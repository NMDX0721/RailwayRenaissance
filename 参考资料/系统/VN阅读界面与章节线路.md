# VN 阅读界面、章节线路与逐句配音

2026-11-03，按用户两张手绘稿实现。沿用现有背景、立绘、第一人称叙述及逐句对齐的多语言字幕。

## 布局与交互

- 右上 Auto / Menu 保持原有 88×40 比例。展开后只展示回顾、跳过、退出三个图标；每项 40×40，内图标 24×24，中文仅作悬停提示。信号灯开关只在设置中。
- 书签移到角色姓名左侧；有音频时依次为重播、书签、姓名。旁白仍可收藏，旁白不展示姓名、重播或语音进度。
- 姓名区下方为本句语音进度，可拖动。缺少已审核音频、男主及内心独白均隐藏语音控件。
- 底部为章节风景轨道，列车沿轨道移动，终点有到站旗；沿用现有已到达区间内的点击/拖动跳转规则。拖动中不连续启动音频，松手后再绑定停留句。
- 倍速徽标改为双前进折线与轨道下划线，保留 ×2。沿用文字快进逻辑，未实现保持音高的配音倍速处理。
- Windows 的风景带高 18 UI 单位，**独立放在对话框外、对话框与屏幕底线之间**；正文底边与条顶边紧贴，条底边贴屏幕底线，不另设底板、不嵌入正文、不留空带。中间为长方形主体，前景有独立的左右半圆端盖组件，覆盖风景两端；与对话框共用深棕半透明底色和淡金边。文本框最小高 160，左上信号组件为 72×152。语音为带外框的喇叭标识，与书签外框同规格。
- 主验收锁定常见 2.5K：2560×1440，使用完整 Windows 画幅，不施加模拟的 32 像素安全区。其他画幅与设备后续统一适配，不为平板强行放大 Auto / Menu。

## 日本铁路信号意象

左上为日式五灯信号头，五种现示：绿=进行、黄绿=减速、黄=注意、双黄=警戒、红=停止。灯位采用上至下 Y/Y/R/Y/G 的一种布局。

本系统将现示用于剧情氛围提示，**不控制阅读、选择或列车驾驶**。根据每章人工配置的节奏分段变化，不扫描未读台词，不预告角色身份或具体事件。不表示故事位于日本。显示开关只在设置中的“剧情信号灯”，偏好持久化。信号本体不是可点击按钮。

现示含义参考：[日本民营铁道协会](https://www.mintetsu.or.jp/knowledge/term/16460.html)、[日本信号公司](https://www.signal.co.jp/products/railway/faq/faq05/)。实际打开图片核对：[日本信号公司信号种类图，五灯 A 型](https://www.signal.co.jp/products/railway/faq/faq07/)、[阪急实物照片](https://cdn.hankyu-app.com/content/article/2025/article_04.html)。外观采用圆头黑色背板、凹入镜片和逐灯遮光罩；不是把网络照片直接当游戏资源。

## 正式配音交付

1. 先审定中文台词及稳定 ID，再完成、校对日语翻译。英语沿用同一结构。
2. 配音服务的重要操作仍须逐次向用户申请批准；本次开发未调用 ElevenLabs、未生成角色音色、未消耗配音额度。
3. 配音中的读音替换或提示标签不得写回显示字幕。保存审核过的音频、原始翻译文本、音色/模型/参数与授权记录。
4. 音频导入 `Assets/Resources/Voice/{locale}/{scriptId}/`，逐句清单为同目录 `catalogue.json`。
5. 条目字段：`key` 复用 VNLocalization 稳定 ID/兼容坐标键；`sourceHash` 为中文源文哈希；`textHash` 为该语言已审核字幕原文哈希；`clip` 为同目录下不带扩展名的相对音频路径。
6. 两个哈希均通过才播放；缺少对应译文、清单或音频时静默隐藏播放控件。修改中文或翻译后旧音频不会继续误播。
7. 设置中配音语言独立于主、副字幕，支持关闭/日语/中文/英语，默认日语。配音音量独立控制，同时服从主音量。
8. Auto 在原有阅读间隔后等待本句语音完成；重播/音频定位会重新安排 Auto。面板、菜单、隐藏 UI 和失焦时暂停，返回后继续。手动推进则中断上一句。男主、旁白、内心独白不配音。

```json
{
  "entries": [
    {
      "key": "prologue_02_day0/s1/d15",
      "sourceHash": "由 VNLocalization.Hash 计算",
      "textHash": "由 VNLocalization.Hash 对审核后日文计算",
      "clip": "suiyue_001"
    }
  ]
}
```

这是格式示意，不是可播放的正式条目。本轮不附冒充角色配音的测试音频。
