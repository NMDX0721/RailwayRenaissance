## 〇、来源说明头（读表前必读）

本表依《后续任务规划.md》§8.1 模式 3「**四列年表 + 双来源勘误**」（范式原型：《X 百科全书》CE 纪年 | NT 纪年 | 事件 | 对应游戏 年表）重构，v1.0 的「时间 | 世界事件 | 角色/剧情事件 | 来源」四列在此**列重组**为「纪年 | NT 纪年 | 事件 | 对应游戏章节」，原表全部事件一条不删。

1. **四列定义**
   - **纪年**：项目现行的公元纪年（20xx 年），即 v1.0 的「时间」列。
   - **NT 纪年**：项目自有纪年占位列。**NT 纪年待设定补充**——已在 `参考资料/设定` 与 `参考资料/引擎` 全目录检索「纪年 / 新纪元 / NT纪 / 公元 / 纪元」，除本方法论条目外**无任何双纪年体系设定**（既无 NT 纪年定义，也无与公元的换算式），故本列暂统一填「—（待设定）」，不擅自编造换算。设定侧补上 NT 纪年后，按本列回填即可。
   - **事件**：原「世界事件 | 角色/剧情事件」两列合并为一列，行内以 **【世界】/【角色】** 前缀保留来源类别，信息不丢失。
   - **对应游戏章节**：对齐 `Assets/Resources/Scripts/prologue_*.json` 实际脚本（章节名取自 `剧情/plot-outline.md` §二 的章节表与 JSON 文件名）。
2. **章节代号对照（prologue_xx 短名，取自脚本文件名 + plot-outline）**

   | 章节 | 短名 | 章节 | 短名 |
   |------|------|------|------|
   | prologue_01 | 新闻（冷开场·世界背景） | prologue_06 | 团队集结 |
   | prologue_02 | Day 0·出发 | prologue_07 | 首修（喷油嘴） |
   | prologue_03 | 旅途 | prologue_08 | 首班车 |
   | prologue_04 | 抵达雾峰（归乡） | prologue_09 | 负债（资金筹措） |
   | prologue_05 | 巡线 | prologue_10 | 交棒·过渡经营 |

3. **双来源勘误标注规则**
   - **设定来源**（世界观与车辆设定 / 世界观扩展设定 / 角色设定 / 序章剧本 / README）与**脚本来源**（prologue_*.json 实际台词）逐行交叉核对；
   - 两方一致 → 正常记录；两方表述有出入 → 行内标 **「勘误：」**；日期本身证据不足或与别处冲突 → 行内标 **「存疑」**；
   - 「—」＝ 该事件目前**未进入任何序章脚本**（或该行无对应章节），不代表事件不成立。
4. **行内来源标记**：原表最右「来源」列的内容压缩为行尾 **〔源：…〕**，避免挤占四列结构；来源列本身不再单列。

## 二、2071年9月13日合理性校验

### 2.1 核对基准

| 基准事实 | 数值 | 来源 |
|---------|------|------|
| 林彪悍出生年 | 2051年 | 角色设定 §一 |
| 游戏开始年 | 2076年 | 世界观设定 |
| 主角游戏开始年龄 | 25岁 | 角色设定 §一 |
| 老陈守护年限 | "我守了四年" | 序章剧本 老陈台词 |
| 爷爷去世年 | 2071年（原文） | 角色设定 §六（本期补全月日） |

### 2.2 推导校验

1. **年龄自洽**：2051年生 → 2076年 = 25岁 ✅（与角色设定一致）
2. **2071年主角年龄**：2051 + 20 = **20岁**。2071年时林彪悍约20岁，正值金日成综合大学本科求学阶段（荣誉研究生须本科毕业，合理）。✅
3. **日期季节**：9月13日属初秋——**采茶季已过、秋收未至**，非农忙期，与"时任站长因意外去世"的宁静悲剧感相容。✅
4. **与2072年停运衔接**：爷爷2071年9月去世 → 老陈接手 → **2012历法推算：2072年全球停运后"守了四年"= 2072-2076年** ✅（老陈台词"我守了四年，实在守不动了"完全吻合）
5. **与2070年担保事件的时序**：2070年林悍以个人名义担保 → 2071年9月意外去世 → 担保人缺席 → 该线在2072年停运潮中"勉强维持"——**担保失效是雾峰村线走向停运的重要伏笔** ✅

### 2.3 结论

> **2071年9月13日通过全部校验**，且与"2070年担保 → 2071年去世 → 2072年停运 → 老陈守四年 → 2076年主角归来"的叙事链条无缝衔接。9月13日设定合理，予以保留。

### 2.4 注意点

- 2071年主角20岁，**此时期主角应在平壤读本科**——剧本中"爷爷遗愿""夹克遗产"等回忆内容的时点需保持在此之前的童年/少年时代（2051-2070年）。
- 岁月2071年仍沉睡于0721号载具中，与主角无交集——首次相遇到2076年序章。
