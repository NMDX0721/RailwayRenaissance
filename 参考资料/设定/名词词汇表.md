| 雾峰村站 | 雾峰村线0km始发站，同时是青溪线0km起点的**两线交汇站**（站番号 雾1／青1），主角故乡、老陈驻地。 | 世界观与车辆设定.md §五（交汇站与站番号）、世界观扩展设定.md §4.3 |
| 雾峰村线 | 全称"雾峰村-乌金岭线"，23公里支线，讫点乌金岭市（站设于矿区，故名矿区站）；剧本通称雾峰村线（오봉촌선），辖内四站：雾峰村—茶山—松桥—矿区。 | 世界观与车辆设定.md §五、世界观扩展设定.md §4.3 |
| 青溪线 | 全称"雾峰村-青溪镇线"，45公里，与雾峰村线共用雾峰村站为0km起点，外侧首站分水岭站（约10km）；Day 60 解锁运营。 | 世界观与车辆设定.md §五、世界观扩展设定.md §4.3 |
| 茶山站 | 雾峰村线中间站（8km），茶叶集散地；春季采茶季为客流高峰，茶农是客流基本盘。 | 世界观与车辆设定.md §五、世界观扩展设定.md §4.3 |
| 松桥站 | 雾峰村线15km处的**会让站，已废弃**；列车需减速通过或检查，是通勤主线与茶叶运输受阻的痛点所在（2074年补票室火灾后铁龙基金会曾二次上门）。 | 世界观与车辆设定.md §五、世界观扩展设定.md §2.7、§4.3 |
| 矿区站 | 雾峰村线终点站（23km），煤炭/矿石枢纽，货运需求来源，也是沙能竞争最激烈处。 | 世界观与车辆设定.md §五、世界观扩展设定.md §4.3 |
| 乌金岭市 | 矿区站所在城市（人口约4,000），即"雾峰村-乌金岭线"的讫点。 | 世界观与车辆设定.md §五（命名对齐） |
| 分水岭站 | 青溪线自雾峰村外首站（约10km），位于两水分流的分水垭口——出山入世的地理分界。 | 世界观与车辆设定.md §五 |

|------|--------------|-----------|

| NF-7 犊牛 | 新一代现役主力机车（柴油-交流传动约2,800kW），"牛犊接班"——耕牛→耕牛·改→犊牛的换代命名；逐步替换 NF-5K。 | 世界观与车辆设定.md §四（架空车辆族谱） |
| SY-22 灰雀 | 短途支线客车（载客30人），现役旧车厢；鸟线命名体系的起点（灰雀→雨燕）。 | 世界观与车辆设定.md §四（客车：SY-22 灰雀） |
| SY-30 雨燕 | SY-22 灰雀的后继支线快车（40人，轻量化），取"雨燕（swift）"鸟线命名。 | 世界观与车辆设定.md §四（架空车辆族谱） |
| 沙子飞猪号 | 第一代沙能飞行汽车（2053年商用）：可瞬间转飞行模式，载2人，补给1500公斤沙子续航1000公里。 | 世界观与车辆设定.md §二、§三 |
| 0721号沙子飞猪号 | 2053年制造的第一代试验车（深蓝色，金日成综合大学校徽），2053-2076封存23年；岁月AI苏醒后第一个接入的节点。 | 世界观与车辆设定.md §三 |
| 沙驴号 | 第二代沙能地面通勤车（2063年推出）：不能飞行、4座、售价为飞猪号的1/5，"让每个家庭都买得起沙能车"。 | 世界观与车辆设定.md §二 |
| 沙鲸计划 | 第三代沙能载具研发代号（Project Sand Whale），官方宣称解决重载与续航两大弱点，预计2077年面市；未公开信息包括试车事故与高成本。 | 世界观扩展设定.md §九 |

| 小米平板（Xiaomi Pad 36 Ultra） | 2053年小米最后一代旗舰平板，随0721封存于金日成综合大学仓库；2076年主角在0721储物格发现全新未拆封品，与岁月共享所有权，模拟经营主界面即其系统桌面。 | 世界观扩展设定.md §8.3、§8.4.2 |

## 五、经济

| 词条 | 释义（一两句） | 出处/语境 |
|------|--------------|-----------|
| 沙本位（制） | 以沙子为价值锚定的货币体系：2053年沙能商业化后沙子成为战略能源，2076年货币体系随之重构，全球经济皆以沙为锚。 | 世界观扩展设定.md §三、沙本位经济核.md（全篇） |
| 沙币 | 沙本位法定货币（Sand Yuan，单位"沙"）：1沙币=10公斤标准工业沙的官方兑换价值（1500公斤沙子=150沙币的全球统一官价）；发行方为朝鲜人民银行。 | 世界观扩展设定.md §3.2-§3.3 |
| 标准工业沙（国标 SB-62） | 沙币的锚定物，也是沙能载具真正的"燃料凭证"基础；补给站就地消耗本地沙子，但须持有提炼权配额。 | 世界观扩展设定.md §3.3、§3.3.1 |
| 提炼权配额（sand quota） | 每座补给站必须持有的"沙能提炼权"，由沙能保障总局按年发放；载具每消耗一公斤沙子都对应一笔沙币回流朝鲜。 | 世界观扩展设定.md §3.3.1 |
| 沙能渗透率 | 铁龙竞争系统的核心变量，每城市独立维护（0-1），初始0.15；渗透>0.60持续15天会在该城建立USET永久营业点，>0.60可触发"收购要约"事件。 | 引擎/铁龙竞争系统.md §5.1、世界观扩展设定.md §2.8 |
| 五条趋势线 | 经济核的长期状态指标：资金、信任、车况、客流、沙能渗透（另设计政治压力、设施老化两条，暂缺代码映射）。 | 沙本位经济核.md §0.1 |
| 基础补贴 | 国家对偏远地区铁路的最低扶持（8,000沙币/月），出自《铁路委托运营条例》第五条，与运营评估挂钩。 | 沙本位经济核.md §6.1、世界观扩展设定.md §5.2 |
| 剧情补贴 | 由剧情任务发放的阶段性补贴（如序章30,000沙币启动资金），前期是生存关键、随进程递减；"剧情是生命线"。 | 沙本位经济核.md §7.2、§7.5 |
| 沙子价格倍率 | 难度参数，影响补给站沙价；其世界观含义是提炼权配额发放量的波动（配额收紧→沙子涨价）。 | 世界观扩展设定.md §3.3.1、§3.4 |
