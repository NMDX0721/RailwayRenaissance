## 五、与MiMo Code协作规范

### 工作流程
1. 发现问题 → 向MiMo Code提问，了解问题根因和当前实现
2. MiMo Code回答 → 分析答案，理解技术细节
3. 提出解决方案 → 与用户确认方案和参数
4. 用户确认 → 写最终提示词（描述需求和参数，不写代码）
5. 发送给MiMo Code → 等待实现结果

### 关键原则
- 写提示词前必须先获取当前代码的实际值，不能猜测
- 目标值就是我们要实现的效果
- 提示词格式：当前值 → 目标值（基于实际代码）
- 如果不知道当前值，必须先询问MiMo Code获取
- 不要给MiMo Code全部代码，提示词描述需求和参数即可
- 分阶段交付任务，不要一次给太多
