## 使用说明

1. **优先级**：P0 > P1 > P2 > P3，先做P0/P1保证游戏能跑
2. **生成方式**：将英文提示词输入AI绘图工具（Midjourney/Stable Diffusion/DALL-E）
3. **参数建议**：Midjourney加 `--style raw`，Stable Diffusion用pixel art LoRA
4. **导出处理**：用PS/GIMP去除背景，保留透明通道
5. **命名规范**：`类别_名称.png`，如 `icon_coin.png`、 `weather_rain.png`
