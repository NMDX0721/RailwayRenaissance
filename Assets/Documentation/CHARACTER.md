# 铁路复兴：沙能冲击 - 角色档案 v1.0

## 世界观背景
- **时代**：2076年，大废线末期
- **核心冲突**：沙能科技公司（2050年发明沙能载具）导致大废线，铁路被淘汰
- **玩家使命**：继承爷爷的废弃铁路，肩负复兴使命

## 主角

### 林彪悍（Lin Biaohan）
- **年龄**：25岁
- **身份**：铁路复兴继承者，大学刚毕业
- **毕业院校**：金日成综合大学
- **性格特征**：倔强、青涩、充满希望但经验不足
- **外貌特征**：
  - 脸型：略圆的椭圆脸，下巴柔和，有婴儿肥
  - 眼睛：大而圆的深棕色眼睛，外眼角略微下垂，看起来无辜清澈
  - 眉毛：自然弯曲的温和眉毛
  - 鼻子：小巧圆润的鼻头，鼻梁精致，右脸颊有淡淡的小痣
  - 嘴唇：略微厚实的嘴唇，嘴角自然上扬
  - 头发：蓬松的黑色短发，略带自然卷，刘海不规则，像刚睡醒用手抓过
  - 皮肤：白皙暖色调，左手腕内侧有淡淡的粉色疤痕
- **服装**：
  - 外套：从爷爷那里继承的深海军蓝色工作夹克，略显空荡，左胸口袋别着圆珠笔，拉链头磨得发亮，右下摆有油渍
  - 内搭：白色圆领T恤，领口略微松弛但干净
  - 配饰：铜色怀表链从夹克领口露出
  - 裤子：深蓝色牛仔裤，裤脚在脚踝处堆叠
  - 鞋子：旧棕色皮鞋
- **已有立绘**：✅（动漫风格）
- **角色关系**：陈守正的关门弟子，与陈鹤年有理念冲突，受赵铁山暗中帮助

## 核心角色

### 陈守正（Chen Shouzheng）- "老陈"
- **年龄**：68岁
- **身份**：最后一任站长，主角的导师
- **性格特征**：温暖、朴实、怀旧、固执但善良
- **外貌特征**：
  - 脸型：方脸，深色皮肤布满皱纹但依然硬朗
  - 眼睛：深棕色，笑时眯成温暖的缝，严肃时显得遥远
  - 眉毛：稀疏的灰白眉毛，修剪整齐
  - 鼻子：扁平鼻梁，圆润的红色鼻头（冻伤）
  - 嘴唇：厚实，嘴角略微下垂
  - 头发：灰白短发梳理整齐，左耳后有一撮不听话的头发翘起
  - 手部：右手食指关节因多年拧螺栓而略微肿大
- **服装**：
  - 衬衫：白色长袖棉衬衫，领口和袖口磨损，第二颗扣子用不匹配的红线缝过
  - 背心：深灰色V领毛线背心，左胸口袋区域起球，下摆有明显的织补痕迹
  - 配饰：老花镜挂在脖子上的旧皮绳上
  - 裤子：深色宽松长裤，有熨烫的折痕
  - 鞋子：黑色布鞋，鞋底磨损
- **角色关系**：主角的导师，对铁路有深厚感情，见证过大废线

- **外貌特征**：

  - 鼻子：高鼻梁，薄鼻翼
  - 嘴唇：薄，习惯性紧闭
  - 头发：乌黑短发向后梳理整齐，鬓角干净，但发际线有几根灰发
  - 皮肤：白皙室内肤色
- **服装**：
  - 西装：深炭色合身西装外套，精确剪裁，左袖露出1cm衬衫袖口
  - 衬衫：浅蓝色棉质衬衫，领口挺括，第一颗扣子故意解开显得亲和
  - 配饰：妻子送的简约银色袖扣，左腕 vintage 机械手表（皮表带磨损）
  - 裤子：深色西裤，笔挺的裤线
  - 鞋子：黑色亮面皮鞋
- **角色关系**：与主角有理念冲突，但内心有旧铁路记忆
