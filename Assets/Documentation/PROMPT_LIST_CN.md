## 透明背景要求（重要！）

**所有AI生成的素材必须满足以下要求**：
1. 背景必须是透明的（不是白色、灰色或棋盘格）
2. 输出格式为PNG with alpha channel
3. 如果AI工具不支持透明背景，需要后处理去除背景
4. 验证方法：在图片查看器中打开，背景应显示为黑色或透明
