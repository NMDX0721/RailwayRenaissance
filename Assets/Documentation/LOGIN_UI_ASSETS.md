# 登录界面 UI 素材提示词 v2

## 风格统一要求
- **风格**：复古像素风/手绘风，偏暖色调（棕/橙/米白）
- **背景**：透明背景
- **整体氛围**：怀旧铁路车站感，温暖不冰冷
- **参考风格**：类似《星露谷物语》《泰拉瑞亚》的UI质感

## 使用说明

1. 优先用英文提示词生成，效果更好
2. 每个素材生成3-4张选最好的
3. 导出后去背景保留透明通道
4. 命名：`login_类别.png`，如 `login_panel.png`、`login_input.png`、`login_button.png`
