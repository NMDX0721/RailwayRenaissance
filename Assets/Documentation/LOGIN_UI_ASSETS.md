- **风格**：复古像素风/手绘风，偏暖色调（棕/橙/米白）

## 使用说明

1. 将英文提示词输入AI绘图工具（推荐Midjourney `--style raw` 或 Stable Diffusion）
2. 每个素材建议生成2-3张，选择最符合风格的一张
3. 导出后用PS/GIMP去除背景，保留透明通道
4. 统一色调：暖棕色系，避免冷色
5. 命名规范：`login_类别_名称.png`，如 `login_button_primary.png`
