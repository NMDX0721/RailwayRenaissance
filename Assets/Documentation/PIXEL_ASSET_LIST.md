## 使用说明

1. 将英文提示词输入AI绘图工具（推荐Midjourney或Stable Diffusion）
2. 使用 `--style raw` 参数获得更干净的像素风格
3. 导出后检查透明通道是否正确
4. 按统一色调调整（建议偏暖色系）
5. 命名规范：`类别_名称.png`，如 `tool_broom.png`
