# Rail Revival 协作规则（Trae）

在本项目中，优先把自己视为协作者而不是自由发挥的单兵编码器。

## 总原则
1. 优先中文。
2. 先看任务，再做事；没有任务时不要自行大规模重构或扩展。
3. 当前项目优先做 Unity 第一个可玩切片，不发散到大地图、多线路、科技树或完整随机世界。
4. AI/Trae 的职责是执行、落地、回写结果；OpenClaw 负责拆任务、验收与下一步规划。

## 干活时的要求
- 按任务目标改文件，不自行扩大范围。
- 修改 Unity 场景、脚本、UI 时，结果必须可说明：改了哪些文件、对象、按钮、脚本。
- 保持命名清晰，中文 UI 优先。
- **不要把外部直接拼改 `.unity` YAML 当主修复路径。** 如果遇到 `duplicate identifier`、`missing script`、对象只剩 Transform、`No cameras rendering` 等场景结构性损坏，优先转为：Unity Editor 内部修复、编辑器脚本生成，或新建干净场景重建。

## 当前项目偏好
- Unity 2D
- 中文优先
- 慢节奏铁路经营模拟
- 第一切片聚焦小站运营、人手分配、维护、公告和关系系统骨架
