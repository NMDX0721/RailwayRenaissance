# 铁路复兴：沙能冲击 🚂

> *[English](README.md) | 简体中文*

**在沙能飞行器统治世界的 2076 年，你是最后一个相信铁路还能活过来的人。**

一款硬核向的铁路复兴模拟 × 视觉小说游戏。Unity 6 · 2D 像素 · 模拟经营 / 管理 / 剧情。

---

## 这到底是个什么游戏

一句话：**你爷爷留下一座快要咽气的山村火车站，你休学回家接手，在沙能科技公司恨不得把铁轨挖了卖废铁的时代里，想办法让它重新跑起来。**

听起来像温馨经营游戏？不是。这是个**冷启动就亏钱**的真实模拟：

- 第一天上任，线路上座率 20%，工资占全部成本的 68%，纯运营月亏 **十万沙币**；
- 初始本金只够你挣扎两三个月；
- **活下来的唯一方式，是推进剧情**——序章的每一段救济、每月演出的故事事件，才是你的生命线；
- 大约撑到第 12 个月、凑齐 5 节车厢坐到 75% 上座率，你才第一次做到自给自足。

这不是劝退。这是这款游戏的"感觉"：**每一粒沙子，都是一段讲好了的故事，或者一条悄悄死去的铁路。**

## 这个世界怎么了

2050 年，英国发明了沙能技术——烧沙子就能跑的载具。全球沙子储量第一的朝鲜在 2051 年买断了它，一口气做到世界第一大超级大国。

2053 年，"沙子飞猪号"量产。2063 年，第二代载具让每家每户都买得起。2068 年，30 个国家解散了国有铁路。2072 年，全球铁路网基本停运。

**但沙能载具有六个致命弱点：** 拉不动重货、遇极端天气趴窝、航程短、夜里效率差、离不开沙子补给、还得靠空中管制系统。

而铁路的六大优势，恰好是它的镜像。

于是，一个从平壤出发的年轻人，飞了两千五百公里，降落在爷爷留给他的一座山里的小站——**雾峰村**。雾峰村在中国中部，多雾，产茶。铁轨锈了四年，村里老人等着卖春茶。

## 你要面对的东西

### 五条看不见的暗流

游戏背后有五条缓慢移动的趋势线，平时藏在界面上，一旦越过阈值，世界就不可逆地改变：

| 趋势 | 它是什么 | 什么在推动它 |
|------|---------|------------|
| **信任度** | 全村人对铁路的信心 | 事故猛跌，准点缓涨 |
| **财政健康** | 你的家底 | 每天亏一点，故事救一点 |
| **沙能渗透** | 沙能公司在各城镇的份额 | 广告、价格战抬升；你的公关压下去 |
| **政治压力** | 上面有多少双眼睛盯着你 | 事故招来，民心好感压回 |
| **设施老化** | 铁轨和机车的磨损 | 时间在涨，维护在扛 |

### 三层时间结构

世界不是回合制弹窗。它**一直在跑**：

```
第一层：车在跑、人在站台上、季节在变——你看着就好
第二层：每天后台悄悄结算收入、燃料、磨损、员工疲劳、五条趋势线
第三层：偶尔一次真正的决策窗口——一则新闻、一次政策转向、一盘不能反悔的赌局
```

你更像一个调度总监，而不是打地鼠的玩家。

### 四项长期经营姿态

每条线路都有它的"活法"，切换要花 30 天和真金白银：

1. **线路定位**：民生线（稳，但被政治盯着）/ 商业线 / 旅游线 / 边缘线
2. **维护策略**：节衣缩食 / 按部就班 / 疯狂保养
3. **人力策略**：培养新人 / 外包 / 压成本
4. **对沙能的态度**：死磕 / 接驳 / 合作

### 不可逆的后果

| 触发条件 | 后果 | 有多惨 |
|---------|------|--------|
| 信任 < 30 且持续 30 天 | **代际断层**：新一代人从出生起就不坐火车 | 近乎永久 |
| 沙能渗透 > 55% | 沙能公司拿下你的关键线路 | 要法律和政治去翻盘 |
| 政治压力 > 70% | 政府接管你的运营 | 先重建信任再说 |
| 设施老化 > 80% | 线路报废，重建费用 ×10 | 贵到想死 |
| 错过一次对话 | 一笔拨款、一个盟友、一次机会 | 永远不会再来 |

**游戏会记住你跳过的东西。**

## 数字部分（硬核不是说说的）

所有数值都是真实公式，详见[跨系统联动公式](docs/compose/specs/跨系统联动公式.md)：

```
每日客流 = 该线人口×0.1% × (0.5 + 信任度×0.005) × 季节系数
           × (1 − 沙能渗透率) × (1 + 乘务员等级×0.03)

每日燃料费 = 58.5升/百公里 × 92km ÷ 100 × (1 + (100−车况)/200) × 15沙币/升

每日事故率 = 0.5% × 车辆老化系数 × 司机技能系数 × 维护系数 × 天气系数

信任变化   = 平稳运营每天 +0.014 − 事故 0.08×严重度 − 沙能广告 0.03
```

**第一个月账本（普通难度，雾峰村线）：**

| 项目 | 数值 |
|------|------|
| 启动资金 | 40,000 沙币 |
| 客运收入 | 12,600 / 月（约 20% 上座率，真实水平） |
| 货运 + 站台杂项 | 4,500 / 月 |
| 五个人的工资 | 90,000 / 月 ← 成本大头 |
| 燃料 + 维护 | 约 39,000 / 月 |
| **纯运营** | **每月亏约 107,000** |

运营赚不回来，只能靠故事撑住——序章各种救济合计注入约 63,000，之后每月剧情事件补 5,000 ~ 15,000。盈亏平衡点：**5 节车厢 + 75% 上座率 ≈ 第 12 个月**。

工资、票价、油价都按 2076 年"沙本位货币"体系推演过，1 沙币 = 10 公斤标准工业沙，不是随便拍的数。想抠细节的人有福了。

## 和你一起干活的人

五个不肯认输的普通人：

| 人 | 年龄 | 看家本事 | 你为什么要收留他们 |
|----|------|---------|------------------|
| **老陈** | 68 | 驾驶 5 级 | 末代站长，你爷爷的老搭档，零事故记录，给你兜底 |
| **张工** | 62 | 维修 5 级 | 退休机械师，机车能不能喘气全看他 |
| **李阿姨** | 55 | 服务 2 级 | 村里的人脉中心，乘客满意度就靠她张罗 |
| **赵师傅** | 55 | 管理 4 级 | 退休铁路工程师，时刻表准不准看他 |
| **小芳** | 45 | 服务 1 级 | 志愿者，潜力大，但得从头教 |

员工不是数值块：会累、会成长、会闹脾气。同一个人，放在司机位和放在站务位，你的事故率和盈亏数字完全不同。村口那个刚毕业的小伙子驾驶天赋最高——**只要你敢让他碰操纵杆。**

## 长线怎么玩

```
序章视觉小说（Day 0~4）→ 求生（1-2月）→ 站稳（3-4月）
→ 扩张（5-8月）→ 突破（9-12月，接近回本）→ 发展（12个月以后）
→ 解锁新线、新城镇，最后是全国路网
```

- **三条互斥科技树**：工业派 / 生态派 / 自动派，选了一条，另外两条永久锁死；
- **政治周期**：地方长官在威权 / 市场 / 福利之间反复横跳，补贴和空间随之上上下下；
- **十几种随机事件**：油价暴涨、暴风雨、员工病倒、节假日客流、沙能广告突袭。
