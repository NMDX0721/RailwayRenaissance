世界向铁路谢幕的那一年，某些不可能的事悄悄开始了。

三天之后，一个研究员离开这间屋子，去复兴一条濒临废弃的山村铁路——雾峰村，2,500 公里，一场豪赌的距离。

**每个伟大的故事都需要一个起点，应该就是这里了。**

---

## 特色

- **五条相互咬合的趋势线** —— 信任、财政、沙能渗透、政治压力、设施老化。每条都是地下的暗流，直到越过阈值，世界不可逆地改变。
- **自在运转的世界** —— 列车在跑、站台有人、四季流转。决策很少到来，但每一条都很重。
- **数据驱动的经济** —— 票价、燃料、工资、补贴全部源于一套沙本位货币模型。没有一句糊弄，每个数字都能追溯到文档化的公式。
- **开放的研发网** —— 基建、机车、调度、社会四个方向并行推进、自由组合。没有锁死的分支，没有后悔的分岔路。
- **会打持久战的对手** —— 沙能垄断企业 USET：广告、价格战、收购你的线路，只要你放松。
- **剧情是生命线** —— 前期纯运营注定亏损，叙事及其带来的救济，是铁路撑到你站稳为止的氧气。
- **五名员工，每人四项技能** —— 疲劳、成长、谁坐在哪个座位上，都在改写你的事故算法和盈亏表。

## 快速开始

需要 [Unity 6000.4.6f1](https://unity.com) 与 Git。

```bash
git clone https://github.com/NMDX721/RailwayRenaissance.git
```

在 Unity Hub 中打开文件夹，然后运行：

| 场景 | 是什么 |
|------|--------|
| `Scenes/VN_Test.unity` | 序章视觉小说（Day 0–4） |
| `Scenes/StationSlice_V1.unity` | 车站经营主场景 |
| `Scenes/Login.unity` · `Scenes/TitleScreen.unity` | 入口界面 |
