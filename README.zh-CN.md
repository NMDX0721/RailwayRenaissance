## 世界

这是 2076 年。沙能飞行器终结了铁路——客运量蒸发 78%，91 个国家解散了国有铁路，到 2072 年全球路网事实上已经停运。沙能垄断企业 **USET** 统治着天空；手握全球最大沙子储量的朝鲜，是世界唯一的超级大国。

但沙能载具有六个致命弱点——拉不动重货、闯不过风暴、飞不远长途、夜间效率低下、离不开沙子补给、受制于空中管制。铁路的六大优势恰好是它们的镜像。你继承了爷爷在雾峰村留下的废弃线路——中国中部一座雾中的茶乡山村——去证明铁轨依然有存在的理由。

## 世界如何运转

**五条相互咬合的趋势线**潜伏在表面之下——越过阈值之前对玩家隐形，一旦越过，世界不可逆地改变：

| 趋势线 | 含义 |
|--------|------|
| **信任** | 公众对铁路的信心 |
| **财政** | 你的家底 |
| **沙能渗透** | USET 在每个城镇对乘客的掌控 |
| **政治压力** | 政府盯着你的程度 |
| **设施老化** | 线路一站一站地磨损 |

## 核心系统

**一个真正在跑的模拟**——列车在跑、站台有人、四季流转。表面之下，一套相互咬合的引擎驱动一切：

- **沙本位经济核（Sand Standard Core）**——经济模拟引擎：客流、燃料、工资、维护、事故概率、信任，各自有一条文档化的公式。收入减去成本是一个真实的数字，不是脚本曲线。引擎驱动五条趋势线，越过阈值，世界不可逆地改变。[跨系统公式一览](docs/compose/specs/跨系统联动公式.md) 把每个变量串在一起。
- **千里马创世核（Chollima Genesis Core）**——新游戏开局时，种子初始化整个世界的底层结构：供需关系、资源分布、人物的倾向。不是每回合掷骰子，而是从种子生长出来的完整世界。两局体验不同，是因为世界本身就是不同的两个世界。
- **岁月叙事引擎（Suiyue Narrative Engine）**——以游戏内 AI 角色"岁月"命名。它分析当前世界状态——种子衍生的底层结构、五条趋势线的位置、玩家与角色的关系——生成对应的事件，覆盖硬编码无法预见的变量。每个事件都是那个世界在那一刻的产物。
- **先民人事系统（Seonmin Personnel System）**——每个员工四条技能轨道、成长速度、潜力上限。但你看不到数字：疲劳和忠诚不出现在界面上，而是通过言行——说话的语气、是否主动加班、事故后的反应——流露出来。减少数字化输入，像现实一样。
- **千里马对手AI（Chollima Rival AI）**——USET 在每个城市维护一个渗透率数值，自然增长，通过营销活动加速。每 30 天它选择一次行动；不回应，就丢城。
- **剧情是生命线**——前期纯运营注定亏损，叙事的救济是铁路呼吸的氧气。

**深度嵌入的 AI**——视觉小说提供三种对话模式（预设 / 自由 AI / 混合），可切换 MiMo、GPT 或本地模型驱动。角色带着人设、好感度阈值和记忆——他们记得你做过什么，态度会变。剧情节点可根据世界状态即时生成。规划中的手机 AI 助手由玩家自己的 API Key 驱动，叙事上包装为远程访问学校服务器调用 RDA 的改造版 RDA 铁路决策辅助系统。

*三层时间模型与阈值机制：[核心玩法循环](docs/compose/specs/核心玩法循环.md) · [AI 系统实现计划](docs/compose/specs/岁月叙事引擎.md) · [VN AI 设计 v2.1](参考资料/视觉小说系统设计.md)*

## 人

你从不独自经营这条线。员工——带着技能、疲劳刻度，还有自己的脾气——起初只是一小撮固执的人，随后随世界一起生长：新人加入、老人退休、学徒被写进正在讲的故事里，成为他们一段叙事的中心。

*完整角色档案与成长系统：[角色设定](参考资料/角色设定.md)*

## 长线

```
序章视觉小说（Day 0–4）→ 求生 → 站稳 → 扩张 → 突破 → 发展 → 全国路网
```

政治周期摇摆着你的补贴。随机事件——风暴、油价、假日客流、USET 广告轰炸——让每个季节都紧绷。剧情记得你跳过的每一次选择。

## AI 开发指南

本项目的 AI 代理专用文档位于 `docs/for-ai/`：

| 文档 | 内容 | 必读 |
|------|------|------|
| `docs/for-ai/PROJECT_OVERVIEW.md` | 项目总览：架构图、数据流、场景流程、设计-实现差距 | ✅ 修改前必读 |

**AI 代理工作流**：
1. 读 `docs/for-ai/PROJECT_OVERVIEW.md` 理解全局
2. 读 `docs/for-ai/CODE_MAP.md` 定位修改目标
3. 读相关的设计文档（`参考资料/` 或 `docs/compose/specs/`）
4. 修改代码，同步更新 `docs/for-ai/` 中的文档
5. 通过 Unity 批处理验证编译
