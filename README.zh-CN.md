# 铁路复兴：沙能冲击 🚂

> *[English](README.md) | 简体中文*

一款硬核像素风铁路模拟经营 + 视觉小说游戏，使用 Unity 6 开发。

---

## 概述

在一个沙能飞行器全面取代传统铁路的世界里，你继承了偏远村庄雾峰村的一条废弃铁路线。你的使命：修复铁路，赢回社区信任，对抗沙能科技公司的步步蚕食。

**类型**：模拟经营 / 视觉小说 / 策略  
**平台**：Windows（优先），Android（计划中）  
**引擎**：Unity 6000.4.6f1 (Unity 6)  
**风格**：16-bit 像素风，暖色调  

---

## 特色

| 特色 | 说明 |
|------|------|
| **硬核经济** | 前期纯运营必然亏损，剧情补贴是生存关键。每个决策都有重量。 |
| **慢节奏玩法** | 世界在后台持续运行，玩家观察趋势、做长期策略选择、面对不可逆后果。 |
| **五条趋势线** | 信任度、财政压力、沙能渗透率、政治压力、设施老化——五条相互影响的趋势线。 |
| **沙能竞争** | AI 驱动的竞争对手，主动发起广告战、价格战、收购你的线路。 |
| **人员管理** | 5 名独特角色，每人 4 项技能，疲劳系统、培训、岗位分配。 |
| **科技树** | 3 条互斥分支（工业 / 生态 / 自动化）。 |
| **剧情驱动** | 序章为视觉小说，平滑过渡到经营玩法。剧情事件贯穿始终。 |
| **随机事件** | 10+ 事件模板：经济波动、天气、人事、沙能行动。 |
| **政治周期** | 地方政府在威权、市场、福利三种倾向间周期性变化。 |
| **术语高亮** | 对话中黄色高亮术语，点击弹出解释。 |
| **参考《爱上火车》** | 借鉴《まいてつ》的沉浸式铁路体验与旅客故事线。 |

## 快速开始

### 前置要求

- Unity 6000.4.6f1 (Unity 6)
- Git

### 安装

```bash
git clone https://github.com/NMDX721/RailwayRenaissance.git
```

在 Unity Hub 中打开项目：

1. 启动 Unity Hub
2. 点击 **添加** → **从磁盘添加项目**
3. 选择克隆的目录
4. 使用 Unity 6000.4.6f1 打开

### 运行

在 Unity 编辑器中打开以下场景：

| 场景 | 说明 |
|------|------|
| `Scenes/Login.unity` | 登录界面（uGUI） |
| `Scenes/VN_Test.unity` | 视觉小说测试（序章开头） |
| `Scenes/StationSlice_V1.unity` | 车站经营主场景 |
