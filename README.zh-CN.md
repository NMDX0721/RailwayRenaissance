## 世界

这是 2076 年。沙能飞行器终结了铁路——客运量蒸发 78%，91 个国家解散了国有铁路，到 2072 年全球路网事实上已经停运。沙能垄断企业 **USET** 统治着天空；手握全球最大沙子储量的朝鲜，是世界唯一的超级大国。

但沙能载具有六个致命弱点——拉不动重货、闯不过风暴、飞不远长途、夜间效率低下、离不开沙子补给、受制于空中管制。铁路的六大优势恰好是它们的镜像。你继承了爷爷在雾峰村留下的废弃线路——中国中部一座雾中的茶乡山村——去证明铁轨依然有存在的理由。

## 世界如何运转

**五条相互咬合的趋势线**潜伏在表面之下——越过阈值之前对玩家隐形，一旦越过，世界不可逆地改变：

| 趋势线 | 含义 |
|--------|------|
| **信任** | 公众对铁路的信心 |
| **财政** | 你的家底 |
| **沙能渗透** | USET 在每个城镇对乘客的掌控 |
| **政治压力** | 政府盯着你的程度 |
| **设施老化** | 线路一站一站地磨损 |

## 方法与架构

**一个自在运转的世界**——列车在跑、站台有人、四季流转。决策很少到来，但每一条都很重——因为底下的模拟是真的，不是装饰：

- **五条相互咬合的趋势线**——信任、财政、沙能渗透、政治压力、设施老化——在后台缓慢漂移，彼此交叉联动；越过阈值，世界不可逆地改变。
- **沙本位的数据经济**——票价、工资、补贴全部追溯到一条文档化的公式，[跨系统公式一览](docs/compose/specs/跨系统联动公式.md) 把它们串成一张网。
- **自研李式调度算法（RDA）**——金日成综合大学智能调度系统实验室的核心成果，也是主角的研究方向。它分析实时客流与线路负载，在每天变动的需求中找到最优运力分配——在游戏中，它直接驱动你的调度面板，不是"剧情彩蛋"，而是"你正在用主角的算法做决策"。
- **开放的研发网**——基建、机车、调度、社会四个方向并行成长、自由组合。没有锁死的分支，没有后悔的分岔路。
- **会打持久战的对手**——USET 广告、价格战、收购你的线路，只要你放松。
- **剧情是生命线**——前期纯运营注定亏损，叙事的救济是铁路呼吸的氧气。

**深度嵌入的 AI**——视觉小说运行在三种模式：预设对话、自由 AI 对话、以及两者的混合。可配置的 Provider 层（MiMo / GPT / 本地模型）负责路由请求；每个角色带着自己的人设、说话方式、好感度阈值和记忆。角色不只是反应——他们记得你做过什么，对你的态度会改变他们说出口的话。剧情节点可以根据你的世界状态即时生成。

*三层时间模型与阈值机制：[核心玩法循环](docs/compose/specs/核心玩法循环.md) · [AI 系统实现计划](docs/compose/specs/AI系统实现计划.md) · [VN AI 设计 v2.1](参考资料/视觉小说系统设计.md)*

## 人

你从不独自经营这条线。员工——带着技能、疲劳刻度，还有自己的脾气——起初只是一小撮固执的人，随后随世界一起生长：新人加入、老人退休、学徒被写进正在讲的故事里，成为他们一段叙事的中心。

*完整角色档案与成长系统：[角色设定](参考资料/角色设定.md)*

## 长线

```
序章视觉小说（Day 0–4）→ 求生 → 站稳 → 扩张 → 突破 → 发展 → 全国路网
```

政治周期摇摆着你的补贴。随机事件——风暴、油价、假日客流、USET 广告轰炸——让每个季节都紧绷。剧情记得你跳过的每一次选择。
