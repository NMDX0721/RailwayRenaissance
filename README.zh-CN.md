《铁路复兴：沙能冲击》是一款铁路经营模拟 × 视觉小说游戏。你继承一条被世界遗忘的废弃铁路，招员工、养车辆、挡沙能巨头的渗透，在一个飞行器统治天空的时代，证明铁轨还有存在的价值。

游戏的核心不是"做选择"，而是"承担过去的选择"。每个决策都受**惯性**支配——今天的降价要 20 天才能见效，过去长期压榨的员工不会因一次加薪就忠诚，**USET** 一旦扎根就难以驱逐。这不是一个可以读档重来的游戏；这是一个必须与历史共处的游戏。

数据驱动的经济系统，五条相互联动的趋势线，基于 3D **Simplex 噪声**的波动引擎——每局游戏的经济走势都不相同。

整个项目结构为 AI 工具链优化——文档、代码、数据格式统一，用生成式 AI 即可实现自定义改造。详见 [AI 原生重构支持](#ai-原生重构支持)。

## 世界背景

2076 年。二十六年前，沙能还只是英国实验室里的一个原型。今天，它是新世界秩序的基石。

2050 年，英国工程师团队发明了沙能原理。次年，拥有全球最大沙子储量的朝鲜民主主义人民共和国买断了全部专利，在平壤组建了**联合沙能科学技术会社（USET，United Sand Energy Technology）**。2053 年，首款量产沙能载具「沙子飞猪号」下线。2056 年，铁路客运量首次下降 34%。2068 年，91 个国家解散了国有铁路系统。2072 年，全球铁路网事实上已停止运营。

朝鲜——曾处于国际体系边缘的国家——成了世界唯一的超级大国。不是因为军事征服，而是因为控制了驱动一切的资源：沙子。

USET 不是一家普通公司。它的股权结构设计使其能在国际制裁体系中游走：卢森堡控股平台名义持股 51%，**白头山动力总会社**（朝鲜国资实体）持股 49%。实际控制权通过三份不公开的协议——管理权、技术授权、沙子独家供应——集中在平壤手中。账面上它是跨国企业，骨子里它是国家机器。

沙能载具有六个致命弱点：拉不动重货、闯不过风暴、飞不远长途、夜间效率低下、离不开沙子补给、受制于空中管制。铁路的六项优势恰好是这六点的镜像——这是你可以利用的设计空间。

你继承了爷爷留在雾峰村，一座被雾气笼罩的中国中部茶乡山村的废弃线路。目标是在一个已经不需要铁路的世界里，证明铁路还有存在的价值。

## 游戏结构

### 五条趋势线

每次游戏的表层之下，五条相互关联的趋势线在运行。它们在越过阈值前不会显现，一旦越过，可能触发不可逆的变化：

| 趋势线 | 定义 | 越界后果 |
|--------|------|---------|
| **信任** | 公众对铁路的信心 | 低于 30：客流雪崩式下跌 |
| **财政** | 玩家的财务状况 | 持续亏损：信用评级降级，利率上升 |
| **沙能渗透** | USET 在各城镇的市场份额 | 超过 0.60 持续 15 天：USET 建立永久营业点 |
| **政治压力** | 政府介入的程度 | 超过 0.70：线路可能被征收或强制转让 |
| **设施老化** | 线路的累积磨损 | 低于 40：状态上限永久降低 10% |

趋势线之间不是孤立的。信任崩塌会助长沙能渗透，沙能渗透侵蚀收入，收入恶化拖累财政，财政恶化加速设施老化——这是一个连锁反应，如果不加干预，足以终结一局游戏。反之，早期对信任的投入会产生正向循环，随游戏进程持续放大。

### 核心系统

游戏由五个相互连接的模拟引擎构成，每个引擎都有独立的设计文档和公式体系：

- **沙本位经济核**——游戏的经济基础，驱动客流、票价、补贴和五条趋势线的互锁关系。得名于"沙本位"货币体系——沙能作为全球硬通货，一切经济活动的价值锚点。
- **千里马创世核**——每局开局时通过种子码生成独一无二的世界结构和游戏参数。得名于朝鲜千里马运动——天地之马，一日千里，每一次开局都是一次新的驰骋。
- **岁月叙事引擎**——根据世界状态动态生成事件，驱动视觉小说对话。得名于"岁月"二字——叙事随时间的沉积而生长，而非预制的脚本树。
- **先民人事系统**——管理员工的技能树、疲劳、忠诚度和成长曲线。得名于"先民"——最早的开拓者，铁路复兴的第一批建设者。
- **铁龙竞争系统**——模拟 USET 的渗透扩张和策略选择。得名于汉代天象：龙与千里马互为镜像——马掌天空，龙掌大地。

每个引擎的详细公式和设计文档见下表：

<details>
<summary><strong>沙本位经济核</strong>——经济模拟引擎</summary>

**核心公式：**
```
PassengerFlow(t) = BaseFlow × sigmoid(Trust(t)) × SeasonalFFT(t) × L2Fluctuation(t)
TicketRevenue(t) = ∫(Flow(τ) × DynamicPricing(τ) × (1 + ElasticityCorrection(τ))) dτ
Subsidy(t) = OperationalScore(t) × PoliticalStanding(t) × StrategicValue(t) × InertiaDecay(t)
```

每条趋势线有自己的微分方程：信任低于阈值时，`d(Flow)/dt ∝ -TrustDeficit × 0.005`；沙能渗透超过 0.60 持续 15 天触发永久营业点。所有系数通过 GlobalRules 在每局游戏开局时由种子生成，确保经济走势各不相同。

**五条趋势线互锁：**
```
TrustCollapse → SandPenetration↑ → Revenue↓ → FiscalHealth↓ → InfrastructureDecay↑
```
反向连锁则形成正向循环。引擎受惯性原则影响最深——没有哪个决策能立即见效，每个选择都背负着过去的重担。

经济模拟在前期是亏损设计。汉字"铁"——左边是"金"，右边是"失"——已暗示了铁路事业注定难以盈利。你靠剧情驱动的补贴生存：政府补贴、社区集资、遗产保护基金，每一项都绑定着需要维护的政治关系。补贴金额由运营评估、政治关系、线路战略价值共同决定，且受惯性原则调制。
</details>

<details>
<summary><strong>千里马创世核</strong>——世界生成系统</summary>

**种子结构：** `RR-XXXXX-YYYYY`
- `RR`：固定前缀
- `XXXXX`：城市模板、依赖图、资源分布、政治倾向的哈希编码
- `YYYYY`：18+ 个 GlobalRules 基线参数的哈希编码

**生成管线：**
```
Seed → CityTemplateSampling → KosarajuSCC(DependencyGraph) → KruskalMST(RailNetwork) → ResourceDistribution → PoliticalAssignment → fBmBlackbox(GlobalRules)
```

**黑箱函数（fBm 3D Simplex 噪声）：**
```
WorldState = ∑_{i=0}^{octaves} noise.snoise(float3(seed.x × lacunarity^i, k, seed.y)) × gain^i
GlobalRules[k] = Lerp(MinBound[k], MaxBound[k], WorldState)
```
- Octaves: 6, Lacunarity: 2.0, Gain: 0.5
- 同一种子始终产生同一世界；不同种子产生结构上不同的世界

**产出物：** CityTemplates[], DependencyGraph(V, E), RailEdges[], ResourceMap, PoliticalMapping, GlobalRules{18+ params}, EventWeightTable
</details>

<details>
<summary><strong>岁月叙事引擎</strong>——事件生成系统</summary>

**事件触发概率：**
```
P(event) = BaseP × (1 - exp(-t / τ_cooldown)) × max(0, 1 - N_recent / N_max) × WorldStateWeight
```
- `τ_cooldown`：冷却半衰期
- `N_max`：密度上限（防止叙事疲劳）

**角色好感度：**
```
Favorability(t+1) = Favorability(t) + EventValue × PersonalityWeight × InertiaDecay(t)
```
累积好感触发新剧情分支或解锁特殊对话选项。

**模板引擎：** 每个事件类型有固定的槽位结构，**WorldAnalyzer** 根据运行时条件填充槽位。事件设有冷却时间、密度上限和对数衰减曲线，防止叙事疲劳。

**三种对话模式：**
- **Preset** — 完全编剧，固定对话树
- **Free AI** — 你输入任意内容，AI 以角色身份回应
- **Hybrid** — 预设分支为主，AI 为未预见的主题兜底
</details>

<details>
<summary><strong>先民人事系统</strong>——员工管理系统</summary>

**技能成长：**
```
DailyGain = BaseGrowthRate × RoleMatch[skill] × (1 + max(0, ParentLevel - SubSkillLevel) / ParentLevel × 0.5) × FluctuationEngine.Weighted(base, variance) × EventModifier
```
- RoleMatch：核心×1.0 / 同系统×0.6 / 低跨系×0.3 / 高跨系×0.1
- 追赶加成：母技能高于子技能时触发，差距越大加成越高

**疲劳与忠诚度：**
```
Fatigue(t+1) = clamp(Fatigue(t) + BaseFatigue + ConsecutiveWorkBonus + RoleBonus, 0, 100)
Loyalty(t) = Baseline + Σ(EventEffects) + SocialComparison(ColleagueSalary, SelfSalary) - WageDissatisfaction
SocialComparison: ΔLoyalty = -α × max(0, ColleagueSalary / SelfSalary - Threshold) × (1 - HiddenPatience/100)
```

**师徒传承：** Mentor ≥ Lv4 → Apprentice ×2 成长速率，Mentor 获得 Apprentice 当日经验的 10% 作为额外成长。
**母技能等级：** `ParentLevel = Σ(SubSkillLevel[i] × Weight[i]) / Σ(Weight[i])`，数值表示 0-100。
</details>

<details>
<summary><strong>铁龙竞争系统</strong>——AI 对手系统</summary>

**渗透值动态：**
```
d(Penetration)/dt = α_natural + Σ(Campaign_i(t)) - Countermeasure(t)
α_natural = 0.0015/day
Campaigns: Advertising +0.005, FreeRides +0.003, PriceWar +0.008
```
永久营业点：Penetration > 0.60 持续 15 天

**USET 策略选择（每 30 天）：**
```
Strategy(t) = argmax_{s ∈ Strategies} E[Value(s) | WorldState(t)]
```

铁龙计划得名于汉代天象隐喻：千里马与龙互为镜像——马掌天空，龙掌大地。USET 的公开面孔是"国际铁路遗产基金会"，六步收购流程在世界观设定中有完整记录。
</details>

### 科技树

四个研发方向构成开放网络，而非线性树形结构。每个节点在满足前置条件后解锁：

| 领域 | 解锁内容 |
|------|---------|
| **基建** | 轨道升级、车站扩建、桥梁修复 |
| **机车** | 新机车类型、燃料效率、货运能力 |
| **调度** | 排班算法、员工优化、客流分析 |
| **社会** | 社区关系、政治杠杆、遗产基金 |

研发不是填进度条，而是选择下一个要解决的问题，并承受未解决问题带来的后果。

### 区域解锁与政治系统

世界分为六个区域，每个区域包含多个城市。解锁一个区域需要满足信任阈值、支付连接费用、并完成一个剧情事件。每个区域有其主导政治倾向——**威权**、**市场**或**福利**——决定了当地政府如何评估你的表现。

政治倾向会随你的行为而偏移。威权地区奖励稳定、惩罚动荡；市场地区奖励盈利、惩罚低效；福利地区奖励服务、惩罚怠慢。你必须针对每个区域的政治气候调整策略，否则将面临补贴削减、检查加严，甚至线路被征收。

### RDA——**李式调度算法** & **铁路决策助手**

你的爷爷开发了**李式调度算法**（RDA，Ri Dispatch Algorithm），一种基于实时客流数据优化列车路径的动态调度协议。你继承了该算法，以及一部运行其改良版的手机助手——**铁路决策助手**（RDA，Railway Decision Assistant），缩写同为 RDA。

**RDA** 系统随线网扩张渐进解锁：初期提供基础排班建议，后期解锁预测性维护预警、自动排班和基于需求预测的动态票价调整。手机助手通过你的 API Key 接入金日成综合大学服务器，直接调用实验室中爷爷留下的原始调度算法。

### 施工队与燃料管理

扩张线网不止需要购置新车。你需要派遣**施工队**铺设新轨道、修复损坏区段、升级车站。每支施工队有自己的技能成长和设备需求。

燃料是最大的单笔持续性开支。NF-5 耕牛型内燃机车在雾峰老旧线路上以 40-60 km/h 的平均速度运行时，油耗为 58.5 L/100 km。**节油策略**——滑行、优化排班、减少怠速、以及最终的机车升级——直接影响利润底线。燃料价格并非固定；它随全球沙能市场波动，受季节指数和随机事件调制。

### 惯性原则

这是游戏的核心设计哲学：**你不是在做选择，而是在承担过去的选择。**

每个系统都存在惯性——一条历史基线，拖累或加速你的操作效果。公式在所有系统中统一：

```
Effect = ActionValue × (1 − InertiaCoefficient) + HistoricalBaseline × InertiaCoefficient
```

| 系统 | 惯性系数 | 含义 |
|------|---------|------|
| 客流 | 0.15 | 降价需要约 20 天才能完全应变 |
| 员工忠诚 | 0.15 | 过去长期低薪的阴影不会因一次加薪而消散 |
| 沙能渗透 | 0.20 | USET 的根扎得最深，最难拔除 |
| 车辆状态 | 0.10 | 一次大修抵消不了数月的疏于维护 |
| 政治关系 | 0.18 | 失信一次，修复以周为单位 |

历史基线是 30 天加权平均：近期的权重更高。当某个系统长期低于阈值时，会产生**永久遗留问题**：一条事故记录、一个 USET 营业点、一个降低的车辆状态上限、一个政治支持降级。这些遗留问题不会随数值回升而自行消除——它们需要数月持续改善才能逐步消除。

波动引擎（L1 简单波动 / L2 加权波动 / L3 复合波动 / L4 黑箱波动）使用 3D Simplex 噪声（`noise.snoise`）提供连续、非重复的变异，确保即使底层数值相近，每日的游戏体验也各不相同。

母技能与子技能之间存在双向反馈机制：子技能提升时，母技能按比例同步增长；当母技能等级高于子技能时，子技能获得追赶加成——经验获取效率随等级差距增大而提升，使资深员工在学习同系统新技能时效率高于新员工。

跨系统学习存在门槛差异。同一系统内的子技能迁移较为自然——具备驾驶技能的员工学习调车任务的效率损失较小。跨系统学习（如驾驶员学习机辆维修）则需要专门培训，效率系数显著降低。

## 游戏进程

```
序章视觉小说（Day 0–4）→ 求生期 → 稳定期 → 扩张期 → 突破期 → 发展期 → 全国路网
```

每个阶段有明确的运营目标和剧情里程碑：求生期靠补贴度日，稳定期实现收支平衡，扩张期开辟新线路，突破期突破 USET 封锁，发展期构建区域路网，最终挑战全国铁路复兴。

游戏围绕一个隐式的三层时间模型展开：每日决策、每月评估、每年战略调整。政治周期影响补贴。随机事件——风暴、油价暴涨、节假日客流、USET 营销攻势——在不同季节施加不同压力。每一个决策都有惯性。你始终背负着过去。

## AI 原生重构支持

本项目专为生成式人工智能改造而设计优化——不仅面向熟悉 C# 的开发者。

传统游戏要靠模组来扩展玩法：官方提供模组接口和规范，你需要学习整套模组框架才能动手。本项目则不同——文档、代码、数据格式全部统一为结构化 Markdown，AI 代理可直接读取和修改。想加新功能？描述需求，AI 代理理解系统结构后直接修改代码、验证结果。不需要学习模组接口，不需要适配特定框架。

每一项设计决策、每一条公式、每一个系统参数都有文档记录——文档与代码并列，按机器可读的格式维护。

**这意味着你可以：**

- 想调整经济平衡？打开 `参考资料/沙本位经济核.md`，让 AI 代理修改弹性系数。代理能理解公式、更新代码、验证结果。
- 想新增员工技能？打开 `docs/compose/specs/先民人事系统.md`，描述技能的功能。代理能找到正确的插入点，实现逻辑，更新测试。
- 想创建自定义世界种子？种子格式（`RR-XXXXX-YYYYY`）在千里马创世核设计文档中有详细说明。生成一个新种子，游戏就会产生一个独特的世界。

项目开源（MIT），文档详尽，AI 工具链就绪。复刻仓库，指向 AI 代理，即可按需改造。
