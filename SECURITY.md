# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.

Instead, report it privately via:
1. **GitHub Private Vulnerability Reporting** — Use the "Report a vulnerability" button on the Security tab
2. **Email** — Contact the repository owner directly

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅ Yes    |
| Older   | ❌ No     |

## Scope

This is an open-source game project. Security issues are limited to:
- Malicious code in dependencies
- Compromised build artifacts
- Sensitive data exposure in commits
