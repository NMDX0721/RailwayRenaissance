# 网易云本机桥接（开发中）

`bridge.js` 通过子进程标准输入输出传递一行一个 JSON 请求，调用固定版本的网易云 API；不监听网络端口。支持二维码、登录状态、搜索、歌单和播放地址查询。会话仅驻留进程内，退出即失效；返回结果不包含 Cookie。播放地址由调用方临时使用，不应写入存档。不得将标准输入输出暴露给网页或不受信任的进程。

开发环境使用 `npm ci --ignore-scripts` 安装，`node bridge.js` 启动。输入示例：`{"id":1,"method":"ping"}`。本桥尚未接到 Unity，尚未验证真实账号，也未准备可分发的 Node 运行时或完整依赖许可清单，不代表网易云已接入完成。禁止通过 `unblock` 绕过播放限制。
