# 网易云本机桥接（开发中）

`bridge.js` 通过子进程标准输入输出传递一行一个 JSON 请求，调用固定版本的网易云 API；不监听网络端口。支持二维码、登录状态、搜索、歌单和播放地址查询。会话仅驻留进程内，退出即失效；返回结果不包含 Cookie。播放地址由调用方临时使用，不应写入存档。不得将标准输入输出暴露给网页或不受信任的进程。

开发环境使用 `npm ci --ignore-scripts` 安装，`node bridge.js` 启动。输入示例：`{"id":1,"method":"ping"}`。本桥已接到 Unity，搜索与测试曲目播放通过；真实账号扫码仍有设备环境异常反馈。初始化补齐稳定设备 ID，并尝试刷新匿名会话，失败时继续扫码；无法保证解除服务器风控。可分发运行时及完整依赖许可仍需发行前核验。禁止通过 `unblock` 绕过播放限制。
