## 一、方案定型与技术架构

遵循总制作人指令 **“窗外 = 3D 程序化，控制台/车窗框 = UI Toolkit 2D 叠加”**：无需外置第三方 3D 资产生成工具，采用纯程序化几何网格构建配合 16-bit 像素画滤镜方案。

### 1. 渲染管线表

| 管线层级 | 组成要素 | 关键参数与实现 |
|---|---|---|
| **底座渲染层** | 3D 程序化场景 | 摄像机眼位偏右 (0.55, 2.45, 0)，SolidColor 天空，近切面 0.2m，远切面 450m |
| **像素化采样层** | RenderTexture | 分辨率 640×360，`FilterMode.Point`，`antiAliasing = 1`，Point 放大产生清晰物理像素颗粒 |
| **材质着色层** | URP Unlit 纯色平涂 | 无高光、无实时法线反射，严格锁定 `CabPalette` 离散调色板色阶 |
| **顶层交互层** | UI Toolkit 2D 控制台 | 工字型金属车窗遮罩 + 双皮肤控制面板 + 顶部测试抽屉 + 平板桌面深度挂接 |

## 二、场景内容清单与代码结构

新建模块位于 `Assets/Scripts/Cab/`：

1. **`CabPalette.cs`**：
   - 核心色：深棕 (`#3A2010`)、暖棕 (`#6B4423`)、琥珀 (`#B8843A`)、米白 (`#E8D8C0`)、暗红 (`#8B3A2A`)、金 (`#D4A843`)、深蓝 (`#1A2A3A`)；
   - 场景色：钢轨银蓝 (`#8C9EAF`)、道砟中灰 (`#47413B`)、枕木深褐 (`#281C13`)、松针绿、远山灰蓝、信号红绿灯；
   - URP Unlit / 平涂材质字典缓存与快捷别名。
2. **`CabEngineState.cs`**：
   - 动力学状态机：柴油机启机状态、换向手柄（后/中/前）、主控推杆（0-8 阶）、大闸制动（充/运/初/常/紧 5 档）；
   - 开机操作规程守卫（①启机 -> ②换向 -> ③制动缓解 -> ④提手柄牵引）；
   - 牵引阻力制动积分：戴维斯阻力公式、180 吨质量动力学积分、车速 (-25~105 km/h)、转速 (600~1500 rpm)、风压、水温、里程推移。
3. **`Cab3DSceneController.cs`**：
   - 窗外程序化几何：直线轨道钢轨与道砟路基、65 根枕木对象池、10 根木质电线杆对象池、中景树木与坡屋、远山天际线、松桥站站台与站房、出站信号机红绿灯、SpotLight 前照大灯、沙雨粒子。
4. **`CabConsoleUI.cs`**：
   - 车窗金属框架遮罩（工字型铆钉框架，遮阳板）；
   - 硬核模拟皮肤（模拟圆形仪表盘：速度、转速、风压、水温；机械推杆；信号与开机提示卡）；
   - 悬浮 HUD 皮肤（大字数显、快捷拇指操作栏）；
   - 顶部调试抽屉（速度覆盖 0~120、昼夜切换、晴雨切换、RT 分辨率阶梯 320/480/640/960、单层触发测试）。
5. **`GameMainUI.cs` 挂接**：
   - 平板桌面增加「驾驶台」App 图标（`🚂` 图标与蓝色液态玻璃底座）；
   - 点击全屏呼出 `CabConsoleUI`，挂载 3D 控制器；
   - 退出时安全销毁并恢复平板桌面。

## 四、三风险评估实测

1. **RT 像素风不违和度**：
   采用 640×360 Point 过滤放大，配合平涂 Unlit 材质，几何棱角在低分辨率下自然呈现阶梯像素边缘，与 16-bit 像素 UI 框完全契合，无 3D/2D 割裂感。
2. **两套皮肤状态一致性**：
   硬核模拟与悬浮 HUD 均唯一绑定同一个 `CabEngineState`，切换皮肤时车速、档位、风压、到站距离完全无缝同步。
3. **性能与内存安全**：
   所有道砟、枕木、树木、雨丝全部在 `Initialize` 时静态生成或进入对象池，`Update` 帧内零 `Instantiate`/`Destroy`，GC Alloc 为 0；退出时安全释放 RenderTexture 与场景根节点。
