尚未实现：三目标全程规划、时间窗求解、在线制动辨识与不确定性、局部跟踪和安全回退、控制器检查点、Unity 接线及 V2 配对实验。保持 V2 与物理内核原样。开发与记录由 Codex 辅助；学生独立复核待完成。

2026-10-28 开发运行：新增独立 V3 局部有限候选控制器雏形，使用速度参考、有限三情景和观测驱动的惰行/制动估计。相同 seed 1100、平轨名义工况直接运行原内核：平稳与省气在 360 秒结束时仍在起点（误差 -900 m、未到达、未退出），准点在 121.90 秒停稳、误差 +1.03 m、超限速 0 Tick。以上是单次开发运行，未冻结、未经过 Unity 验收，不构成优越性结论。平稳/省气初始参考速度为零，当前评分允许持续选择零牵引；须修复启动/进度约束并重测。时间匹配的参考曲线仍不是三种不同的优化轨迹。
