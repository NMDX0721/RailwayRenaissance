## 第二批：配音方案

2026-11-01 用户确认新方案为**日语配音＋中文字幕**，替代旧韩语方案。`参考资料/资产/角色音色设计_ElevenLabs.md` 保留旧稿作历史参考，其中角色性格与音色底色可用于改写，韩语提示词、方言要求和试听台词不可直接作为当前生产稿。日语音色和台本尚未制作或验收。英文字幕另列，不假设已翻译。

建议首测采用完整文字+BGM+音效，配音列为后续版本增强；如果首测要展示配音，仅选一段连续关键场景做「部分配音」样片，并明确版本范围。不要零散给每个角色塞几句后称为全配音。

1. 冻结主要角色与场景台词；确认角色音色卡。先为林彪悍、岁月、老陈、嘉颖徐各选普通、低语/情绪、铁路术语台词，制作短试听。
2. 日语方案先翻译再审校，建立人名、地名、车型和铁路专业术语的日语读音表。按角色年龄、性格和情绪重写日语音色提示词与试听台词；不能直接用中文台本配日语音色代替翻译。配音语言变更不自动改变故事所在地、角色身份或世界观。
3. ElevenLabs 作为现有设计的首选试音渠道；原创设计音色或获授权音色。先比较试听结果，再订生产方案；本轮不购买服务、不调用付费生成。
4. 离线逐句导出与打包，游戏运行时播放本地资源。保存台词文本哈希、日语稿、角色/音色ID、模型、生成设置、来源、授权记录与人工听审状态。
5. 引擎接入需新增独立 voice 字段和声轨、音量开关与重播；点击下一句、快进、回退、读档、切场景、退出VN时停止旧对白。自动模式须等待打字和语音完成。缺语音时继续文字流程。
6. 为生产台词分配稳定 ID；审计 JSON 的 scene/entry 是定位坐标，编辑剧本会漂移，不能直接作为长期配音ID。文本变化标记旧录音失效，不静默沿用错句。
7. 完成日语发音、情绪、截尾、静音、峰值及BGM混音听审；先连续场景，再扩至全篇。旁白默认无声，心理活动是否录制单独决定。

此前核对的官方页面包含日语与 Voice Design；免费层面向个人非商业用途，付费层提供商业使用权。实际生产仍须记录所选音色与服务条款，不把免费试听当作可发行商用录音。
来源：[ElevenLabs Text to Speech](https://elevenlabs.io/text-to-speech)（2026-11-01访问）。不在试音前承诺费用或特定方言质量。

## 首个测试版验收门槛

1. 必要背景、CG与实际出场立绘无占位；逐张确认人物、车辆、地理、时段及画风。
2. Unity 真实导入与播放检查：small/full的裁切、点击推进、渐变、恢复读档、CG图鉴解锁；审计无缺图不等于此项通过。
3. 十章完整通关；覆盖12个选择条目的可达分支、存读档、回顾跳转、自动/快进、结尾进入经营场景。分支覆盖须另建记录，不能用顺序扫JSON代替。
4. Windows 独立 Player 从干净测试存档启动，核对字体、BGM/SFX、分辨率与日志；不覆盖开发者当前存档。
5. 确认测试包只包含发行范围内内容及所需资源，核对字体、音乐、图片和第三方组件的分发许可与署名。以实际包内容为准，不把音乐服务现有原型自动纳入已许可发行范围。
6. 打包版本号、已知问题、反馈入口及存档兼容说明。当前没有完成上述运行验收，也没有发布测试版。
