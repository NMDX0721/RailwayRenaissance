# NF-5K 模拟后端首轮

2026-10-22补充：独立CabRailMotionReview场景通过`CabRailMotion`只读本核PositionM驱动车体循迹、轮对正反转和转向架转向，原CabSimulationReview保持静态。检查线不是正式线路系统，轮轨接触力/滑移/全车限界仍未实现，见[走行部运动](NF5K_RAIL_MOTION.md)。

## 定位与研究依据

这是虚构柴油电传动短编组的可操作后端原型，尚非原车标定或完整高拟真机车。场景只显示头车；候选整列质量包含尚未建模的挂车。真实动态太阳、黄昏与天气仍按用户要求暂缓；低黏着、坡度和环境温度只是后端测试输入。

2026-10-21 查阅的主要资料及本轮采用范围：

- [Open Rails 官方物理说明](https://www.openrails.org/learn/physics/)及[柴油电传动章节](https://open-rails.readthedocs.io/en/latest/physics.html#diesel-electric-locomotives)：区分启动过程、原动机功率、辅助负载、轮周功率和黏着限制。本项目自行实现简化模型，未复制其程序代码，也不声称达到 Open Rails 精度。
- [Wabtec 26C 制动阀](https://www.wabteccorp.com/locomotive/braking-systems/pneumatic-controls/26c-brake-valve)和[气动控制部件](https://www.wabteccorp.com/locomotive/braking-systems/pneumatic-controls)：制动管控制列车制动，本机制动可由继动阀利用总风供气。引用系统关系，不将 26C 冒充 JZ-7，也不直接套用某阀认证。
- [Knorr-Bremse 气动制动控制](https://rail.knorr-bremse.com/en/dk/portfolio/products-and-systems/braking-systems/control/pneumatic-control/)与[铁路供风系统](https://rail.knorr-bremse.com/en/se/portfolio/products-and-systems/braking-systems/supply/)：供风、制动指令与缸压分别建模；本轮采用有限储风与充排气。
- [印度铁路 CAMTECH 2019 双驾驶室 WDP4D 手册](https://indianrailways.gov.in/railwayboard/uploads/directorate/eff_res/camtech/mechanical/YearWise/Hand%20book%20for%20Dual%20cab(WDP4D)%20locomotives%20Siemens%20make(1).pdf)：借鉴主控、燃油泵、启动和空压机控制的分工。该车并非 NF-5K，不能移植其发动机或电气定额作为原车事实。
- [FRA 气动评估报告](https://railroads.dot.gov/sites/fra.dot.gov/files/2024-05/Arup%20Aero-A%20Revision.pdf)：阻力系数随车型标定，注意牛顿、米每秒的单位；这里使用自行选定的二次 Davis 系数，未采用高速铁路车辆系数。

## 架构与使用

- `CabSimulation.cs`：纯 C#、double 状态、20ms 固定步长；种子初值、柴油机、供风、制动、牵引、黏着、坡道、热状态和电池。
- `CabSimulationCodec.cs`：按字段名排序的版本化二进制标量编码，Base64 嵌入 JSON，保留 double 精度；拒绝错误类型、字段数及尾随数据。
- `CabSimulationDriver.cs`：唯一写入适配器，把旧控制接口映射为输入，把后端输出送给现有仪表，并将发电/备用电源可用状态接入现有灯光。
- `CabEngineState` 保留旧场景默认行为；挂载并启用 Driver 才使用新内核。其 `UpdatePhysics` 在该模式只调用适配器，不再同时运行旧物理。禁止调试速度覆盖与新内核争用速度。`IsEngineStarted` 保留启动请求语义，`IsEngineRunning` 表示实际运行；绿色运行灯采用后者。
- `NF5KSimulationReview` 生成独立的 `Assets/Scenes/CabSimulationReview.unity`，不改写已有内装/白天场景。菜单 `RailRevival/Cab/Prepare Simulation Backend Review`；批处理入口 `NF5KSimulationReview.BatchBuild`。

运行审阅场景：左下方测试面板依次插钥匙→开主控→开油泵→启动，等柴油机启动与充风→前进→运转/缓解→解除停放制动→加牵引。可测试独立制动、常用/紧急制动、低黏着、坡度及设备故障。该面板用于验证后端，3D 手轮/闸把机械交互尚待接线；场景车体暂不沿轨道移动。现有距离触发的信号显示仍是旧演示，不是闭塞/联锁后端。

## 本轮公式与状态关系

1. **牵引**：油门经3s一阶迟滞产生负荷需求；转速以180r/min/s变化。轴功率受需求及转速包络限制，扣20kW辅助负荷与工作中的空压机负荷后乘传动效率。热降额在100–115℃间逐步收力。轮周力取起动力限制、`P/max(|v|,0.8)`及`μ·动力质量·g`三者最小值，乘已接受的方向。停放、气压不足、缸压未缓解、未运行、油压不足或紧急制动均阻断牵引。电流目前是轮周力比例代理，不是发电机/电机电路求解结果。
2. **运动**：阻力`A+B|v|+Cv²`，坡道力`-m·g·sin(atan(坡度‰/1000))`；按运动方向施加阻力和制动力。零速以外力能否克服阻力判断静止，不凭油门归零强制停车。跨零时避免制动力造成自发反向；位移采用步内前后速度平均，累计里程取绝对值，线路位置保留正负。
3. **空气**：同温、固定容积近似。源向目标充气时，目标压升为`min(速率·dt, 目标压差, 源/目标压差÷(1+V目标/V源))`，源压按容积比扣除。压缩机是外部气源，排风与泄漏计入排出量；检查`Σ(p表·V)`与累计供气、排气的平衡，不能从空风缸生成制动压力。
4. **制动**：常用/全常用目标管压430/350kPa，紧急排至0；服务/紧急排风速率35/180kPa/s，供管70kPa/s。缓解/运转时允许副风及控制容积充气。自动缸压目标为`clamp(2.6·(控制压力-管压),0,380)`，列车缸从副风取气，本机继动缸从总风取气。独立制动与自动本机制动取较大目标，不对全列增加两份制动力。泄漏、充排气速率均是候选调参。
5. **热/燃油**：冷却液为单节点能量平衡，额定负荷入热450kW、热容量5MJ/℃，散热与温差、风扇、速度有关；风扇83℃开启/78℃关闭，冷却故障降低散热。115℃触发停机锁存，冷却至80℃以下且停机才可复位。油温随热状态滞后，油压随实际运行和转速滞后。耗油为怠速8L/h加每轴功率kWh约0.25L的负载项；机油回路、泵失效、燃油系统管路尚未求解。
6. **供电**：SOC按启动机、停机辅助负荷和发电充电积分。主控开启且实际运行转速达到怠速90%时认为主电源可用；SOC>20%认为备用可用。现有灯光回路接受这两个布尔输入，停机可转备用。灯具功率尚未逐盏反馈至负荷，不能称已完成整车电网。

## 初值、快照与复现

冷车初始转速、油压、各气压、速度、里程均为物理零状态；燃油、电池荷电量、温度、载荷及审阅停车点由显式种子按±5%抖动。适配器优先读取创世核 `seedCode/seedId` 并稳定散列；无世界种子的独立审阅场景使用明示的20261021兜底。正常游戏开局/槽位存档尚未接线，不能据此声称解决所有创世核入口问题。

所有时间推进拆为20ms步长，不随帧率改变积分步长；余量保留，数值容差为10ns。未来输入录制必须带模拟tick，当前输入在每次外部调用采样后作用于该调用包含的步；不能从核心回放一致推断任意现实时间鼠标事件也已确定性回放。

检查点JSON封装版本2，包含精确配置、状态、输入编码与往返格式的时钟余量。恢复先验证候选状态；在暂停且钥匙/主控与记录匹配的驾驶台中使用。它不是完整游戏存档，钥匙实体、门、灯光选择、场景位置、世界/经营状态尚未一起恢复。改变字段后需要明确迁移；未知模式/类型/非法压力或非有限数拒绝恢复。

## 验证与尚缺部分

`NF5KSimulationReview.Validate` 覆盖启动守卫/延迟、气量守恒、空风缸无制动力、低压牵引闭锁、加速惰行停车、独立制动、低黏着、坡道溜车/停放、过热保护、精确检查点回放、30/144FPS逐位一致、种子初值和非法快照。Play Mode 使用现有钥匙/主控/油泵接口，检查仪表状态输出、运动中换向拒绝、检查点与紧急停车。结果写入 `tools/compile/cab_simulation_acceptance.json`。

最终验收通过：`tools/compile/cab_simulation_backend_verified.log`，15项核心标志全部为true。30/144FPS按同一tick命令序列运行200s，状态编码逐位一致；检查点恢复后的30s演化也逐位一致。固定容积气量平衡最大残差约`2.65e-7 kPa·L`。Play Mode 还检查发电/电池供电投影，以及停机后车内照明转入备用。该结果证明当前模型内部一致性，不等于真实车辆标定或停止距离认证。

仍缺：逐车制动管传播与阀的速率敏感性、列车纵向车钩/缓冲器、轮对惯量与黏滑、真实牵引特性曲线、电气与热系统标定、供风故障全树、真实线路/闭塞、动态太阳天气、整车存档和性能验收。固定控制压力的本轮简化不能准确复现所有慢漏/缓解特性。未标定的停车距离是回归结果，不能当作真实 NF5K 制动数据。
