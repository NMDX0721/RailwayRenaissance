## 二、模块一：日本铁路信号机（色灯式）双模态设计

### 1. 真实日本铁路信号规程考证（色灯式信号機）
参考日本《鉄道運転規則》及 JR/国铁标准，色灯式信号机分为 2 灯至 5 灯式，其速度限制与现示含义如下：

| 灯显名称 | 日文现示 | 灯光组合 | 5灯式排布参考 | 规程限制速度 | 游戏内真实含义 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **進行** | 進行 (G) | **绿 1 灯** | 🟢 (单亮) | 最高规定时速 (Line Speed) | 闭塞前方空闲，全速前进 |
| **減速** | 減速 (YG) | **绿 + 黄 同亮** | 🟢 + 🟡 | 65 ~ 75 km/h | 予告下一个信号为“注意”或“警戒” |
| **注意** | 注意 (Y) | **黄 1 灯** | 🟡 (单亮) | 45 ~ 55 km/h | 予告下一个信号为“停止”或“警戒” |
| **警戒** | 警戒 (YY) | **黄 + 黄 同亮** | 🟡 + 🟡 | 25 ~ 30 km/h | 极近距离有列车/道岔受阻，必须减速 |
| **停止** | 停止 (R) | **红 1 灯** | 🔴 (单亮) | **0 km/h** | **绝对禁行**，越过即触发冒进事故（SPAD） |

### 2. VN 模式：左上角“剧情先兆指示仪”（Foreshadowing Signal）
在视觉小说叙事中，信号机作为**铁道隐喻**置于屏幕左上角，实时揭示当前对话暗含的后续剧情走势与危机度：

```
┌────────────────────────────────────────────────────────┐
│ [🚦 减速 YG] (点击可开关)                  [Auto] [Menu]│
│                                                        │
│                    【立绘 / Cut-in 区域】              │
│                                                        │
│ ┌────────────────────────────────────────────────────┐ │
│ │ [🔖] 孙工                                           │ │
│ │ ── 听好了，这趟车拉的是沙能核心，半路要是停了……   │ │
│ └────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

* **先兆灯语对应法则**：
  * **進行 (G)**：气氛轻松、合作顺畅、暂无危机潜伏；
  * **減速 (YG)**：言辞试探、异动征兆、暗流涌动；
  * **注意 (Y)**：利益冲突浮现、信任裂痕、不可逆抉择逼近；
  * **警戒 (YY)**：拔枪相向、沙暴迫近、敌对势力登车、千钧一发；
  * **停止 (R)**：谈判决裂、封锁降临、重要角色牺牲/绝境关头。
* **自主开关**：支持在左上角直接点击信号机或在“设置 - 辅助”中开启/关闭“剧情先兆灯”，为硬核玩家保留纯粹悬念。
* **剧本配置语法**：在剧本 JSON 中无缝扩充可选字段 `"signal"`（如未填则由情绪分析器自动平滑推算）：
  ```json
  {
    "s": "齐局长",
    "text": "你们新平站要是再交不上这笔沙税，铁轨就得拆回省城。",
    "signal": "Y"
  }
  ```

### 3. 经营模式：行车调度、区间闭塞与事故防御
在发车运营与行车界面中，信号系统直接作为调度核心：
* **闭塞区间计算**：单线/双线区间根据前车位置与沙暴路况动态计算信号现示；
* **防冒进与正点率惩罚**：若玩家在驾驶或AI司机行车中违反信号速度（如“注意Y”灯下以80km/h冒进），将触发**风闸急刹、车轮擦伤、设备老化率飙升**；若强闯“停止R”，则触发重大脱轨事故；
* **贯彻数值不外显**：不提示“事故率+30%”，而是以信号机刺眼的红灯爆闪、风缸高频蜂鸣与车体剧烈颤动带来身临其境的窒息压迫感。

## 三、模块二：机车驾驶台（Cab View）双模式设计

### 1. 架构：全景驾驶室 vs 侧挂仪表 UI
驾驶台支持在**经营发车运行中**与**VN关键驾驶高潮节点**中通融使用：

```
                    ┌──────────────────────────────────────────────┐
                    │               机车驾驶台切换核心             │
                    └──────────────────────┬───────────────────────┘
                                           │
                 ┌─────────────────────────┴─────────────────────────┐
                 ▼                                                   ▼
┌─────────────────────────────────┐                 ┌─────────────────────────────────┐
│     【方案 A：全景双窗沉浸驾驶室】 │                 │    【方案 B：侧挂仪表紧凑面板】   │
│          （纯沉浸 · 不融合UI）    │                 │          （HUD融合 · 兼顾经营）   │
├─────────────────────────────────┤                 ├─────────────────────────────────┤
│ • 经典前瞻双挡风大窗 (キハ07视界) │                 │ • 右侧垂直机械仪表立柜           │
│ • 车外沙暴、雪原、铁轨疾退特效   │                 │ • 车速、风压、油温、排烟四指针   │
│ • 主控杆/自阀大闸/单阀小闸拟真手柄│  <══ 一键切换 ══> │ • 状态铭牌指示灯与紧凑推杆       │
│ • 驾驶室顶部气窗与纯机械风噪震颤 │    (Tab / 按钮) │ • 左侧与上方完全保留经营地图/清单│
│ • 零杂乱UI覆盖，纯粹老司机手感   │                 │ • 适合一边调度运营一边观察车况   │
└─────────────────────────────────┘                 └─────────────────────────────────┘
```

### 2. 交互与平滑过渡机制
* **输入响应**：键盘快捷键 `Tab` 或界面一键切换胶囊按键。
* **镜头过渡（Camera Blend）**：
  * 全景模式下虚拟相机前推至司机座椅视点（FOV 65°）；
  * 切换到侧挂模式时，相机平滑微后退并向右偏转 25°，左侧屏幕平滑划入经营状态信息流，耗时 0.35s（Ease-Out-Cubic），零掉帧无缝过渡。
* **VN 叙事深度融入**：
  * 当剧情进入“破沙暴突围”、“亲调爷爷留下的喷油泵”、“手推大闸极限刹车”时，VN 直接调用全景驾驶台，手柄高亮，玩家必须亲自操作才能推进行车剧情。

## 四、模块三：VN 播放器交互次世代重构

### 1. 分镜级 Cut-in 机制
* **规则基准**：**底部对话栏保留、背景保留，人物立绘被 Cut-in 矩形画框取代**。
* **分镜表现**：
  * 当触发关键动作（如递扳手、道尺调平、油泵喷油、眼神震颤）时，原有左/右槽位立绘淡出（Fade Out 0.2s）；
  * 居中弹出 16:9 或 4:3 的精致像素特写画框（带复古黄铜/磨砂边框与细微胶片抖动），突出视觉冲击力。
* **剧本扩展标签**：
  ```json
  {
    "t": "cutin",
    "id": "cutin_wrench_turn",
    "s": "我",
    "text": "扳手在掌心沉得像一块生铁，我咬紧牙关，把它向下压了四分之一圈。"
  }
  ```

---

### 2. 底栏进度条革新：沿线里程地貌断面条（Route Elevation / Terrain Strip）
彻底废弃原有单调简陋的细线胶囊进度条，将其重构为**具有铁道地理风貌的动态断面轨**：

```
沿线地貌微缩条:
[起点站:雾峰村] ──~/\~【山地 Mountain】───════【铁桥】───🌲🌲【森林 Forest】───▓▓▓【沙暴区】──> [终点站:松桥]
                       ▲
                    [🚂 机车滑块] (当前进度，随句推进平滑前行)
```

* **视觉呈现**：
  * 轨道底衬呈现微缩海拔起伏折线、森林树木、山体阴影、涵洞隧道标识；
  * **进度滑块（Thumb）**：定制为流线型蒸汽/内燃机车车头像素图标（车头朝向前进方向，甚至带微弱烟尘火星粒子）；
  * **交互**：保留点击地貌断面任意位置与拖拽机车滑块 Seek 功能，悬停显示当前区段里程与对应剧情节点概览。

```
┌────────────────────────────────────────────────────────┐
│ [🔖书签] 孙工 (主工长)                                  │
│ ılılıllı (语音播放中动态音轨条，播完淡出)               │

└────────────────────────────────────────────────────────┘
```

* **书签标识（Bookmark）移位**：
  * 原 Menu 下拉列表中的书签按键彻底移除；
  * 改为人名左侧/右侧的精巧书签图钉图标 `[🔖]`；
  * 点击即点亮金色高光，提示“已在当前对话插入书签”，轻量高效。
* **语音播放条（Voice Bar）**：
  * 位于说话人名字正下方；
  * **状态机**：
    * **未播放/无语音**：高度为 0，完全隐藏（`DisplayStyle.None`）；
    * **正在播放**：平滑展开高度 4px，呈有节律的声波像素跳动（仿复古示波器或金波光轨）；
    * **播放结束**：以 0.3s 渐隐淡出，不留多余 UI 杂痕。

### 4. 2.0x 工业动效倍速键
* **视觉重绘**：按键绘制为**狂飙疾驰的像素机车图标**，伴随烟囱喷薄出的翻滚黑烟与穿梭电闪流光；
* **挡位调节**：
  * 点击循环切换：`1.0x (常速)` $\to$ `1.5x (提速)` $\to$ `2.0x (机车疾驰冒烟)` $\to$ `3.0x (电闪极速)`；
  * 长按 `Space` 或 `Ctrl` 激活临时巡航极速。

---

### 5. 打字机音效与文本播放速度规范
* **打字机音效（Typewriter SFX）**：
  * **默认状态**：**完全关闭（OFF）**，杜绝强加给玩家听觉疲劳；
  * **独立控制**：在“平板系统设置 - 声音与振动”中增设独立开关（Toggle）与独立音量调节滑块（0% ~ 100%），彻底与主音量/环境音解耦。
* **文本播放速度（Text Speed）**：
  * **挡位预设**：
    * 慢速：`0.05s / 字`（品味文学感）
    * 标准：`0.03s / 字`（默认平衡速度）
    * 快速：`0.015s / 字`（老玩家流畅阅读）
    * 瞬显：`0s`（全句即时展现）
  * **自定义微调**：设置界面提供毫秒级滑动条（`1ms ~ 80ms`），满足各种不同阅读习惯。

## 六、模块五：开放生态——Player AI Agent (Modding) 接入指南

本设计完全响应 Mind Map 提出的愿景：**`Allowing players use their own AI Agent to modify the game`**（允许玩家使用自身的 AI 智能体修改并扩展游戏）。

### 1. 架构明文与数据解耦
游戏内所有核心资产均保持开放、明文、零加密的 JSON 架构：

```
Assets/Resources/ (或游戏根目录 Mod/ 目录)
├── Scripts/             # VN剧本 (prologue_*.json, custom_*.json)
├── Configs/             # 经济/列车参数 (locomotives.json, routes.json)
├── events.json          # 经营随机事件库
├── orders.json          # 运输订单生成模板
└── Terms.json           # 铁路专业术语百科与高亮词库
```

---

### 2. 官方 AI Agent 提示词模板（Agent Modding Prompts）
玩家只需将以下 Prompt 复制并提供给自身的本地 AI Agent（Claude, DeepSeek, ChatGPT 等），即可精准生成符合引擎规程的合法 Mod：

````markdown
# 【铁路复兴：沙能冲击】官方 Mod 创作者系统指令

你现在是《铁路复兴：沙能冲击》的资深关卡与剧本设计师。你的任务是根据玩家的主题创作符合引擎规范的 JSON 模组。

## 必须遵守的核心规范：
1. **两项铁律**：
   - 严禁在玩家可见文本中出现冷冰冰的数字概率与数值（政治压力、机车老化、忠诚度等），必须使用定性档位词与动作描写。
   - 必须体现物理惯性（刹车制动距离、重联机车提速滞后）与剧情宿命惯性。
2. **剧本 JSON 标签规范**：
   - 心理独白：`{"t": "thought", "s": "说话人", "e": "表情", "text": "[心理文字]"}`（带中括号与说话人）；
   - 特写分镜：`{"t": "cutin", "id": "特写资源ID", "s": "说话人", "text": "描述"}`；
   - 信号机隐喻：可指定 `"signal": "G" | "YG" | "Y" | "YY" | "R"`；
   - 专业铁路名词：必须规范使用《铁路技术管理规程》标准术语（如道尺、大闸、给水泵、闭塞、喷油泵）。

## 模板输出格式：
输出为标准 JSON 数组，确保语法严密无缩进错误。
````

---

### 3. Mod 加载与安全机制
1. **自动扫描目录**：游戏启动时自动探测 `StreamingAssets/Mods/` 与玩家个人目录；
2. **热重载与语法自愈**：通过 `JSONParser` 增加防溃保护，当外部 Agent 生成的 JSON 存在末尾逗号或缺少非致命字段时，自动填充默认值并输出友好日志，保证游戏绝不崩溃。
