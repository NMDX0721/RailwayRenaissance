Folia fork 来源为 AGPL-3.0，参考行为并独立实现 Unity；其网易云本机服务依赖 @neteasecloudmusicapienhanced/api 4.41.1，发行前需核对完整依赖许可证和服务权限。真实账号、服务连接与硬件听音尚待各渠道分别验证。

本机依赖清点（2026-10-29）：发现 LGPL-3.0-only `@unblockneteasemusic/server`，`node-forge` 可选 BSD-3-Clause；`busboy` 与 `streamsearch` 在旧式 `licenses` 字段标记 MIT。该清点不是完整分发法律审查，不代表已满足所有通知和源码义务。桥接没有调用解除版权限制的接口。

Windows 隔离测试证据：`tools/compile/netease_music_review_v3/netease-player.log` 中匿名搜索、测试曲目的音频加载播放及本地元数据保存通过；真实账号登录、个人歌单与硬件听音未验证。该版本不包含后续添加的歌词与本地封面改动。

Folia 上游核对（源码清单）：QQ 使用 `@yakult-green-tea/qq-music-api` 3.3.3 且包默认启动本机 HTTP 服务；酷狗使用 KuGouMusicApi v1.6.0；波点使用 `bodian-music-api` 0.1.2；Navidrome 采用 Subsonic 1.16.1。上述 QQ、酷狗、波点依赖已用于本工程实验桥接；真实账号和发行条件仍需核验。Spotify 和 YouTube Music 的 Folia 私有协议实现不作为本工程可直接分发或合规的证据。

QQ 音乐实验桥接现可生成扫码图，匿名搜索真实返回上游 2001 拒绝；已编写登录、歌单及播放路径但真实账号尚未验证，不视为渠道验收完成。候选 QQ 依赖 3.3.3 元数据为 MIT，波点候选 0.1.2 为 AGPL-3.0；实际分发仍需核对所有依赖义务及平台条件。

来源核对链接：QQ 3.3.3 包元数据与使用范围见 https://www.npmjs.com/package/@yakult-green-tea/qq-music-api/v/3.3.3；酷狗依赖许可见 https://github.com/MakcRe/KuGouMusicApi/blob/v1.6.0/LICENSE。QQ 的 README 将用途描述为技术研究、学习与兼容性开发，发行前需要同时核对许可文本、平台条件及全部依赖，不能仅凭 npm 元数据认定整合可发行。

酷狗 v1.6.0 实验桥接：匿名搜索和二维码生成实测成功；匿名播放请求失败；扫码登录、账号歌单和实际播放均尚未验证，不视为完整接入。候选依赖许可和分发条件须审核。

波点 v0.1.2 实验桥接需 Node 24+、AGPL-3.0 许可义务核查：匿名搜索与二维码生成成功，一首匿名曲目返回 HTTPS 地址；真实账号、歌单和 Unity 播放仍未验证。状态仅代表当前进程内本机会话，地区限制不得伪称成功。

Subsonic/Navidrome 实验桥接实现连接、搜索、歌单和播放地址，模拟服务器完成成功/失败认证、搜索、歌单、来源隔离与登出检查（`SUBSONIC_MOCK_OK`）。真实用户服务器、MP3 转码及 Unity 播放尚未验证。依据 [Subsonic API](https://www.subsonic.org/pages/api.jsp) 的 token 与 salt 方式；凭据不保存于音乐状态。

### 官方平台能力核对（2026-10-29）

- Spotify [开发者政策](https://developer.spotify.com/policy) 明列禁止游戏、与其他服务的流内容集成及音乐与视觉媒体同步。当前产品为游戏内多来源播放器，直接按 Folia 私有协议接入并不能说明符合这些条件；需要平台明确授权或另行确定可行产品形式，当前不接入、不冒充成功。
- YouTube [开发者政策](https://developers.google.com/youtube/terms/developer-policies) 禁止分离音视频及在不可见播放器中后台播放；与本计划「关闭窗口继续音频」存在冲突。需要合规的可见播放器体验及凭据，当前不声称已接通。
- Apple [MusicKit](https://developer.apple.com/musickit/) 需开发者媒体标识与签发密钥以及用户授权；Windows 可研究官方 Web 播放器，当前项目未提供开发者凭据或播放器宿主。

WebDAV 实验桥接：根目录搜索、直接子目录和 MP3/WAV/OGG 地址已实现；模拟服务完成认证、目录边界、搜索及登出检查（`WEBDAV_MOCK_OK`）。实际服务器、重定向兼容和 Unity 播放尚未验证；不递归子目录，密码不保存到存档或旧版偏好。
- SoundCloud [API 指南](https://developers.soundcloud.com/docs/api/guide) 要求注册应用并使用 OAuth 2.1；其[注册页面](https://developers.soundcloud.com/docs/api/register-app)当前要求 Artist Pro 才能申请应用凭据。项目目前未提供注册应用或安全的授权宿主，因此链接配置不能当作真实接入。

依赖漏洞核查（2026-10-29，官方 npm audit）：WebDAV 的 `fast-xml-parser` 已从有严重漏洞的旧版升级到 5.11.2，模拟检查再次通过，当前 WebDAV 依赖未报告漏洞。QQ、酷狗、波点依赖当前审计未报告漏洞。网易云依赖链有 4 项高危报告，涉及 `basic-ftp` / `get-uri` / `pac-proxy-agent`，npm 未提供可用修复；当前桥接不接受调用方代理参数，但这不是漏洞消除或发行安全证明。需上游修复或完成替代与复审后才能作为正式分发依赖。

后续修复：将 `basic-ftp` 通过 npm override 固定为 6.2.3 后，官方 npm audit 当前未报告网易云依赖漏洞；已实际复测匿名搜索、播放地址解析与扫码图生成。该覆盖跨越上游声明的依赖主版本，桥接未启用 PAC 代理，代理兼容性、真实账号及完整发行许可证仍需核验。

Windows Player v6 实测：`QQ_PLAYER_QR True`；`kugouSearch=True`；`bodianSearch=True bodianPlayback=True`。该测试没有完成账号扫码、私人歌单或人工听音，并早于 WebDAV 及网易云依赖覆盖。
- B 站[开放平台概览](https://open.bilibili.com/doc)列出账号授权、公开信息和稿件数据等能力，并要求开发者入驻；目前未核实适合游戏内音频播放和用户收藏夹的官方能力及应用权限。旧实现仅有扫码并将凭据明文写入 PlayerPrefs，未接到新版；不应直接复用并称作收藏或播放已接通。

各在线来源的歌单分页续读仍未完成；界面会在来源标记有更多结果或达到已知上限时提示只显示部分。不同服务的分页准确性仍需真实账号核验。

分页进展：在线歌单和曲目已增加“加载更多”入口，分别使用来源的偏移或游标，并对重复项去重；尚需真实账号验证各渠道与边界。

Windows Player v7 已用本机模拟服务验证 Subsonic 与 WebDAV 的连接、搜索及音频加载播放；真实服务器、不同服务端配置和实际账号仍未验证。网易云和波点匿名播放、QQ 二维码和酷狗搜索同时通过。

当前隔离 Windows Player v8：网易云界面搜索及匿名音频、QQ 二维码、酷狗匿名搜索、波点匿名音频、模拟 Subsonic/WebDAV 音频均通过自动检查；真实扫码、账号歌单、私人服务器及人工听音未涵盖。

2026-10-29 用户实测：v10 网易云二维码能够显示，但使用网易云 App 扫码时提示“当前设备环境异常”，因此真实登录、个人歌单与账号播放尚未通过。该提示由用户观察到，具体触发原因未确定；不将二维码生成成功等同于登录成功。
