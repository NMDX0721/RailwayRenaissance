# NF-5K 消防设备与取放交互（2026-10-22）

后续纠正：旧瓶体及瓶身横线占位已重做，完整标签、机械结构、真实参考和抱箍开闭见 [灭火器重做说明](NF5K_EXTINGUISHER_REFERENCE.md)。以下“没有解扣动画”指没有连续手部/扣锁动画；目前已支持抱箍开闭姿态切换。

本轮覆盖两具灭火器和一把安全锤，替代前轮“仅静态外观”的状态。生成仍由 NF5KCabFittings.Apply 完成，四份整车审阅场景同步更新。

## 几何和材质

灭火器补独立背板、墙面锚固、底托、固定带和扣件，瓶体、阀颈、压柄、保险销、软管和瓶身标签组成可取下模型。独立中文“灭火器 / FIRE”挂架名牌保留在原位；安全锤补中文名牌。红色低光泽漆、局部裸钢、橡胶和暖纸标签分别使用不同材质；文字使用 Sarasa 中文字体和既有深度测试字体着色器，避免穿墙文字。未标注未经定型的药剂、容量、压力等级或认证标志。

## 操作接口

`Assets/Scripts/Cab/CabSafetyEquipment.cs` 保存挂架与可取模型的关系。`CabContextInteraction` 将其纳入射线和近邻候选，提供“查看铭牌与用途”及长按“取下检查／放回并固定”。沿用玩家当前交互键与设置输入隔离，不增加必背快捷键。

查看操作展示中文用途和当前功能边界；取下时模型移至相机右下方检查位置。一次仅允许持有一件；放回必须距离原挂架不超过2.4 m，恢复精确父节点、局部位置、旋转与缩放。挂架保留射线目标；组件关闭时归还模型，防止物件遗留于相机。当前没有背包、手部动画、固定带解扣动画、自由掉落、喷射、灭火、破窗或生涯保存。握持表现是检查展示，不代表完整第一人称持物系统。

该轮只提供用途查看，不执行真实消防培训判断，也不虚构铭牌技术参数。后续需要确定灭火剂与适用火灾类别后，再设计喷射、有限药剂和火灾后端。

## 验证

`NF5KSafetyEquipmentReview.Validate` 检查三处通道侧挂架射线、浮动菜单两项动作、取下／归位、远距离归位拒绝、单件限制与禁用归位。相机与焦点检查后恢复；测试不是整车自由行走或手部动画验收。原启动、驾驶、上下文输入、停放制动和轨道运动回归继续保留。
