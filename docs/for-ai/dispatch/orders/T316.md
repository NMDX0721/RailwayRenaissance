#### (4) 关闭单项及全部任务后旧控件引用释放与受控 GC 辅助核验
- **核心问题与 UI Toolkit 机制解释**:
  - UI Toolkit 的 `VisualElement` 挂载在 `IPanel` 上时，面板内部的事件分发器、布局系统以及 `FocusController`（持有 `focusedElement`）均会构成强引用根；此外，在宿主测试窗口 `EditorWindow.rootVisualElement` 未被销毁前，已移除的元素可能因焦点或分发器缓存保持根存活。
  - 在 C# Mono / IL2CPP 运行时栈中，宿主测试方法的局部变量在当前函数帧未退出前同样作为 GC Root。
  - 为此，`GameMainUI.CloseTabletTask` 与 `CloseAllTabletTasks` 增加了 `task.Root = null` 及 `task.LastFocusedElement = null`，彻底断开会话与根视觉树的强引用。
  - 在测试中，建立独立无内联的执行方法 `ExecuteWeakReferenceTaskLifecycle`：
    1. 针对 **笔记单项关闭**：创建 `weakNotesRoot`、`weakNoteTitle`、`weakNoteBody` 弱引用；调用 `CloseTabletTask("笔记")`，并将焦点交还 `desktop.Focus()`；
    2. 针对 **图鉴全任务关闭**：创建 `weakSettingsRoot`、`weakTipsPage`、`weakTerm` 弱引用；调用 `CloseAllTabletTasks()`，并将焦点交还 `desktop.Focus()`；
    3. 关闭并销毁测试窗口解绑 Panel，退出宿主方法帧切断堆栈根；
    4. 执行受控 GC：循环 3 次执行 `GC.Collect()` + `GC.WaitForPendingFinalizers()` + `GC.Collect()`。
  - **断言结果**:
    - `!weakNoteTitle.IsAlive` 为 true（笔记标题输入框已被回收）；
    - `!weakNoteBody.IsAlive` 为 true（笔记正文输入框已被回收）；
    - `!weakNotesRoot.IsAlive` 为 true（笔记根 VisualElement 已被回收）；
    - `!weakTerm.IsAlive` 为 true（图鉴词条 Label 已被回收）；
    - `!weakTipsPage.IsAlive` 为 true（图鉴子页面容器已被回收）；
    - `!weakSettingsRoot.IsAlive` 为 true（设置根 VisualElement 已被回收）。
    确证无论单任务关闭还是全量关闭，UI 树均能被垃圾回收彻底释放，绝非单纯静态字段置空。
