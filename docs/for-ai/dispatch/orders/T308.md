## 1. 目标模型：双层结构（温度计 + 状态机）

- **内层（隐）**：`PoliticalPressure` 连续量照旧演化（宏观波/噪声/赤字/沙能，现引擎不动），只作**风险温度计**——决定「监管事件」的触发概率与严重度，**永不直接切档**。
- **外层（显）**：新增 **`PoliticalTier`（0-4，对应 常态监管/警示通报/约谈整改/挂牌督办/停产停业整顿）离散状态机**。**档位只允许在「监管事件程序结算」时迁移**；`GetSanctionTierName()` 改为按 `PoliticalTier` 返回档名；补贴/限趟等罚则（L1059、L1098-1111）全部改读 `PoliticalTier`——**罚则只在迁移当日变更**，之后哪怕连续量波动也不再抖动。

## 2. 现实事件源（触发程序；严格参考现实，全部要能在回执里指出法规/制度出处）

**上行（恶化）事件源** —— 概率 = f(风险温度计, 车况, 线路老化, 事故史, 沙能渗透, 检查周期)：
1. **安全监察与检查**：国家铁路局安全监察 / 市交通运输局例行检查 / 安委会**安全生产大检查**（可挂 180 天宏观周期做「大检查年」）/ 专项督查「回头看」
2. **事故与险情**：脱轨、道口事故、险性事件通报（接现有事故/事件管线）
3. **媒体与舆情**：记者暗访、负面报道、热搜发酵（3~5 天转段）
4. **审计与督察**：运营补贴审计、环保督察（扬尘/噪声）
5. **社会监督**：乘客集中投诉、人大代表建议/政协提案

**下行（缓和）事件源**（降档必须靠这些，**禁止数值跌了就自动降档**）：
1. **隐患销号**：整改复查验收通过、挂牌督办摘牌
2. **程序履约**：约谈后按期提交并完成整改方案
3. **考核激励**：年度安全生产考核优良（对应现实奖补）
4. **正面舆情**：媒体正面报道、上级调研肯定

## 3. 程序流水（硬核核心：跨日推进、文书落地，禁止同日完成）

每条链以**多日状态机**推进（在途程序存档持久化），每步必须落一条 `Notices` 公文反馈（沿用现有公文语风格，编号+机关名+文书名）：

| 链 | 步进（示例天数，进参数表可调） | 档位效果 |
|---|---|---|
| **A 检查链** | D0 检查组进驻通报 → D+3~5 下达《责令限期整改通知书》（列隐患项数） → D+7~10 复查：不合格→约谈；合格→维持 | 通知书→**升Ⅱ**；约谈→**升Ⅲ** |
| **B 舆情链** | D0 媒体曝光/报道 → D+3~5 舆情转段（热度参数） → 依风险温度计定性 | 转段→**升Ⅱ或Ⅲ** |
| **C 事故链** | D0 事故/险情通报 → D+2~5 事故调查组报告 → 依调查结论 | 一般→**升Ⅱ**；较大→**升Ⅲ** |
| **D 挂牌链**（Ⅲ→Ⅳ） | 约谈后整改验收**不合格**，或隐患逾期未改 → D+7 挂牌督办公示 | **升Ⅳ** |
| **E 摘牌链**（降档） | 提交整改方案 → D+7~14 复查验收通过 → 摘牌/销号 | **降一档** |
| **F 考核链** | 年度安全生产考核优良（360 天周期） | 直接回落至 **Ⅰ** 并保留 Notice 记录 |
| **G 危机链**（→停产停业整顿） | 沿用现 `≥0.95 听证接管倒计时`（连续 7 天未回落），但**触发载体**必须是事件文书（《责令停产停业整顿决定书》） | **升Ⅴ/末档** |

**滞回（现实性关键）**：升档 = 连续量 ≥ 阈值 **且** 对应程序事件完成；降档 = 连续量 ≤ 阈值−0.10 **且** 销号/验收事件完成——摘牌必须比挂牌难，杜绝档位反复横跳。

**文书格式示例**（进事件文案表，供你按风格铺开）：
`市交通运输局〔2076〕第14号：责令限期整改通知书——检查发现 K3+500 段护坡崩落等 3 项隐患，限 7 日内报送整改方案。`
