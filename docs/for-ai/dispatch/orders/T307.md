## 1. 核心改进清单与技术方案

### 1.1 术语交互与弹窗系统美学重构（`DialogueBox.cs`）
- **悬浮下划线交互（Hover Only）**：
  - 根除默认常驻下划线对剧情阅读体验的视觉打扰；
  - 默认状态下文字为纯净高亮（暖金色），仅当鼠标指针悬停于术语文字时，动态渲染点状虚线/实线下划线；鼠标移出即刻消失。
  - 下划线由内嵌式错位布局重构为基于文本排版基线的精准悬停挂接，彻底消除文字与下划线的重叠穿插。
- **弹窗卡片方向与位置重构（Bottom Dock）**：
  - 由原先向上弹出（常遮挡上一行对话或角色立绘视线）改为向正下方展开悬浮卡片；
  - 自动适配屏幕边界，若下方空间不足则智能翻折。
- **单人卡片口吻与头像展示（Single Avatar Card）**：
  - 移除原先冗余的多人说话人堆叠显示；
  - 卡片顶部展示术语规范词典释义，底栏直接挂载匹配的角色代表头像与角色口吻简评，去除多余姓名牌干扰。
- **弹性盒排版防御（Flex Shrink Bug Fix）**：
  - 针对长文本解释把右侧【📖 图鉴】按钮挤出卡片视界边界的 Bug，在 `termCard`、`mainRow` 与 `body` 明确声明 `flexShrink = 1`、`minWidth = 0` 及 `overflow = Overflow.Hidden`；
  - 无论术语释义文本多长，均严格在卡片内换行，右侧【📖 图鉴】跳转按钮永久稳固吸附在卡片右缘。

  - 彻底露出的上层路基放样中线、高对比度测量花杆与鲜亮信号红旗。
- **列车滑块显著加长**：

  - **松手直接就地停驻（Park）**：更新 `sbIdleThumbTarget = currentTop`，不执行任何反弹，彻底消除此前因回弹产生的拖影与闪烁残影（Ghosting）；

### 1.4 对话回顾面板第二阶段（正常滚动）自适应缩放与惯性滚动（`VNBacklog.cs`）
- **滑块上下文自适应长度动态缩放（解决图五）**：
  - 废弃原先 `Mathf.Min(110f, trackH * 0.40f)` 的 110px 刚性矮滑块限制；
  - 采用真实自适应公式 `Mathf.Clamp(scaled, 64f, trackH * 0.70f)`：
    - 当对话刚发生溢出时（条目少），滑块根据视口与内容比例舒展拉长，最高可达轨长的 70%；
    - 当对话持续增多时，滑块平滑收缩，最低保留 64px 保证机车微缩像素画精细度。
- **鼠标滚轮自由滚动与指数阻尼平滑滑行**：
  - 增加 `e.PreventDefault()` 拦截 UI Toolkit 原生 ScrollView 硬生生的 notch 步进；
  - 采用 `16ms` 连续微步动量注入，并以 `_wheelVelocity *= 0.88f` 进行阻尼指数平滑衰减，彻底消除大步长跳跃感。
- **高对比度信号车挡与石质底座**：
  - 车挡立柱提亮为银白钢结构（`#E0E0E6`），红白高反差梁与石质底座明度重调，彻底告别暗黑环境下的杂灰低对比度。
