# T318 · 触控手势与 Android 大屏适配

执行方：Antigravity；验收方：Codex；状态：待 T317 验收后由用户手动投递。规格 SHA-256：b775a816693503a2d982c6437e441b9f8da721b3076f41664d3531e7b7c936cf。

## 任务正文

在最新集成基线检查当前实现，完善并验证 Android 与 Windows 触屏手势：边缘返回、底部上滑主页、上滑停留最近任务、左/右上沿分别打开通知/控制中心。确保手势不抢音乐进度条、滚动、拖动、输入和第二触点；取消、中断和屏幕旋转后不留粘滞状态。

先建立可重复的输入边界/状态回归，再在可用设备或模拟器验证横竖屏、至少两种屏幕比例、软键盘及系统返回。如果没有真实触屏或 Android 设备，交付模拟测试与设备执行步骤，真实设备明确 NOT_RUN，不把编辑器模拟当设备通过。

允许修改 `TabletEdgeGesture.cs`、`GameMainUI.cs` 的手势/导航部分、相关编辑器测试和文档；不修改音乐业务和场景 YAML。回执追加本文件，附设备型号/系统、操作、记录、日志、回归与未验项；不提交、不推送，等待 Codex 验收。

### 一、手势判定状态机与决策树

```mermaid
flowchart TD
    TouchDown["PointerDown (touch)"] --> DirectCheck{"IsDirectManipulationTarget?<br/>(按钮/滑块/滚动/输入/音乐条/键盘)"}
    DirectCheck -- "是 (true)" --> RejectDirect["阻断手势 (blockDirect=true)<br/>原生控件接管交互"]
    DirectCheck -- "否 (false)" --> MultiCheck{"activeTouchPointers.Count > 1?<br/>(多指/第二触点)"}
    MultiCheck -- "是 (>1)" --> ResetMulti["ResetSystemGesture()<br/>多指手势抑制"]
    MultiCheck -- "否 (单指=1)" --> EdgeRegion{"触点起始边缘区域"}

    EdgeRegion -- "y <= 24px (顶沿)" --> TopSplit{"x < 宽度 * 0.5"}
    TopSplit -- "左侧下拉 (dy > 40px)" --> OpenNotify["唤出通知中心<br/>(TabletSystemPanel.Notifications)"]
    TopSplit -- "右侧下拉 (dy > 40px)" --> OpenControls["唤出控制中心<br/>(TabletSystemPanel.Controls)"]

    EdgeRegion -- "y >= 高度 - 44px (底沿)" --> BottomSwipe["向上滑动 (dy < -28px)"]
    BottomSwipe --> HoldCheck{"悬停时间 >= 0.28s?"}
    HoldCheck -- "是 (松手前即时响应)" --> OpenRecents["打开最近任务<br/>(TabletGestureAction.Recents)"]
    HoldCheck -- "否 (快速释放)" --> GoHome["返回平板桌面<br/>(TabletGestureAction.Home)"]

    EdgeRegion -- "x <= 18px 或 x >= 宽-18px (侧沿)" --> SideSwipe{"向内滑动 (|dx| > 36px)?"}
    SideSwipe -- "是" --> TriggerBack["触发系统返回<br/>(RequestSystemBack)"]
```

[设备实机验证规程 (Manual Checklist for Physical Android Tablets)]
测试基准设备：小米平板 6S Pro (12.4" 3:2) 或 联想小新 Pad Pro (12.7" 16:10) / Android 13+
1. 边缘返回 (Side Inward Back)：
