### 4. 关键交互回归用例覆盖详情

#### (1) 文本输入时打开最近任务，后台按键隔离与焦点恢复
- **用例逻辑**:
  1. 启动应用并在界面挂载 `TextField (name: "shell-review-input", value: "init_clock_input")` 并获得焦点（`root.panel.focusController.focusedElement == input`）；
  2. 打开最近任务（`OpenRecentTasks()`），验证 `recentTasksOverlay` 覆盖于最前层；
  3. 在最近任务展开期间向输入框派发按键事件（`KeyDownEvent: 'z', KeyCode.Z`）；
  4. **断言确认**: `input.value == "init_clock_input"` 严格未变，输入被根节点 capture 拦截（输出 `02-recent-tasks.png`）；
  5. 验证三类退出方式及焦点恢复：
     - **Escape 退出**: 发送 Escape，`recentTasksOverlay` 隐藏，焦点精准恢复到 `input`；
     - **系统返回退出**: 再次打开最近任务，调用 `RequestSystemBack()`，`recentTasksOverlay` 隐藏，焦点精准恢复；
     - **暗色遮罩点击退出**: 再次打开最近任务，派发 `ClickEvent` 到 `recentTasksOverlay` 外部区域，遮罩关闭，焦点精准恢复。

#### (2) 焦点销毁后的安全退回
- **用例逻辑**:
  1. 创建临时输入框 `tempInput`，聚焦并打开最近任务（或系统面板）；
  2. 模拟外部或异步销毁（`tempInput.RemoveFromHierarchy()`）；
  3. 关闭最近任务（`CloseRecentTasks()`）或系统面板；
  4. **断言确认**: 不抛出 `NullReferenceException`，UI Toolkit 焦点控制器安全退回到桌面或 root（`focusedElement != tempInput`），无悬挂引用。

#### (3) 系统面板互斥切换、关闭与再次打开
- **用例逻辑**:
  1. 打开通知中心，验证 `state.Panel == TabletSystemPanel.Notifications`，未读角标从 1 置 0；
  2. 点击控制中心按钮，面板即时切换为 `TabletSystemPanel.Controls`（通知中心关闭，控制中心开启）；
  3. 发送 Escape 关闭控制中心，验证 `state.Panel == TabletSystemPanel.None`，模糊背景即时清除；
  4. 再次打开控制中心，点击控制面板内“设置”按键，控制中心关闭并平滑过渡至设置应用；
  5. 打开通知中心并通过点击外部遮罩（`tablet-shell-scrim`）关闭，验证外点关闭正常。

#### (4) 设置子页返回、同名页替换与全部关闭后的可见层级
- **用例逻辑**:
  1. 导航进入设置应用，打开“术语图鉴”子页面（`ShowTipsPage("rail_ballast")`），验证子页面生成，设置主页暂时隐藏（输出 `05-settings-subpage.png`）；
  2. **同名页替换**: 再次请求打开同名页面（`ShowTipsPage("rail_expansion_joint")`），断言 `Pages.Count == 1`（保持栈深为 1），旧子页面直接被移除替换，不出现多重重复压栈；
  3. **子页返回**: 调用 `RequestSystemBack()`，顶层子页面弹出销毁，设置主页重新恢复 `DisplayStyle.Flex`（输出 `06-settings-parent-restored.png`）；
  4. **全部关闭**: 调用 `CloseAllTabletTasks()`，断言应用层 `appLayer.style.display == DisplayStyle.None`，桌面层 `tablet-desktop.style.display == DisplayStyle.Flex`，所有任务引用完全清空（输出 `07-desktop-all-closed.png`）。

#### (5) 跨窗口比例分辨率改变、采样前壳层隐藏与防叠防变暗
- **用例逻辑**:
  1. 打开控制面板，分别在 1440×900 (16:10) 与 1024×768 (4:3) 两种比例下切换分辨率；
  2. 修复批处理模式下的双路径模糊机制：检测到离屏 `targetTexture != null` 时由 `TriggerShellBlurCapture` 执行零延迟同步 Blit 与高斯模糊处理；
  3. 捕获重绘生命周期严格执行：采样前 `_overlay.style.opacity = 0`，采样完成后 `_overlay.style.opacity = 1`，彻底杜绝模糊采入系统浮层自身或多次叠加变暗；
  4. 断言验证：`OverlayOpacity == 1f`，小分辨率下控制面板无裁切（`xMin >= -0.1f && xMax <= 1024.1f`），并与顶部状态栏无重叠遮挡（输出 `08-controls-1024x768.png` 与 `09-notifications-1024x768.png`）。
