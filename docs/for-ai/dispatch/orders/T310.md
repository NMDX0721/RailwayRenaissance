# T310 · Play 模式代验收单：T301/T304/T307/T308 机器可测项全量核验

> **派发方式**：`assign_task` 只发指针——「请读取 `docs/for-ai/dispatch/orders/T310.md` 并原文执行」
> **任务来源**：用户 2026-10-17：「你能让 AGY 的调试会话来验收吗，代替我」——由 Antigravity 调试会话在 Unity Play 模式代跑验收，**机器可测项**全部代验；手感/审美项仅做客观记录，终审仍归用户与 MiMo。
> **铁律**：**只验不修**——发现任何问题只如实记录进回执，**禁止顺手改业务代码**（修复由 MiMo 另立整改单）；临时验证钩子/脚本必须在回执中列出并在验证结束后**删除**；**不 git commit**。
> **白名单（仅限验证期临时物）**：`Assets/Editor/` 下临时验收脚本（用后删）、Play 日志与截图输出目录 `Tools/playtest/`（新建，可保留作证据）。
> **禁改**：一切业务源码、剧本 JSON、资源。

## 0. 方法要求

1. **进 Play 模式**（Unity Editor 在你侧可驱动）；若需要推进天数，用临时 Editor/调试钩子调用 `GameData.AdvanceDay` 批量推进（**钩子属于临时物，回执列清单并删除**）。
2. **证据三件套**：①断言输出（逐项 PASS/FAIL + 关键数值快照——数值只进回执文档，不进任何 UI）②相关 `Notices` 原文摘录 ③关键界面截图（Play 模式 Game 视图，存 `Tools/playtest/`，回执给路径）。
3. **两档判定**：每项标 **机器判定 PASS/FAIL** + **客观观察**（无法机器判定的写"待人工"）。
4. 诚实原则：FAIL 不许美化；跑不起来的写清楚卡在哪。
