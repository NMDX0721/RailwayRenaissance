### 审查问题

1. **返回与输入优先级**：实体键 Escape、屏幕返回、系统面板、应用内页面/弹窗和重绑定流程是否按方案优先级执行；检查 UI Toolkit 事件传播、焦点失效、合成按键事件是否有重复关闭或误关 App 风险。
2. **任务卡与状态恢复**：切回桌面、切换 App、关闭任务、视图回收和恢复是否语义一致；滚动位置、文本草稿、焦点恢复是否可能引用已销毁元素或与数据绑定冲突；主动关闭和系统回收是否能清楚区分。
3. **内存回收**：平台 API 可用性、事件订阅/取消订阅、阈值与轮询逻辑是否存在反复回收、遗漏根节点或保留悬挂引用的风险。不要把 Windows 桌面内存压力支持假设成 Android 系统信号。
4. **触控手势**：起始边缘、手势阈值、目标控件过滤、指针类型、捕获/释放是否可能抢走滚动、拖动、Slider 或鼠标输入；判断 Windows 触屏与 Android 的路径是否都接通。
5. **通知/控制面板与导航布局**：面板互斥、叠层、scrim、关闭和焦点恢复是否一致；横屏/竖屏/窄宽度响应式布局有无遮挡或无法关闭路径。
6. **设置页重排**：分类选择器、侧栏/单列切换、搜索和滚动位置保存是否存在重建时丢状态或分类映射错误。
