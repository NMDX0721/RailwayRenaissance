## P0 · 驾驶台进去一片蓝、什么都没有（用户实测）

**首要嫌疑（Mimo 已定位，请优先验证）**：

`Assets/Scripts/Cab/CabConsoleUI.cs` L78：
```csharp
var panelSettings = Resources.Load<PanelSettings>("CabPanelSettings");
if (panelSettings != null) uiDoc.panelSettings = panelSettings;
```

**全项目不存在 `CabPanelSettings.asset`**（Mimo 已全盘搜索确认）。
而全项目其他 7 处 UIDocument 一律加载 `"UI/TitleScreenPanelSettings"`：
`GameMainUI L199` / `VNManager L329` / `MainStoryUI L59` / `TitleArchiveUI L200` / `DebugPanel L41` / `AutoLoginUI L139,L179`。

→ `panelSettings` 为 null ⇒ `UIDocument` **完全不渲染** ⇒ 整个驾驶台 UI（含 3D 视口 `Image`）一个像素都不出 ⇒ 露出底下主相机清屏色，即"蓝不拉几"。

**验证与修法**：
1. 改为 `Resources.Load<PanelSettings>("UI/TitleScreenPanelSettings")`，与其余 7 处对齐
2. 进 Play 实测：驾驶台应出现 3D 画面 + 车窗框 + 控制台
3. 若改后仍异常，按此顺序继续排查并**在回执写明实际结论**：
   - `rtDisplayImage.image` 是否绑到 `sceneController.TargetTexture`（`CabConsoleUI` L130-133）
   - `Cab3DSceneController.Initialize()` 的 `RecreateRenderTexture()` → `TargetTexture.Create()` 是否成功
   - 相机 `targetTexture` 是否指向**当前** RT（`SetResolution` 重建 RT 后是否同步，L162-169）
   - URP 下新建 Camera 是否被正确渲染（`CabCamera` 创建于 `Cab3DSceneController` L220-230）
   - `m_SceneRoot` 在 `y=-500` 独立空域，几何是否真的生成在视野内
   - `CabConsoleUI.Update()` → `UpdateUI()` 是否在跑、`sceneController` 是否被 `OnDestroy` 提前销毁

**回执必含**：根因结论（是/不是 PanelSettings）、实际改动行号、Play 实测截图描述（画面里能看到轨道/远山/站台吗）、若仍有问题列出下一步排查项。
