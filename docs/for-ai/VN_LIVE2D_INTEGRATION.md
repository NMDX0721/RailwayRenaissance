The project's main manifest requests URP 17.0.3, but its cached package source actually reports 17.5.0. The evaluation uses that cache and records the distinction; main package settings were not changed.

Normal UPM launch failed before SDK import with `The "path" argument must be of type string. Received undefined` and empty request params. `-noUpm` alone omitted package assemblies. It is a development workaround, not proof that normal package installation works.

One isolated SDK compatibility patch enables its existing `EntityId.ToULong(GetEntityId())` branch at `UNITY_6000_5_OR_NEWER`, because this installed 6.5 Editor already treats GetInstanceID as an obsolete error. The original SDK gates that branch at 6.6. Vendor runtime code is otherwise unmodified. Never silently copy this evaluation environment into the main game.

## Owned adapter source

Canonical source is under `tools/vn/live2d_integration_20261105/src/`; matching copies are compiled in the isolated project:

- `VNLive2DModelBridge`: caches real parameters and expression assets, samples actual AudioSource output into a reused buffer, gates pause/mute/listener/stop, and closes the mouth. SpeechEnabled must be supplied only for the actual voiced speaker when integrated with VNVoicePlayer.
- `VNLive2DBasePose`: when Animator is inactive, restores authored parameter defaults **after Fade but before ParameterStore/Expression/Blink**. HasUpdateController is explicit to prevent a second LateUpdate from undoing blink/expression output.
- `VNLive2DSampleReview`: creates the isolated review scene via Editor API, runs Play checks, captures 2.5K frames and exits with the result marker.

Expression asset names may end in `.exp3`; the bridge accepts the stem. Neutral uses an authored normal expression when supplied. If absent, it creates a per-instance default expression for the parameters referenced by the model's expressions, without mutating the shared asset. Setting index -1 alone was insufficient to restore this sample; earlier failed runs are retained. Owned expression data is released on destruction.

`prepare_live2d_review.py` unpacks a hash-checked original package into a fresh isolated target. `prepare_live2d_offline.py` records the offline fallback setup. These setup scripts were assembled from the successful operations; fresh end-to-end recreation has not been separately accepted. Do not rerun the pristine extractor over the compatibility-patched target.
