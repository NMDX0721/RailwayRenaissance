# 日语配音：首测制作方案

当前方案：日语对白＋中文字幕；世界观、角色身份和所在地不随语言改变。目前没有生成音频，也没有接入可直接调用的TTS服务。

字幕底层现按[多语言协议](VN_LOCALIZATION.md)支持简体中文、日本語、English主副语言组合。正式翻译放在独立语言JSON，按源句显式对齐，`textJa`仅作早期兼容。批量翻译由用户交给Gemini；Codex提供工作包、校验与少量样例。

2026-11-03补充：用户确认男主不配音；正式配音必须先准备、审校日文翻译。字幕译文与TTS发音/标签稿分离。ElevenLabs生成、重生成、保存/替换音色、删除及订阅/付费前均须用户审批，旧112积分首轮方案未获批准。岁月225条序章发言的正文依据、新提示词与试听草译见[岁月音色基准](../../参考资料/资产/岁月_日语音色与配音基准.md)。

## 建议制作顺序

1. 冻结中文台词与行ID；先翻译日文，再审校语气、人名和铁路术语读音。保存中文内容哈希，中文修订后让旧音频失效，不能按条目下标盲目套用。
2. 首批试听做岁月、老陈、嘉颖徐、佯教授四种音色，各取普通、低声和情绪台词。男主不配音；旁白与心理活动先仅文字。
3. 有授权的日语TTS音色或声优录制均可。若沿用ElevenLabs，先做一段连续场景的样片，确认音色与发音，再批量制作；不先为1170条对白全部花费生成额度。
4. 正式接入独立Voice声轨、逐句文件、音量/静音设置；切句或跳过立即停止上一句，自动阅读可等待语音结束，存读档与书签不串句。文件按稳定行ID绑定，不能和BGM/SFX混用。
5. Windows及Android平板分别试听响度、首播延迟、切句、后台暂停和内存占用，再打包。部分配音版须明确范围。

## 四个角色的试听方向

| 角色 | 音色和表演 |
|---|---|
| 岁月 | 清晰、灵活的少女声，专业术语准确；保留玩笑和细微情绪，不用夸张机械滤镜 |
| 老陈 | 年长男性，质朴、克制；着急时有气息变化，避免全程夸张沙哑 |
| 嘉颖徐 | 年轻成年女性，有底气、略带傲娇；关心常藏在直率或责备里，避免每句话都冷嘲 |
| 佯教授 | 中年男性，清楚、温和而有分量；生气差分更严厉，不靠持续吼叫 |

## 可先试听的日文台本草案

以下只提供翻译草案，不代表声音成品或正式读音定稿。

- 老陈，`prologue_01_news/0/5`：
  - 中文：再来一次……求你了，再转一把，就一把！
  - 日文：もう一度……頼む、あと一回だけ回ってくれ。たった一回でいい！
- 佯教授，`prologue_01_news/2/14`：
  - 中文：熬了整整三天三夜，你这台电脑里算来算去，果然还是那条线。
  - 日文：三日三晩、ずっと計算し続けて……結局、またあの路線か。
- 岁月，`prologue_02_day0/1/15`：
  - 中文：——神经元逻辑回路握手成功！全传感器自检通过，系统重启完成！
  - 日文：ニューロン論理回路、ハンドシェイク成功！ 全センサーの自己診断を通過。システム、再起動完了！
- 嘉颖徐，`prologue_03_journey/3/19`：
  - 中文：猴局长，好久不见。听说你的人扣了我的人。
  - 日文：局長、お久しぶりです。そちらの部下が、私の関係者を足止めしているそうですね。

人名读音仍需统一；上例嘉颖徐暂以职务称呼，不能据此把正式全篇的人名省略。日语台本中的角色语气应随场景变化，不能将所有角色统一成同一种礼貌程度。
