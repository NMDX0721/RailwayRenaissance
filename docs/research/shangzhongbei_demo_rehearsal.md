# 上海中学杯：研究场景演示预演卡

此卡依据研究场景代码整理，供展示前逐项实测；不能用已存在的自动化通过标记代替现场机器的实际预演。研究对象是简化计算机模拟器，不代表真实列车自动驾驶。

## 演示准备

- 在展示机器打开 Unity 项目与 `Assets/Scenes/CabAtoResearchReview.unity`；若场景不可用，可在编辑器中使用菜单 `RailRevival/Research/Build ATO Review` 生成研究场景。该操作会生成或更新场景，应先确认本地已有修改已妥善保存。
- 进入 Play Mode，先按现场界面和驾驶联锁完成启机、供气等准备。研究控制器的“准备完成后启用自动运行”只有在相应条件满足时才能接管；不要为演示绕过联锁。
- 面板上的“使用 V3 实验控制器”须在未自动运行、未暂停时选择；V2 保持默认。确认显示任务限速、剩余距离和状态，再选择“平稳”“省气”或“准点”。

## 可讲解的步骤

1. 指出任务是 900 m、三段限速，目标首次停稳时间 115–125 s；强调这是模拟任务参数。
2. 在条件允许时启用自动运行，观察限速、剩余距离和控制状态；运行中切换目标后，应在下一控制周期生效。现场如果没有达到这些条件，记录真实现象，不把设定当作演示结果。
3. 演示“人工接管”，确认自动运行退出。正式展示前单独验证实体操作接管；不要仅凭按钮画面推断所有人工接管路径已验收。
4. 暂停后可保存研究检查点，并在暂停状态恢复；按实际界面确认恢复状态，再继续运行。旧检查点兼容应单独准备文件验证，不能凭新检查点推断。
5. 打开研究报告中的失败轨迹与消融图，解释一次提前到达和样本不足；不要为达到演示效果隐去失败。
