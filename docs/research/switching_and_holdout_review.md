# 制动驻留约束与首次留出工况验证

2026-10-25。后续开发；用户已授权继续。改动的是ATO控制决策层，不修改 `CabSimulation` 的动力、空气制动、燃油或热管理方程。

## 实现

`CabAtoController`新增可配置 `SwitchPenalty` 与 `MinimumBrakeTicks`。进入预测控制后，若距上次切换不足最短驻留步数，排除改变首动作的候选；后续动作块仍各持续1秒。默认算法构造器保持旧参数0.15/0，以便复现；Unity研究适配器显式选用0.15/25，即最短0.5秒。

驻留约束只作用于预测阶段。提前采样、反向异常、目标越界和停稳保持有独立行为，终端保持制动可绕过驻留约束。它不是全局驾驶指令限频，更不是安全保证。FixedPoint/DistanceRule不使用该约束；结果中的参数列只表示调用时传入的配置。

## 开发集选择

`research/ato/results/tuning-switch-v5`保存9组参数比较：切换惩罚0.15/1/4，驻留0/15/25步；EarlyPredictive和AdaptivePredictive各在同54个开发工况运行，共972条记录。开发种子1000/1001，未使用测试种子选择参数。

较大惩罚降低切换，但增大误差；保留原惩罚0.15、加入25步驻留，两个方法联合平均误差约0.39m，平均切换约28.8次；原0驻留联合约0.36m、84.2次。选择侧重保留开发集亚米级精度并减少切换，并非声称该参数全局最优。

## 测试协议与可复现证据

运行前创建 `research/ato/heldout-protocol-v1.json`，然后按其参数执行；程序直接读取协议，而非在测试循环里再选择参数。协议SHA256为 `11011F0F535279682B9F9E91C00DC3BF187B3F0125320906E6D1DB85D19E89F7`，完整副本在结果目录。没有根据此次测试结果回调控制参数。

64个有限组合：种子2000/2001 ×质量0.9/1.1 ×黏着0.4/0.7 ×坡度-5/+5‰ ×距离750/1100m ×目标速度14/18m/s。五种主方法，各64条；提前固定与自适应另各加0驻留消融，共448条。相同工况初始快照一致，方法不读取真实质量、黏着或纵坡。

这是未参与调参的**工况网格**，不是64次独立实车抽样；种子中的多个状态对停车可能影响很小。不得将达标率解释为真实铁路成功概率。模型仍为原集总仿真，观察无传感噪声，未覆盖故障、响应速率失配、动态黏着突变或实车数据。初速由同一自动加速流程形成，变化的是目标速度而非直接指定停车初速。

原始数据、每工况控制周期CSV、完整Config/快照及源码副本位于 `research/ato/results/heldout-switch-v1`。`analyze.py`核对协议与源码哈希、448行及配对初态；检查2589个正常预测阶段的切换间隔，最短为25个内核步，未发现低于所设驻留时间的间隔。采样/终端转换不计入此间隔检查。

## 结果（这批有限工况）

停车成功规则：300秒内速度绝对值低于0.01m/s并持续2秒；达标规则另要求位置误差绝对值<=5m。所有方法均停稳；失败与超差不会删样本。

| 方法 | 驻留(s) | ±5m达标/64 | 平均绝对误差(m) | 平均切换数 |
|---|---:|---:|---:|---:|
| 固定点 | 不适用 | 3 | 44.238 | 9.58 |
| 距离规则 | 不适用 | 56 | 1.602 | 17.34 |
| 名义预测 | 0.5 | 52 | 2.730 | 22.95 |
| 提前固定参数预测 | 0 | 64 | 0.307 | 99.83 |
| 提前固定参数预测 | 0.5 | 64 | 0.245 | 35.77 |
| 自适应预测 | 0 | 64 | 0.338 | 76.06 |
| 自适应预测 | 0.5 | 64 | 0.247 | 23.08 |

可支持的结论：在这批工况中，0.5秒驻留约束减少了两种提前预测方案的切换，且没有降低±5m达标数。自适应方案相对自身0驻留版本，平均切换减少约69.7%。但与固定参数提前方案比较，停车误差基本相同，自适应方案甚至略高；不应宣称在线估计改善停车精度。是否具有实质平顺性或耗风收益，尚需记录加加速度与空气消耗，切换次数不能替代这些指标。

名义预测仍有12个超差工况，说明只使用“高级预测”名称不构成优势。后续应分析失败机制，不能把失败方法从主表删除。
