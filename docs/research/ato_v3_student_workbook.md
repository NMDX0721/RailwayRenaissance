## 复核一次已观察到的失败

在仓库根目录执行（需要 .NET 6 SDK）：

```powershell
dotnet run -c Release --project research/ato-v3/followup/ReplayFailure.csproj -- research/ato-v3/runs/20261028T121643698Z 63001-weak_wet_v2-AirSaving-v3-r0 tools/compile/student_failure_trace.csv
```

这会读取先前保存的初始状态和接受的命令，重新推进物理内核，写入 0.5 秒采样轨迹；它不是重新执行控制器决策，也不是新测试样本。原始结果位于 `research/ato-v3/runs/20261028T121643698Z/results.json`，查找同一个 `id`。结果中的 `arrival` 是首次进入停车窗并停稳的时间，不能用轨迹最后一行替代。可使用另一个案例 `63003-weak_wet_v2-AirSaving-v3-r0`，并给输出另取文件名。
