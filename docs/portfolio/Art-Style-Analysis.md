## 一、现有资产分析

### 1. Banner/关键视觉（home_banner.jpg）

**风格特征：**
- **媒介：** 数字绘画（仿油画/厚涂质感）
- **色调：** 暖琥珀色/金色为主，蓝绿色点缀（天空、旗帜）
- **光影：** 黄金时刻（Golden Hour）侧光，强烈的明暗对比
- **构图：** 中心对称+层次分明（前景铁轨→中景建筑→远景城市）
- **细节密度：** 极高，每个区域都有叙事元素

**可提取用于 Portfolio 的元素：**
- 色彩方案（琥珀+蓝绿的互补色运用）
- 光影处理（黄金时刻的氛围营造）
- 叙事性构图（每个细节都在讲故事）

### 2. 角色像素画（Lin, Laochen, Jiaying）

**风格特征：**
- **媒介：** 像素画（Pixel Art）
- **比例：** Q版/chibi（约 3-4 头身）
- **分辨率：** 中等（约 64-96px 高）
- **色彩：** 有限调色板，暖色调为主
- **线条：** 清晰的像素边缘，无抗锯齿
- **表情系统：** 每个角色 10+ 表情，统一风格

**技术亮点：**
- 像素画中的光影层次（2-3 级阴影）
- 面部表情的微妙变化（通过眉毛、眼睛、嘴巴的像素调整）
- 服装细节的像素化处理（铜色怀表链、工装纹理）

### 3. 环境像素画（Station, Tea House）

**风格特征：**
- **视角：** 俯视 3/4 视角（类 Stardew Valley）
- **光影：** 强烈的环境光（窗户透光、灯光）
- **材质：** 木材纹理、石板、植被、锈迹
- **氛围：** 废墟感+温暖感的平衡

**技术亮点：**
- 光影的像素化处理（窗户光束、阴影渐变）
- 植被的像素画表现（藤蔓、杂草、小花）
- 建筑细节的暗示（不需要画出每个砖块，但能感受到材质）

## 二、风格定位

### 你的风格可以描述为：

**"Narrative Pixel Art with Warm Cinematic Lighting"**
（叙事性像素画 + 温暖电影光影）

**核心特征：**
1. **暖色调主导** — 琥珀/金色/棕色，传达怀旧和温暖
2. **光影叙事** — 不只是照亮场景，而是用光影讲故事（废弃车站的夕阳 = 希望与衰落并存）
3. **有限但精心选择的调色板** — 不是颜色少，而是每个颜色都有意义
4. **像素画的"呼吸感"** — 不追求极致精细，而是让像素有呼吸的空间
5. **文化融合的视觉语言** — 中国建筑+朝鲜元素+蒸汽朋克

### 风格参考矩阵

| 你的风格 | 参考对象 | 你学到什么 | 你独特的地方 |
|----------|----------|------------|--------------|
| 暖色调像素画 | Stardew Valley | 温暖色彩的运用 | 你的色调更"电影感"，更有叙事性 |
| 角色表情系统 | Maitetsu | VN角色的表达力 | 你融合了像素画和VN两种媒介 |
| 废墟环境 | Night in the Woods | 用环境讲故事 | 你的废墟有"复兴"的希望感 |

| 电影感光影 | 宫崎骏动画 | 光影的叙事力量 | 你用像素画实现了"电影感"光影 |

## 四、色彩系统分析

### 当前调色板（从 banner 提取）

**主色调（暖色系）：**
- 深琥珀色 `#8B4513` — 木材、建筑
- 金色 `#DAA520` — 光线、温暖
- 暖棕色 `#A0522D` — 铁轨、锈迹
- 米色 `#F5DEB3` — 石板、地面

**辅助色（冷色系）：**
- 深蓝色 `#191970` — 夜空、阴影
- 青绿色 `#2F4F4F` — 植被、铜锈
- 红色 `#8B0000` — 旗帜、装饰

**点缀色：**
- 白色 `#FFFFFF` — 蒸汽、高光
- 黑色 `#000000` — 轮廓、深阴影

### 色彩运用建议

1. **保持暖色调主导** — 这是你风格的核心识别
2. **冷色只用于对比** — 不要让冷色喧宾夺主
3. **用色彩讲故事** — 暖色=希望/记忆，冷色=衰落/威胁
4. **限制总色数** — 像素画建议 16-32 色

## 五、技术规格参考

### 像素画规格

| 元素 | 建议分辨率 | 缩放倍数 | 备注 |
|------|------------|----------|------|
| 角色 | 64×96 px | 4x-6x | 保持 chibi 比例 |
| 场景 | 320×180 px | 6x (1080p) | 标准 indie 分辨率 |
| UI 元素 | 按需 | 4x | 保持像素清晰 |
| 图标 | 16×16 或 32×32 | 4x-8x | 简洁清晰 |

### 像素画规则

1. **整数缩放** — 只用 2x, 3x, 4x, 6x，不用 2.5x
2. **Nearest Neighbor** — 纹理过滤必须是最近邻
3. **对齐像素网格** — 角色和 UI 必须对齐
4. **有限调色板** — 每个角色/场景 8-16 色

## 六、Portfolio 展示建议

### 作品排列顺序

**Sustained Investigation（15张）：**

```
调研 → 实验 → 发展 → 成品 → 反思

1. 实地速写（铅笔）
2. 情绪板（拼贴）
3. 色彩实验（水彩/数字）
4. 角色草图（铅笔迭代）
5. 环境概念（马克笔）
6. 色彩方案对比
7. 像素画技法实验
8. 角色设计发展
9. 环境设计发展
10. UI 设计迭代
11. 光影实验（日/夜/晨昏）
12. 完整角色成品
13. 完整环境成品
14. 游戏截图整合
15. 自我反思
```

**Selected Works（5件）：**

```
1. Banner/关键视觉（最高完成度）
2. 角色设计图（多角度+表情）
3. 像素画场景（技法展示）
4. UI/交互设计
5. 环境概念绘画
```
