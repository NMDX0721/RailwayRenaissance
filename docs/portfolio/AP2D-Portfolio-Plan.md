# AP 2D Art & Design — Portfolio Plan

> Railway Renaissance: Sand Energy Impact — 用游戏项目构建作品集

---

## 一、AP 2D Art 要求概览

| 部分 | 内容 | 权重 | 要求 |
|------|------|------|------|
| **Sustained Investigation** | 持续调研（15张图片） | 60% | 展示实践、实验、修改的过程；附 1200 字 Artist Statement |
| **Selected Works** | 精选作品（5件成品） | 40% | 展示最高水平的完成度 |

**关键理解：** 15张图片不必都是成品。可以是 8-10 件成品 + 过程图（草图、迭代、实验）。评审看重的是**探索过程**，不只是最终结果。

---

## 二、你的 Sustained Investigation 主题建议

### 推荐主题

**"Railway Renaissance: Visual Storytelling Through Game Design"**
（铁路复兴：通过游戏设计进行视觉叙事）

**Investigative Question（调研问题）:**

> How can pixel art and visual novel aesthetics be used to explore themes of cultural heritage, technological change, and human resilience in a fictional East Asian setting?

这个主题的优势：
1. **有深度** — 不只是"画好看的角色"，而是探讨视觉艺术如何服务于叙事
2. **有范围** — 聚焦于一个具体项目，但涵盖多种媒介（像素画、角色设计、环境设计、UI）
3. **有个人意义** — 你的游戏融合了中朝文化，有真实的个人动机
4. **有实验空间** — 可以展示从传统媒介（铅笔速写）到数字媒介（像素画）的完整工作流

## 四、Artist Statement 框架（1200 字）

### Part 1: 你的调研问题（600 字）

**结构建议：**

1. **开头（100字）** — 用一个具体的观察或经历引入
   > 例："When I first visited the abandoned railway station in [你的城市], I noticed how the afternoon light filtered through broken windows, illuminating dust particles that floated like memories..."

2. **调研问题（200字）** — 清晰陈述你的核心问题
   - 你对什么感到好奇？
   - 你想通过艺术探索什么？
   - 为什么这个问题对你重要？

3. **背景与动机（200字）** — 你的个人联系
   - 为什么选择铁路主题？
   - 中朝文化融合的背景
   - 游戏作为媒介的选择理由

4. **方法论（100字）** — 你如何探索
   - 实地考察 → 资料研究 → 概念设计 → 数字实现 → 迭代修改

### Part 2: 你的实践过程（600 字）

**结构建议：**

1. **发现（200字）** — 调研中学到了什么
   - 视觉参考如何影响你的设计决策
   - 色彩、光影、构图的实验结果

2. **挑战与解决（200字）** — 遇到了什么困难，如何克服
   - 像素画的技术挑战
   - 在限制中创造表达
   - 多种媒介的整合

3. **成长与反思（200字）** — 这个项目如何改变了你
   - 对视觉叙事的理解
   - 对艺术在游戏中的角色的认识
   - 未来方向

## 五、调研矩阵（填写你的素描本）

### 事实调研（Factual Research）

| | 一手（Primary） | 二手（Secondary） |
|------|-----------------|-------------------|
| **内容** | - 实地考察：去一个真实的火车站（最好是老站），拍照+速写<br>- 采访：问长辈关于绿皮火车的记忆<br>- 体验：坐一次老式火车，记录感受 | - 中国铁路发展史资料<br>- 朝鲜铁路现状（纪录片、新闻）<br>- 蒸汽机车技术手册<br>- 《铁道》《火车》等纪录片 |
| **时间** | 周末安排 1-2 次 | 2-3 周收集 |
| **产出** | 速写本 3-5 页 + 照片 20-30 张 | 参考图文件夹 + 笔记 |

### 视觉调研（Visual Research）

| | 一手（Primary） | 二手（Secondary） |
|------|-----------------|-------------------|
| **内容** | - 摄影：火车/铁轨/车站的光线和材质<br>- 速写：公共场所人物动态<br>- 色彩采集：从实景中提取调色板 | - Maitetsu 截图分析<br>- Stardew Valley 美术风格分析<br>- 像素画教程（Lospec, Pixelation）<br>- 宫崎骏列车场景参考<br>- Night in the Woods 环境设计 |
| **工具** | 手机相机 + 速写本 + 水彩/马克笔 | Pinterest 看板 + Aseprite |
| **产出** | 参考照片库 + 色彩样本 | 风格分析笔记 + 参考图库 |

### 艺术家调研（Artist Research）

| | 一手（Primary） | 二手（Secondary） |
|------|-----------------|-------------------|
| **内容** | - 如果可能，联系独立游戏开发者，了解他们的美术工作流<br>- 参加本地像素画/游戏开发聚会 | - 像素画艺术家作品分析（eBoy, Pixel Boy）<br>- 独立游戏美术总监访谈<br>- 涩谷员子（FF像素画大师）作品研究<br>- 冯梦波、曹斐等中国游戏艺术先例 |
| **产出** | 访谈记录（如果有） | 艺术家分析笔记 3-5 篇 |

## 七、Selected Works（5件精选）规划

这 5 件应该是你最高完成度的作品，建议：

1. **环境设计** — 雾峰村全景或车站内部（最高完成度的数字绘画）
2. **角色设计** — 主角林彪悍的完整设计图（多角度+表情+服装细节）
3. **像素画场景** — 游戏内场景截图（展示像素画技法）
4. **UI/交互设计** — 游戏界面设计（展示设计思维）
5. **关键视觉** — Banner/海报级作品（你的最高水平）
