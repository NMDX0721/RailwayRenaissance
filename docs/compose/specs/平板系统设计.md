## 一、设计原则

| 维度 | 决策 | 理由 |
|------|------|------|
| 屏幕 | **16:9 横屏**（平板横置） | 用户明确 |
| 字体 | **Zpix 像素字体**（主） | 与游戏风格统一 |
| 视觉风格 | 澎湃液态玻璃 → **像素化演绎** | 半透明面板+渐变色图标+微交互动画 |
| 朝鲜特供 | 锁屏扫脸 → "主体护目镜"式扫脸动画 | 呼应澎湃扫脸+朝鲜审查味 |
| 状态信息 | 顶部状态栏（时间/日期/信号/电量） | 平板常态 |
| 唯一入口 | **平板桌面 = 游戏的唯一入口** | 开机→锁屏→解锁→桌面，在桌面上操作一切 |

### 1.1 像素风 + 玻璃质感混合

**保留的像素元素：**
- zpix字体（系统字体不变）
- Unicode像素图标（鉄、岁、R、购等）保持不变
- 江南水乡壁纸主题保持不变

**新增的玻璃质感元素：**
- 半透明面板：所有弹窗/窗口/设置页面使用 `rgba(15, 12, 18, 0.75)` 半透明深色背景 + 高斯模糊
- 状态栏：半透明背景 + 模糊效果
- Dock栏：半透明毛玻璃背景
- 小部件：半透明卡片 + 圆角加大至16px
- 图标：保留unicode字符，但背景改为渐变色圆角矩形（2.5D感）
- 窗口系统：从硬边框改为柔和阴影 + 半透明边框
- 锁屏：大胆字体 + 半透明时间显示

## 二、App 分类体系

App分三类，命名风格和交互深度完全不同：

| 类别 | 命名规律 | 来源 | 交互深度 |
|------|---------|------|---------|
| **系统自带** | 小米真名（相册/音乐/笔记/设置） | 澎湃32预装 | 全功能交互 |
| **朝鲜本土化** | 朝鲜品牌名（阿里郎/未来网/白头疫苗） | 特供版预装 | 可交互（有朝鲜特色功能） |
| **第三方** | 商业软件品牌感（RDA/归途/媒姬百科） | 嘉颖徐基金/APK安装 | 全功能交互 |

### B.1 彩蛋：系统管控恢复实验

澎湃32出厂时，朝鲜按审查铁律替换了小米原生应用。玩家在「设置」→「应用管理」底部可找到隐藏条目"已禁用的系统应用（4个）"，点击展开后有"恢复"按钮。

**四个被替换的应用及恢复效果：**

| 原小米应用 | 朝鲜替换版 | 恢复后第一次打开 |
|-----------|-----------|----------------|
| 小米应用商店 | 阿里郎商店 | 商店Logo闪现0.3秒 → 黑屏 → 朝鲜风格弹窗："该应用已被系统管控替代·阿里郎商店提供全部应用服务·非授权应用将被记录并上报" → 跳转阿里郎商店 |
| 小米浏览器 | 未来网 | Chrome风格首页闪现 → 弹窗："外部网络连接已被防火墙拦截·请使用未来网浏览内网资源" → 强制打开未来网 |
| 小米安全中心 | 白头疫苗 | 盾牌Logo闪现 → 弹窗："安全服务已由白头疫苗统一管理·原服务已停用" → 跳转白头疫苗 |
| 小米云服务 | (已移除) | 黑屏2秒 → 弹窗："云服务不可用·设备已离线·请联系系统管理员" → 无跳转，死路 |

**朝鲜风格弹窗样式**（复刻真实红星OS行为）：
- 顶部：红色警告图标 + 朝鲜文标题（시스템 관리 경고）
- 正文：简体中文"该应用已被系统管控替代"
- 底部：系统版本号（澎湃OS 32 · DPRK Edition）
- 按钮：只有"确定"，不可拒绝

**累进惩罚机制：**

| 恢复次数 | 反应 |
|---------|------|
| 第1个 | 正常重定向 |
| 第2个 | 弹窗出现加速 |
| 第3个 | "检测到反复尝试恢复受限应用·已上报国家安全局" |
| 第4个 | 黑屏3秒 → 显示时间胶囊："有些东西会停，有些东西不会。" → "系统异常·已自动恢复出厂设置" → 所有恢复的应用被重新替换 |

**现实原型**：红星OS——试图禁用杀毒/防火墙 → 弹出错误信息或系统自动重启；阿里郎手机——系统应用全部替换为朝鲜版本，禁止安装第三方应用。

## 四、App详细功能性规格

### 4.1 RDA（铁路行车调度助手）⭐ P0

**现实原型**：小米AI语音助手"小爱同学"（HyperOS深度整合）
**全名**：铁路行车调度助手·RDA（Railway Dispatch Assistant）
**来源**：嘉颖徐铁路基金内部开发，内网分发APK

**命名双关**：Railway Dispatch Assistant = Ri Dispatch Algorithm（爷爷林悍的调度算法）
**版本迭代（叙事）**：RDA可后续更新，嘉颖徐团队持续开发新功能（AI辅助/预测性维护/自动排班），版本号随剧情推进升级——软件在成长，铁路在活过来。

#### 功能模块

| 模块 | 功能 | 描述 |
|------|------|------|
| **运营总览** | 每日报告 | 显示当日运营数据摘要（客流、收入、信任度变化趋势） |
| | 快捷操作 | 一键切换班次、一键维修、一键发车 |
| **调度面板** | 班次管理 | 查看/调整列车班次时刻表 |
| | 线路管理 | 查看已开通线路状态、规划新线路 |
| | 实时监控 | 当前运行列车位置、准点率 |
| **员工面板** | 人员列表 | 查看所有员工状态（技能/疲劳/满意度） |
| | 岗位调配 | 拖拽式岗位分配 |
| | 招募入口 | 进入招募界面 |
| **财务面板** | 收支报表 | 日/周/月收支明细 |
| | 资金余额 | 当前资金+趋势图 |
| | 补贴状态 | 政府补贴发放情况 |
| **车辆面板** | 机车状态 | NF-5耕牛等机车的维护状态 |
| | 维护计划 | 预防性维护提醒 |
| **沙能分析** | 竞争态势 | 铁路vs沙能的数据趋势对比 |
| | 渗透率图 | 各城市沙能渗透率可视化 |

#### 交互设计

- 点击桌面RDA图标→弹出窗口（720×420）
- 窗口内为多Tab面板（运营/调度/员工/财务/车辆/沙能）
- 首次打开→用户名输入界面（叙事：嘉颖徐基金要求实名注册）
- 版本号显示在设置页："RDA v1.0.0 · 嘉颖徐铁路基金"

## 十一、平台适配

### 11.1 Android平台

| 问题 | 影响 | 解决方案 |
|------|------|---------|
| **返回手势** | 从屏幕左/右边缘滑动→触发Android系统返回→直接退出游戏 | Unity设置：`Input.backButtonLeavesApp = false`；或在AndroidManifest中禁用系统手势区域 |
| **底部导航栏** | 三键导航栏占用屏幕空间 | 全屏沉浸模式：`Screen.fullScreen = true` + Android全屏flag |
| **触屏交互** | 平板桌面的点击/hover适合触屏 | 天然适配，无需特殊处理 |
| **屏幕比例** | 不同Android设备屏幕比例不同 | UI Toolkit自适应布局（已有） |

**关键修复**：Android返回手势问题
```xml
<!-- AndroidManifest.xml -->
<activity android:excludeFromRecents="true"
          android:theme="@style/UnityThemeSelector">
    <!-- 禁用系统返回手势 -->
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity>
```
或者在Unity中：
```csharp
// 禁用Android返回键退出
Input.backButtonLeavesApp = false;
```

### 11.2 Windows平台

| 问题 | 影响 | 解决方案 |
|------|------|---------|
| **鼠标交互** | 平板桌面设计为触屏，鼠标操作不够自然 | 增加鼠标hover效果（已有）+ 右键菜单（可选） |
| **窗口模式** | 默认窗口模式下平板效果打折 | 默认全屏模式 |
| **分辨率** | 不同显示器分辨率不同 | UI Toolkit自适应 + ScreenScaler |
| **键盘快捷键** | 键盘操作需要映射 | 空格=解锁/确认，ESC=返回/关闭，方向键=导航 |

**鼠标→触屏映射**：
- 鼠标左键 = 触屏点击（已有）
- 鼠标hover = 触屏长按预览（可选）
- 鼠标滚轮 = 页面滚动
- 无需右键菜单（平板没有右键）

| 策略 | 描述 |
|------|------|
| **输入抽象层** | 统一处理触屏/鼠标/键盘输入，上层代码不感知具体设备 |
| **手势冲突检测** | 检测是否在Android/iOS边缘区域，禁用系统手势 |
| **自适应布局** | 所有UI使用相对定位+锚点，不硬编码像素位置 |
| **平台检测** | `Application.platform` 运行时检测，调整交互方式 |
