## 一、沙能公司行为模型

沙能不是"随机事件"，而是一个有自身策略的AI对手。

### 1.1 沙能渗透率（核心变量）

每城市独立维护 `sand_penetration[city]`，范围 0-1。

```
初始值：0.15（大废线4年后，沙能已占据大部分市场）
自然增长：+0.0015/天（约0.045/月，0.54/年）
```

### 1.2 沙能AI行为轮

每30天为一个"沙能行动轮"，执行以下行为之一：

| 行为 | 触发条件 | 效果 | 玩家应对 |
|------|---------|------|---------|
| 广告攻势 | 渗透率<0.30 | 渗透率+0.05，信任-0.03 | 公关反击（消耗500沙币） |
| 免费试乘 | 渗透率0.30-0.50 | 渗透率+0.03，乘客-10%（持续7天） | 提升服务品质 |
| 战略合作 | 渗透率>0.50 | 渗透率+0.02，获取政府补贴 | 政治游说 |
| 价格战 | 任何时间 | 收入-15%（持续14天） | 差异化服务 |
| 收购试探 | 渗透率>0.60 | 触发"收购事件" | 选择抵抗/接受/谈判 |

## 二、对抗沙能的手段

### 2.1 公关手段

| 手段 | 成本 | 效果 | 冷却期 |
|------|------|------|--------|
| 社区宣传 | 200沙币 | 信任+0.02 | 7天 |
| 媒体合作 | 500沙币 | 信任+0.05，沙能渗透-0.02 | 14天 |
| 政治游说 | 1,000沙币 | 政治压力-0.05 | 30天 |
| 铁路文化节 | 2,000沙币 | 信任+0.08，短期客流+20% | 60天 |

### 2.2 运营手段

| 手段 | 效果 | 副作用 |
|------|------|--------|
| 降价竞争 | 吸引乘客回流 | 收入-20% |
| 提升服务 | 提升信任 | 成本+15% |
| 接驳合作 | 共享客流 | 沙能渗透速度+50% |
| 差异化定位 | 避开正面竞争 | 市场受限 |

### 2.3 剧情手段（推荐）

通过完成特定剧情任务，获得对抗沙能的手段：
- 收集沙能事故证据 → 媒体曝光，沙能信任-0.10
- 争取市长支持 → 政策保护，沙能扩张受限60天
- 铁路联盟 → 多条线路联合，谈判筹码增加

## 三、沙能渗透的影响

| 渗透率 | 影响 |
|--------|------|
| 0.00-0.20 | 轻微影响，铁路仍是主要交通方式 |
| 0.20-0.35 | 客流开始流失，收入-10% |
| 0.35-0.50 | 显著影响，收入-20%，政治压力+0.10 |
| 0.50-0.65 | 严重威胁，收入-35%，沙能开始收购线路 |
| 0.65-0.80 | 危机状态，线路可能被强制停运 |
| 0.80-1.00 | 铁路在该城市实质上已死亡 |

## 四、沙能公司关键事件

| 事件 | 触发条件 | 描述 | 玩家选择 |
|------|---------|------|---------|
| 沙能入驻 | 游戏第30天 | 沙能公司在相邻城市设点 | 观望/应对/提前合作 |
| 广告攻势 | 第60天 | 大规模广告投放 | 反击/无视/合作 |
| 价格战 | 第90天 | 沙能降价50% | 跟降/差异化/接驳 |
| 收购要约 | 渗透>0.60 | 沙能提出收购线路 | 接受/抵抗/谈判 |
| 沙能事故 | 随机 | 沙能载具发生重大事故 | 补刀/沉默/帮助 |
| 政策摇摆 | 政治周期 | 新市长支持沙能/铁路 | 游说/适应/对抗 |
