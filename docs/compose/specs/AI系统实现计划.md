# AI系统实现计划

> 版本：v1.0  
> 设计原则：先做模板化AI，本地模型作为后期优化，不阻塞核心玩法开发

---

## 一、实现策略

### 阶段1：模板化AI（MVP，当前阶段）

不使用任何外部AI模型，所有文本由预置模板+参数填充生成。

**实现方式**：
```
新闻模板："{city}{事件类型}，{影响描述}"
示例："雾峰村发生机车故障，导致列车停运2天"
```

**模板管理系统**：`Resources/Templates/` 目录下JSON文件

### 阶段2：本地AI服务（开发期）

使用Python FastAPI + llama-cpp-python本地服务。

**架构**：
```
Unity客户端 → HTTP请求 → FastAPI服务 → 本地模型(.gguf)
```

### 阶段3：嵌入式推理（发行期）

使用llama.cpp DLL或Unity Sentis嵌入游戏。

## 二、阶段1详细设计（当前实现）

### 2.1 新闻模板

```json
{
  "type": "accident",
  "templates": [
    {
      "city": "{city}",
      "headline": "{city}铁路发生{事故类型}，{影响}",
      "body": "据本站消息，{city}铁路于昨日发生{事故类型}。{详细描述}。{后续影响}",
      "effects": {"trust": -0.05, "money": -2000}
    }
  ]
}
```

### 2.2 NPC对话模板

```json
{
  "character": "老陈",
  "context": "first_meeting",
  "lines": [
    "孩子，你终于回来了...",
    "这条线，我守了四年了。",
    "你爷爷要是知道你来，一定很高兴。"
  ]
}
```

### 2.3 任务描述模板

```json
{
  "type": "repair_task",
  "templates": [
    "{city}的{设备}需要维修，{人物}请求你的帮助。",
    "检查发现{问题}，需要{材料}才能修复。",
    "修复完成后，{奖励描述}。"
  ]
}
```
