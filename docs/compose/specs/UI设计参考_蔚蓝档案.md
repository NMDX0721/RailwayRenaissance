## 一、核心设计语言（Design DNA）

### 1.1 八大签名元素

| # | 元素 | 说明 |
|---|------|------|
| 1 | **半透明白色面板 + 菱形几何纹理** | 面板呈水晶/玻璃质感，背景若隐若现 |
| 2 | **细线角标**（○ △ ✚ ✕） | 面板四角的几何装饰符，兼作功能提示 |
| 3 | **黄色下划线强调** | 类别标签下方的金色细线，标记信息层级 |
| 4 | **平行四边形/斜切卡片** | 卡片带轻微斜切或透视旋转（5-8°），打破死板 |
| 5 | **对角分割构图** | 界面左右分区用 25-30° 斜线切割，制造动感 |
| 6 | **冷色调为主的配色纪律** | 蓝/白/灰主调，唯一暖色 = 金色（奖励/货币） |
| 7 | **磨砂玻璃导航栏** | 半透明白底 + backdrop-blur，悬浮在内容上方 |
| 8 | **大圆角 + 软阴影** | 对话框 14-20px、按钮 8-12px 圆角，柔和浮起 |

### 1.2 配色体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 主蓝 | `#4A90D9` / `#3A7BD5` | 导航、选中态、按钮 |
| 天青 | `#5BC0EB` → `#A8E6FF` | 主要按钮渐变（主行动） |
| 浅蓝背景 | `#D6E8F7` → `#E8F0FA` | 页面背景渐变 |
| 深蓝文字 | `#1A2B4A` / `#1E2D4A` | 标题、正文 |
| 灰文字 | `#8A9BB5` / `#6B7C8D` | 描述、次要信息 |
| 金色 | `#E8C84A` / `#FFD54F` | 奖励、货币、强调下划线 |
| 青色 | `#4FC3F7` | 能量/科技强调 |
| 红色 | `#E74C3C` | 完成印章、警报、Combat 徽章 |
| 白色 | `#FFFFFF` | 卡片、按钮文字 |
| 遮罩 | `rgba(0,0,0,0.65)` | 弹窗背景变暗 |

### 1.3 排版层级

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| L1 页面标题 | 24-28pt | Bold | "Main Story" |
| L2 章节标题 | 18-22pt | Bold | 章节名 |
| L3 副标题/描述 | 12-14pt | Regular | 剧情摘要 |
| L4 数字/指标 | 14-16pt | Semi-bold | 资源、编号 |
| 按钮文字 | 16-18pt | Bold | CTA |

**字体风格**：几何无衬线（Noto Sans / Source Han Sans 风格），中文用思源黑体风格，数字可等宽。

### 2.2 章节卡片规格

| 元素 | 规格 |
|------|------|
| 形状 | 平行四边形（skew ~5-8°），圆角 8-12px |
| 阴影 | `0 4px 20px rgba(30,60,100,0.15)` |
| 缩略图 | 梯形 clip（上宽下窄），背景插图 |
| 标题条 | 卡片底部白色渐变条 ~60-70px 高，含章节名 |
| "Clear" 徽章 | 左上角半透明蓝底白字胶囊，~4px 圆角 |
| 进度符 | 底部 ○+×△ 三枚小符号（解锁/进行中/完成/锁定） |
| 选中态 | 金色/黄色发光描边 |

### 2.3 右侧章节列表面板

| 元素 | 规格 |
|------|------|
| 面板 | 半透明白 `rgba(255,255,255,0.85)` 宽 ~200-220px |
| 区块头 | "▼ Prologue" 带下拉三角 |
| 列表项 | 44-48px 高，左侧蓝色竖线标记选中 |
| 编号 | 左侧 浅蓝灰 数字（01/02/03） |

### 2.4 关键交互态

| 状态 | 视觉 |
|------|------|
| 完成 | "Clear" 徽章 + 绿色/蓝色标记 |
| 选中 | 金色发光描边、面板蓝色左border |
| 锁定 | 暗色 + 锁图标（后续章节） |
| Combat | 红色菱形徽章 + 剑图标（我们无此类型，跳过） |

## 七、设计禁忌（避免破坏风格）

1. **不要用暖色做主调**——冷色调是 BA 风格的根基，金色只用于奖励/强调
2. **不要用直角元素**——所有交互元素保持圆角
3. **不要加重型边框**——用阴影和透明度分层，不用粗描边
4. **不要堆叠纯色大块**——背景必须分层（渐变+纹理+几何）
5. **不要用 emoji 图标**——用细线几何符号（○△✚✕），保持一致性

## 八、本土化融入方案（铁路复兴版）

> 2026-08-19 确认
> 核心原则：**不照搬 BA 外观**，移植其设计**手法**，套进我们的**暖棕像素铁路风**（Zpix 字体、暖棕 #1A0F0A 面板、金色 #FFDC96 边框）。

### 8.1 手法 → 铁路意象映射

| BA 手法 | 我们如何融入 | 铁路意象来源 |
|---------|-------------|-------------|
| 菱形几何纹理 | → **枕木/铁轨纹理**（横木+道砟，淡描边不抢戏） | 铁路枕木 |
| 细线角标 ○△✚✕ | → **铁路信号符号**（信号灯/道岔箭头/扳道标志） | 铁路信号机 |
| 黄色下划线 | ✅ 保留（本就更符合我们的金色调） | 已有金色边框 |
| 平行四边形卡片 | → **车票据样式**（斜切票根 + 齿孔边缘） | 老式火车票 |
| 冷色纪律 | → 保持暖棕主调，**青绿色只做"沙能科技"点缀** | 沙能发光体 |
| 磨砂玻璃导航栏 | → **旧茶色玻璃窗效果**（半透明暖棕 + 斑驳质感） | 老站台玻璃窗 |
| ○+×△ 进度符 | → **三色信号灯**（绿=解锁/黄=进行中/红=锁定） | 铁路信号机 |
| Reward 金色斜体 | ✅ 保留（金色 + 星光粒子符合庆典氛围） | 已有金色 |
| 对角分割构图 | → **铁轨透视斜切**（列车运行视角透视线） | 铁路轨道 |

### 8.2 各界面落地差异

| 界面 | 现在 | 融入后 |
|------|------|--------|
| MainStory 章节卡片 | 直角矩形暖棕 | **斜切票根卡片 + 枕木纹理边** + 信号灯状态符 |
| 话列表右侧面板 | 平铺矩形 | **旧站台玻璃质感**（半透明暖棕），选中=绿色信号灯 |
| 话结束过渡横幅 | 黑遮罩+横幅 | 保持，横幅加 **金色下划线 + 四角铁路信号角标** |
| 奖励弹窗 | 无 | **深棕底 + 金色斜体标题 + 星光粒子 + 青色(沙能)发光线** |
| VN 右上角 Auto/Menu | 深棕按钮 | 保留暖棕，按钮加 **信号灯式选中态**（绿=激活） |
| 背景装饰 | 纯色 | 加 **枕木纹 + 轨道透视线** 淡纹理 |
| 站长日志 | 暖棕面板 | 页签分隔线改 **铁轨式**，成就卡片加信号灯角标 |

### 8.3 明确的"不融入"（保持我们特色）

- ❌ 蓝白冷色调主背景 —— 我们保持暖棕
- ❌ 玻璃拟态（backdrop-blur）—— 像素风用旧玻璃质感替代
- ❌ 圆形头像/角色肖像框 —— 我们用像素立绘
- ❌ "Clear"蓝色徽章 —— 用我们的"已解锁"金色标签
- ❌ 圆角过多 —— 像素风保持小圆角，票据齿孔边缘才是签名

| 优先级 | 改造项 | 复杂 |
|--------|--------|------|
| P0 | 话结束过渡横幅：四角铁路信号角标 + 金色下划线 | 低 |
| P0 | 奖励弹窗：深棕+金色斜体+沙能青色发光线 | 中 |
| P1 | MainStory 卡片改车票据样式（斜切+齿孔）+ 信号灯状态符 | 中 |
| P1 | 右侧话列表面板：旧站台玻璃质感 + 绿信号灯选中 | 低 |
| P2 | 背景枕木纹 + 轨道透视线 | 低 |
| P2 | VN Auto/Menu 信号灯式选中态 | 低 |
