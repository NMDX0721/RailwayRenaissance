## 一、设计哲学

### 1.1 沙能 AI 不是一个"数字"，是一个"对手"

传统经营游戏的竞争系统是：**有一个数字叫"竞争度"，数字大了就发事件**。玩家和这个数字之间没有真正的博弈，只有"花钱消灾"。

千里马对手 AI 要做的是：**沙能是一个有自身策略的对手，它会思考、会学习、会针对玩家的弱点出击**。

### 1.2 核心原则

```
1. 沙能 AI 有自己的"目标"——不是随机捣乱，而是追求利润最大化
2. 沙能 AI 会"观察"玩家——玩家扩张哪里，沙能就渗透哪里
3. 沙能 AI 会"记忆"——玩家上次反击了，这次换策略
4. 沙能 AI 会"升级"——随着游戏推进，行为越来越激进
5. 沙能 AI 会"犯错"——沙能也会出事故，给玩家反击机会
```

## 二、沙能公司设定

### 2.1 USET 企业信息

| 属性 | 内容 |
|------|------|
| 全称 | 联合沙能科技（United Sand Energy Technology） |
| 总部 | 平壤 |
| 成立 | 2050年 |
| 性质 | 国际合资企业，控股方为朝鲜国家资本 |
| 社训 | "沙能千里马，前进再前进" |
| 产品线 | 飞猪号（民用）、沙驴号（通勤）、沙鸡号（紧凑）、沙牛号（货运）、沙熊号（SUV） |

### 2.2 沙能 AI 的"内部动机"

从游戏机制角度，沙能 AI 的决策可以理解为追求以下目标（从高到低优先级）：

```
1. 利润最大化（优先）→ 选择渗透率高的城市→价格战
2. 市场扩张（优先）→ 选择渗透率低的城市→广告攻势
3. 消除竞争（次要）→ 玩家做得好→针对性行动
4. 政治影响（次要）→ 政治压力高→游说政府
5. 危机应对（被动）→ 沙能出事故→低调处理
```

## 三、沙能 AI 行为模型

### 3.1 核心变量：沙能渗透率

```
每城市独立维护 penetration[city]，范围 0-1。

初始值：0.15（大废线4年后，沙能已占据大部分市场）
自然增长：+0.0015/天（约0.045/月，0.54/年）
自然衰减：-0.0005/天（沙能自身事故/口碑下降）

影响因素：
  玩家行动：
    - 公关活动：-0.02/次
    - 提升服务品质：-0.005/天（持续）
    - 沙能事故曝光：-0.10/次
  
  沙能 AI 行动：
    - 广告攻势：+0.05/次
    - 免费试乘：+0.03/次
    - 战略合作：+0.02/次
```

### 3.2 沙能 AI 决策树

```
每 30 天执行一次"沙能行动轮"：

Step 1: 评估全局态势
  - 计算每个城市的渗透率
  - 计算玩家在每个城市的"铁路健康度"（信任+车况+服务）
  - 识别"薄弱城市"（渗透率低但玩家健康度也低）
  - 识别"关键城市"（渗透率高或玩家健康度高）

Step 2: 选择策略
  ┌─ 如果全局渗透率 < 0.30 ──────────────────────────────┐
  │  策略：广告攻势（扩张）                                 │
  │  目标：渗透率最低但玩家防御最弱的城市                   │
  │  效果：渗透率+0.05，信任-0.03                          │
  │  玩家应对：公关反击（500沙币，-0.02渗透率）             │
  └───────────────────────────────────────────────────────┘
  
  ┌─ 如果全局渗透率 0.30-0.50 ────────────────────────────┐
  │  策略：免费试乘（施压）                                 │
  │  目标：玩家收入最高的城市                              │
  │  效果：渗透率+0.03，客流-10%（持续7天）                 │
  │  玩家应对：提升服务品质（成本+15%，抵消效果）           │
  └───────────────────────────────────────────────────────┘
  
  ┌─ 如果全局渗透率 > 0.50 ──────────────────────────────┐
  │  策略：价格战（收割）                                  │
  │  目标：渗透率>0.50且玩家依赖度高的城市                  │
  │  效果：收入-15%（持续14天）                             │
  │  玩家应对：差异化服务/接驳合作/政治游说                 │
  └───────────────────────────────────────────────────────┘
  
  ┌─ 如果玩家最近3次行动都进行公关反击 ────────────────────┐
  │  策略：收购试探（针对性）                               │
  │  目标：玩家资金最紧张的城市                             │
  │  效果：触发"收购事件"，要求玩家选择                      │
  │  玩家选择：抵抗（消耗2000沙币）/ 接受（失去线路）/ 谈判  │
  └───────────────────────────────────────────────────────┘

Step 3: 执行行动
  - 根据策略选择具体行动
  - 更新渗透率
  - 触发对应的叙事事件
  - 记录本次行动，供下次决策参考
```

## 四、对抗手段系统

### 4.1 公关手段

| 手段 | 成本 | 效果 | 冷却 | 条件 |
|------|------|------|------|------|
| 社区宣传 | 200沙币 | 信任+0.02，渗透率-0.005 | 7天 | 无 |
| 媒体合作 | 500沙币 | 信任+0.05，渗透率-0.02 | 14天 | 信任>40 |
| 政治游说 | 1,000沙币 | 政治压力-0.05，渗透率-0.01 | 30天 | 资金>2000 |
| 铁路文化节 | 2,000沙币 | 信任+0.08，客流+20%（7天） | 60天 | 信任>50 |

### 4.2 运营手段

| 手段 | 效果 | 副作用 | 条件 |
|------|------|--------|------|
| 降价竞争 | 客流+15%，但沙能渗透-0.01 | 收入-20% | 资金>3000 |
| 提升服务 | 信任+0.03/天，渗透-0.005/天 | 成本+15% | 有乘务员≥2级 |
| 接驳合作 | 客流+5%，沙能渗透-0.005 | 沙能渗透速度+50%（长期代价） | 无 |
| 差异化定位 | 避开正面竞争，稳定性+10% | 市场增长受限 | 无 |

### 4.3 剧情手段

| 手段 | 触发条件 | 效果 | 来源 |
|------|----------|------|------|
| 沙能事故曝光 | 沙能发生事故时选择"补刀" | 沙能信任-0.10，渗透-0.05 | 剧情选择 |
| 争取市长支持 | 完成特定支线任务 | 政策保护60天，沙能扩张受限 | 支线剧情 |
| 铁路联盟 | 连接3个以上城市 | 多条线路联合，谈判筹码增加 | 玩法解锁 |
| 技术展示 | 完成科技树研发 | 信任+0.10，沙能渗透-0.03 | 科技树 |

## 六、沙能关键事件时间线

### 6.1 预设事件

| 时间 | 事件 | 内容 | 玩家选择 |
|------|------|------|----------|
| 第30天 | 沙能入驻 | 沙能公司在相邻城市设点 | 观望/应对/提前合作 |
| 第60天 | 广告攻势 | 大规模广告投放 | 反击/无视/合作 |
| 第90天 | 价格战 | 沙能降价50%，持续14天 | 跟降/差异化/接驳 |
| 渗透>0.60 | 收购要约 | 沙能提出收购某线路 | 抵抗/接受/谈判 |
| 随机 | 沙能事故 | 沙能载具发生重大事故 | 补刀/沉默/帮助 |
| 政治周期 | 政策摇摆 | 新市长支持沙能或铁路 | 游说/适应/对抗 |

### 6.2 动态事件

```
动态事件由沙能 AI 根据世界状态自行触发：
  - 玩家扩张太快 → 沙能针对性阻击
  - 玩家资金紧张 → 沙能价格战
  - 玩家信任高 → 沙能广告攻势
  - 沙能渗透停滞 → 沙能战略合作
```
