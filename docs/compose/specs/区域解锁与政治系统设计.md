## 一、区域解锁系统

### 1.1 区域结构

```
区域0：雾峰村（新手区，初始解锁）
  ├── 线路：雾峰村-乌金岭线（23km）
  ├── 城市：雾峰村（人口8,000）、乌金岭（人口4,000）
  └── 解锁条件：无（初始）

区域1：青溪镇（第1个解锁区域）
  ├── 线路：雾峰村-青溪镇线（45km）
  ├── 城市：青溪镇（人口12,000）
  ├── 解锁条件：运营>60天 + 资金>50,000沙币 + 完成剧情"老陈的请求"
  └── 新功能：货运专列解锁

区域2：云渡港（第2个解锁区域）
  ├── 线路：青溪镇-云渡港线（80km）
  ├── 城市：云渡港（人口25,000）
  ├── 解锁条件：运营>120天 + 信任>0.65 + 完成剧情"市长的邀请"
  └── 新功能：旅游专线解锁、政治系统开启

区域3：白鹭洲（第3个解锁区域）
  ├── 线路：云渡港-白鹭洲线（150km）
  ├── 城市：白鹭洲（人口50,000）
  ├── 解锁条件：运营>200天 + 累计盈利>100,000 + 完成剧情"铁路联盟"
  └── 新功能：多线路运营、科技树分支选择

区域4：枫林渡（第4个解锁区域）
  ├── 线路：白鹭洲-枫林渡线（120km）
  ├── 城市：枫林渡（人口35,000）
  ├── 解锁条件：运营>300天 + 选择科技树分支
  └── 新功能：重型货运、工厂合作

区域5：望海港（最终区域）
  ├── 线路：白鹭洲-望海港线（200km）
  ├── 城市：望海港（人口40,000）
  ├── 解锁条件：运营>450天 + 完成全部主线剧情
  └── 新功能：国际贸易、終局内容
```

### 1.2 解锁流程

```
玩家满足条件 → 触发剧情事件 → 剧情任务链 → 完成 → 区域解锁
                                              → 失败 → 可重复尝试
```

## 二、政治系统

### 2.1 政治倾向变化

政治倾向不是一个固定值，而是随时间周期性变化。

| 周期 | 持续时间 | 倾向 | 特点 |
|------|---------|------|------|
| 初始 | 0-180天 | 中立 | 标准补贴，无特殊政策 |
| 周期1 | 180-360天 | 随机（威权/市场/福利） | 根据前期玩家行为加权 |
| 周期2 | 360-540天 | 与前周期不同 | 倾向变化，玩家需适应 |
| 周期3+ | 540天+ | 随机 | 周期缩短为120天 |

### 2.2 政治倾向效果

| 倾向 | 补贴 | 竞争环境 | 玩家策略 |
|------|------|---------|---------|
| 威权 | 补贴+30% | 强制调度，收入-20% | 稳定优先，减少扩张 |
| 市场 | 补贴-20% | 自由竞争，价格浮动 | 效率优先，积极扩张 |
| 福利 | 补贴+50% | 效率下降，运输时间+10% | 长期投资，稳健发展 |

### 2.3 政治事件

| 事件 | 触发 | 效果 |
|------|------|------|
| 市长选举 | 每180天 | 政治倾向可能变化 |
| 政策调整 | 每90天 | 当前倾向下的政策微调 |
| 突发危机 | 随机 | 信任下降/财政压力增加 |
| 铁路法案 | 运营>365天 | 决定铁路命运的投票 |
