# 站长日志（合集菜单）设计

> 版本：v2.0  
> 更新：2026-08-19 — 新增音乐鉴赏、故事章节回看、场景鉴赏、书签管理  
> 位置：标题界面 btn-archive（站长日志），VN 内也可通过 Menu 打开  
> 实现：`Assets/Scripts/TitleArchiveUI.cs`（独立 UIDocument，DontDestroyOnLoad 单例）

---

## 一、定位

"站长日志"是游戏的收藏/鉴赏合集——玩家解锁过的所有内容都可以在这里回顾：
- 已解锁的 CG 插画（CG鉴赏）
- 已获得的成就（成就系统）
- 已解锁的音乐（音乐鉴赏，可播放）
- 已解锁的故事章节（故事回看）
- 已解锁的场景（场景鉴赏）
- 已收集的角色/列车档案（图鉴）
- 运营统计（统计）
- 书签管理（手动书签查看/跳转）

---

## 二、菜单结构

```
站长日志（独立面板）
├── 成就（Achievements）     — 7个成就，有限定度标签
├── CG鉴赏（Gallery）        — 9个CG插画，点击全屏查看
├── 音乐（Music）            — 13首音乐，子分类(全部/BGM/歌曲)，底部悬浮播放器
├── 故事（Stories）          — 10话章节回看，点击跳转 VN 重播
├── 场景（Scenes）           — 9个场景，随进度解锁
├── 图鉴（Collection）       — 角色档案 + 列车档案
└── 统计（Stats）            — 运营统计
```

---

## 三、数据源

| 数据 | 来源 | 存储 |
|------|------|------|
| 成就 | `AchievementManager.cs` | PlayerPrefs `Achievements_Data` |
| CG | `Resources/bg/*` 或 `Resources/cg/*` | PlayerPrefs `ArchiveCG_*` |
| 音乐 | `Resources/bgm/*` | PlayerPrefs `ArchiveMusic_*` |
| 故事 | prologue JSON 脚本 | PlayerPrefs `ArchiveStory_*` |
| 场景 | `Resources/bg/*` | PlayerPrefs `ArchiveScene_*` |
| 图鉴 | 角色/列车数据表 | PlayerPrefs `ArchiveChar_*` / `ArchiveTrain_*` |
| 统计 | `StatsManager.cs` | PlayerPrefs 跨会话累计 |

---

## 四、解锁绑定

所有解锁在 `TitleArchiveUI.AutoUnlock(scriptName)` 中统一管理，由 VNManager 在进入序章脚本时自动调用。详见 `书签与经营记录系统设计.md`。
