# 站长日志（标题界面合集菜单）设计

> 版本：v1.0  
> 位置：标题界面 btn-archive（站长日志）  
> 性质：类似视觉小说的 EXTRA/一览界面，是成就、鉴赏、收集的集合  
> 关联：经济系统.md §9.5 成就系统、CharacterProfile、VN剧本

---

## 一、定位

"站长日志"不是运营日志，而是**标题界面的收藏/鉴赏合集**——玩家解锁过的内容都在这里回顾：
- 已解锁的 CG 插画（鉴赏）
- 已收集的角色档案（图鉴）
- 已获得的成就（成就系统）

给玩家"我走过这段路"的回顾感，也是长期游玩的目标激励。

---

## 二、菜单结构

```
站长日志（btn-archive）
├── ① 成就（Achievements）
│     按经济系统.md §9.5 成就表实现
├── ② 鉴赏（Gallery/CG）
│     已解锁的 CG 插画，未解锁显示剪影占位
├── ③ 图鉴（Collection）
│     角色档案 / 列车档案 / 背景档案
└── ④ 存档记录（若有）——暂缓
```

## 三、成就系统（来自经济系统.md §9.5）

### 3.1 荣誉成就（展示用）

| 成就 | 条件 | 稀有度 |
|------|------|--------|
| 铁路新人 | 完成第一个月运营 | 普通 |
| 安全之星 | 连续90天无事故 | 稀有 |
| 服务大师 | 乘客满意度连续30天>90 | 稀有 |
| 培养专家 | 培养1名员工从1级到5级 | 史诗 |
| 铁路复兴者 | 首次月度盈利10万 | 史诗 |
| 铁路企业家 | 累计盈利100万 | 传说 |
| 铁路传奇 | 完成所有终极目标 | 传说 |

### 3.2 功能性成就（影响游戏）

| 成就 | 奖励 |
|------|------|
| 安全之星 | 事故概率-20% |
| 服务大师 | 广告收入+50% |

| 铁路复兴者 | 解锁新线路 |
| 铁路企业家 | 解锁多线路运营 |

```json
{

    "railway_newbie": {"unlocked": true, "unlockedDate": "2076-05-12"},
    "safety_star":    {"unlocked": false},
    "service_master": {"unlocked": false},
    "mentor_expert":  {"unlocked": false},
    "revivalist":     {"unlocked": false},
    "entrepreneur":   {"unlocked": false},
    "legend":         {"unlocked": false}
  }
}
```

存储：`PlayerPrefs` 或 `Saves/achievements.json`

## 六、实现方案

### 6.1 新文件

- `Assets/Scripts/TitleArchiveUI.cs` — 站长日志面板（UI Toolkit 动态构建）
- `Assets/Scripts/AchievementManager.cs` — 成就数据与判定

### 6.2 复用

- 已有 UI 资源（button_primary 等）做面板
- CG 直接引用 `Resources/bg/*` 已有背景

### 6.3 入口

`TitleScreen.cs` 的 `OnArchive()` 从 `SceneManager.LoadScene("VN_Test")` 改为 `archiveUI.Show()`

## 七、优先级

| 子项 | 优先级 | 说明 |
|------|--------|------|
| 成就列表 UI | P1 | 数据来自经济系统.md，静态展示先做 |
| 成就数据管理 | P1 | AchievementManager 判定与持久化 |
| CG 鉴赏 UI | P2 | 依赖背景图资源到位 |
| 角色图鉴 UI | P2 | 依赖立绘资源到位 |
| 解锁联动 | P2 | 序章播放时标记解锁 |
