# 书签与经营记录系统设计 v1.0

> 2026-08-19
> 替代旧版存档系统，解决"线性推进"与"自由回看"的冲突

---

## 一、核心原则

1. **阅读位置**和**经营状态**完全分离，各自独立管理
2. 书签只存 VN 内的阅读位置，经营记录只存经营界面的游戏状态
3. 回看章节时**不写经营记录**，不覆盖书签
4. 话完成后自动书签自动销毁，从头回看通过 MainStoryUI 重新播放

---

## 二、书签系统

### 2.1 自动书签

| 属性 | 说明 |
|------|------|
| 创建时机 | 进入新话时自动创建 |
| 更新方式 | 阅读时自动推进（每次 NextDialogue 时更新位置） |
| 最大数量 | 5 个（滚动销毁最旧的） |
| 销毁时机 | 话完成时自动销毁 |
| 特殊处理 | 强制退出时保留，下次进入提示"是否继续观看？" |

**数据结构：**
```
AutoBookmark
├── scriptName: string    // 脚本名（如 prologue_03_journey）
├── sceneIndex: int       // 场景索引
├── dialogueIndex: int    // 对话索引
├── episodeNum: int       // 话数（显示用）
├── episodeTitle: string  // 话标题（显示用）
├── updatedAt: string     // 更新时间
└── isCompleted: bool     // 是否已完成
```

### 2.2 手动书签

| 属性 | 说明 |
|------|------|
| 创建时机 | 玩家在 VN 中点击 Menu → 书签按钮 |
| 创建方式 | 点击 Menu 展开的书签按钮 → 自动创建（不中断阅读流程） |
| 命名 | 可自定义名称（默认"第X话 · 当前台词摘录"） |
| 数量 | 不限 |
| 保留 | 永久保留，不自动销毁 |
| 管理 | 在书签管理器中查看，点击跳转回看 |

**书签内容必须包含：**
- 话数（第X话）—— 玩家看话数就知道在哪
- 话标题（如"边境危机"）
- 当前台词摘录（存档时自动截取当前对话文本，作为书签内容预览）
- 场景索引 + 对话索引（跳转用）

**数据结构：**
```
ManualBookmark
├── id: string            // 唯一ID
├── name: string          // 书签名（可自定义，默认自动生成）
├── scriptName: string    // 脚本名
├── sceneIndex: int       // 场景索引
├── dialogueIndex: int    // 对话索引
├── episodeNum: int       // 话数（必填，否则记不得位置）
├── episodeTitle: string  // 话标题（必填）
├── previewText: string   // 当前台词摘录（存档时自动截取）
├── note: string          // 备注（可选）
├── createdAt: string     // 创建时间
└── updatedAt: string     // 最后更新时间
```

### 2.3 书签管理器

- 独立 UI 面板，可从 VN 菜单和站长日志中打开
- 显示自动书签（最多 5 个）和手动书签（全部）
- 自动书签标记"自动"标签，手动书签显示自定义名称
- 点击书签 → 跳转 VN 回看（只读模式，不写经营记录）
- 自动书签已完成的显示"已完成"，不可点击跳转
- 手动书签可编辑名称/删除

## 三、经营记录系统

### 3.1 自动存档

| 属性 | 说明 |
|------|------|
| 触发时机 | 每日结束时自动保存 |
| 槽位 | 1 个（自动覆盖） |
| 内容 | 游戏状态（天数/资金/信任/机车状态等） |

### 3.2 手动存档

| 属性 | 说明 |
|------|------|
| 触发时机 | 玩家主动保存 |
| 槽位 | 6 个 |
| 显示 | 槽位显示日期、天数、资金预览 |
| 覆盖 | 玩家选择槽位时显示已有存档信息 |

### 3.3 数据结构

```
SaveData
├── slot: int              // 槽位编号（0=自动存档）
├── day: int               // 当前运营天数
├── money: long            // 当前资金
├── trust: float           // 当前信任度
├── trainCondition: int    // 机车状态
├── expectedPassengers: int // 预期客流
├── unlockedChapters: string[]  // 已解锁的剧情章节
├── completedChapters: string[] // 已完成的剧情章节
├── savedAt: string        // 保存时间
└── version: string        // 游戏版本
```

### 3.4 继续运营流程

```
标题画面 → 继续运营 → 显示经营记录列表（自动存档+手动存档槽位）
                                    ↓
                          选择存档 → 加载经营状态 → 进入 GameMainUI
```

## 四、书签与经营记录的关系

```
                    ┌─────────────────┐
                    │   经营记录系统    │
                    │  (自动+手动存档)  │
                    └────────┬────────┘
                             │ 保存经营状态
                             ↓
                    ┌─────────────────┐
                    │   GameMainUI    │
                    │  (模拟经营界面)  │
                    └────────┬────────┘
                             │ 事务→剧情
                             ↓
                    ┌─────────────────┐
                    │  MainStoryUI   │
                    │  (话列表)       │
                    └────────┬────────┘
                             │ 选择一话→播放
                             ↓
                    ┌─────────────────┐
                    │  VNManager     │
                    │  (只读模式)     │  ← 回看不写经营记录
                    └────────┬────────┘
                             │ 创建/更新书签
                             ↓
                    ┌─────────────────┐
                    │   书签管理器    │
                    │  (自动+手动)     │
                    └─────────────────┘
```

---

## 五、话完成后的销毁流程

```
第X话 播放完毕
  │
  ├→ 自动书签标记 isCompleted = true
  ├→ 继续链式播放下一话 → 创建新的自动书签
  │
  └→ 如果是最后一话 → 返回 GameMainUI
       → 自动书签销毁（因为从头回看不需书签）
```

---

## 六、强制退出处理

```
玩家强制退出游戏
  │
  ├→ 自动书签保留（当前阅读位置）
  │
  └→ 下次进入游戏
       ├→ 检测到未完成的自动书签
       └→ 提示"检测到未完成的剧情，是否继续观看？"
            ├→ 是 → 跳转到书签位置继续
            └→ 否 → 进入 GameMainUI，自动书签保留
```
