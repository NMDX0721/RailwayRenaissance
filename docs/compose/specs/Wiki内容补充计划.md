## [S4] 页面模板规范

**结构统一**（延续现有页风格）：

1. 有立绘条目：`<img src="images/xxx.png" width="300" style="float:right">` + wikitable 信息框
2. 无立绘条目（赵铁山/陈鹤年/林悍/王小弟/城市/势力/载具/系统/剧情）：文字信息框或纯文本数据表，**不配图、不编造素材**
3. 正文章节：简介 → 数据表 → 剧情/游戏内作用 → 底部回链

**系统页速览式**（每页 1-2 屏）：

| 章节 | 内容 |
|------|------|
| 定位 | 该系统在游戏中的作用（1 段） |
| 核心机制 | 机制表（名称↔效果↔对应数值节点） |
| 主要数值 | 3-8 个关键数值/阈值 |
| 联动 | 与哪些系统交互 |
| 详见 | 原始设计文档链接 |

**补建英文页**：提取合并页英文内容，补充到 1-2 屏，底部回链 `Home`（注意：非 `Home-EN`，v1.1 修正）。
