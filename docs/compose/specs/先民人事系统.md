# 先民人事系统（Seonmin Personnel System）

> 版本：v1.0  
> 设计原则：减少数字化输入，像现实一样——疲劳和忠诚不出现在界面上，而是通过言行流露。  
> 关联：角色设定.md、沙本位经济核.md、跨系统联动公式.md

---

## 一、设计哲学

> 每位员工是一个"人"，不是一串数值。技能数字可见，但疲劳和忠诚不可见——玩家通过观察员工言行来推断。

**核心原则**：
1. **技能可见**——玩家知道员工能做什么、有多强、潜力多大
2. **疲劳不可见**——玩家看不到数值，只能通过行为变化推断
3. **忠诚不可见**——玩家看不到数值，通过员工言行、加班态度、事故反应感知
4. **独立成长曲线**——每项技能有独立的成长速度和难度
5. **国际铁路标准职级**——基于真实铁路行业职级命名

## 五、隐藏机制

### 5.1 疲劳系统（内部数值，不显示在界面上）

> 疲劳是内部状态，玩家看不到数字。疲劳通过行为流露：连续加班后员工说话变少、出错率上升、事故后反应更激烈。

| 连续工作天数 | 效果（内部） |
|--------------|------------|
| 1-5天 | 正常 |
| 6-10天 | 专注度-10%，事故概率+5% |
| 11-15天 | 专注度-25%，事故概率+10% |
| 16+天 | 强制休息3天 |

**代码实现**：`CrewManager.cs` 中 `CrewMember.fatigue` 字段，每日 +10

### 5.2 满意度系统（内部数值，不显示在界面上）

| 因素 | 影响/月 |
|------|---------|
| 工资准时发放 | +5 |
| 工作环境改善 | +3 |
| 长期拖欠工资 | -10 |
| 事故发生 | -15 |
| 连续工作无休息 | -5 |

| 满意度 | 效果 |
|--------|------|
| 90-100 | 效率+10%，拒绝离职 |
| 70-89 | 正常 |
| 50-69 | 效率-10%，可能抱怨 |
| 30-49 | 效率-25%，可能罢工 |
| 0-29 | 强制离职 |
