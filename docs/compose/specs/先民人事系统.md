# 先民人事系统（Seonmin Personnel System）

> 版本：v2.0  
> 设计原则：减少数字化输入，像现实一样——疲劳和忠诚不出现在界面上，而是通过言行流露。  
> 关联：角色设定.md、沙本位经济核.md、跨系统联动公式.md
> 代码状态：⚠️ 基础数据结构已实现，隐藏机制和成长系统未实现

## 一、设计哲学

> 每位员工是一个"人"，不是一串数值。技能数字可见，但疲劳和忠诚不可见——玩家通过观察员工言行来推断。

### 1.1 可见与不可见

| 属性 | 可见性 | 展示方式 | 设计理由 |
|------|--------|----------|----------|
| 技能等级 | ✅ 可见 | 数字（1-5级） | 玩家需要知道谁适合做什么 |
| 技能潜力 | ✅ 可见 | 星级（1-5⭐） | 玩家需要知道培养谁值得 |
| 岗位 | ✅ 可见 | 文字标签 | 玩家需要知道谁在做什么 |
| **疲劳** | ❌ 不可见 | 无数字，通过行为流露 | 像现实一样，你看不到同事的"疲劳HP" |
| **忠诚** | ❌ 不可见 | 无数字，通过态度感知 | 你看不到员工的"忠诚进度条" |
| 工资 | ✅ 可见 | 数字 | 玩家需要做成本预算 |

### 1.2 行为流露机制

疲劳和忠诚不显示数字，而是通过以下方式"流露"：

```
疲劳度高时：
  - 对话文本变化："今天有点累了..." → "不太舒服" → "...（沉默）"
  - 语音语调变化（文本描述）："声音正常" → "声音疲惫" → "声音沙哑"
  - 操作效率下降：从100%逐渐降到60%
  - 事故率上升：从基准值逐渐升到3倍
  - 极端情况：强制休息（"老陈今天没来上班"）

忠诚度低时：
  - 对话变得敷衍："嗯" → "好的" → "随便吧"
  - 拒绝加班："今天想早点走"
  - 事故后态度变化：从"积极处理"到"抱怨"
  - 极端情况：离职（"小芳留下了辞职信..."）
```

| 岗位 | 核心技能 | 最低等级 | 建议人数 | 技能匹配加成 | 不匹配惩罚 |

| 司机 | 驾驶 | 3级 | 1-2人 | +20%效率，事故率-30% | 等级不足：效率×0.5，事故率×2 |
| 机械师 | 维修 | 2级 | 1人 | +20%效率，维护成本-15% | 等级不足：维护成本+30% |
| 乘务员 | 服务 | 1级 | 1-2人 | +15%效率，信任+0.005/天 | 不匹配：信任-0.005/天 |
| 站务员 | 管理 | 1级 | 1-2人 | +10%效率，售票效率+10% | 不匹配：客流-5% |
| 调度员 | 管理 | 2级 | 1人 | +15%效率，准点率+10% | 不匹配：准点率-10% |

### 3.2 初始配置困境

**只有5人、5个岗位，人手全面紧张**：

| 问题 | 现状 | 影响 |
|------|------|------|
| 司机缺口 | 只有老陈(5级)够格 | 无法轮班，老陈疲劳风险极高 |
| 机械师独苗 | 只有张工(5级) | 张工请假=无人维修 |
| 无人替补 | 每个岗位刚好1人 | 任何一人请假会影响运营 |

**解决方案**：玩家必须选择一种分配策略，每种策略都有代价。

### 4.2 成长速度影响因素

```
每日经验 = 基础经验 × 岗位匹配系数 × 师傅系数 × 培训系数

基础经验：
  - 在岗工作：+1.0 天/天（匹配岗位）
  - 不在岗工作：+0.2~0.5 天/天（不匹配岗位）
  
岗位匹配系数：
  - 核心技能匹配：×1.0
  - 非核心但相关：×0.5
  - 完全不相关：×0.2

师傅系数（师傅带徒）：
  - 有师傅指导：×1.5
  - 师傅等级≥4级：×2.0
  - 无师傅：×1.0

培训系数（主动培训）：
  - 每7天可培训1次
  - 培训消耗：200 沙币/次
  - 培训效果：+3.0 天/次（驾驶）、+4.0 天/次（维修）
```

## 五、隐藏机制详解

### 5.1 疲劳系统

**数值模型**（内部，不显示）：

```
每日疲劳增长 = 10（基础值）
  - 如果连续工作 > 7天：额外 +5/天
  - 如果岗位是司机：额外 +3/天（司机更累）
  - 如果当日有事故：额外 +15

每日疲劳恢复 = 5（休息日恢复 30）
  - 如果安排了休息日：当日疲劳不增长，恢复 30
  - 如果当日有培训：疲劳增长减半（培训=休息）

疲劳阈值（内部）：
  0-30：正常，效率100%，无副作用
  31-60：效率-10%，事故概率+5%，对话开始变化
  61-80：效率-25%，事故概率+15%，可能请假
  81-100：强制休息，对话明显疲惫
```

**行为流露对照表**：

| 疲劳区间 | 对话示例 | 行为表现 |
|----------|----------|----------|
| 0-30（正常） | "今天精神不错！" | 正常操作 |
| 31-60（轻度） | "有点累了..." | 偶尔走神，效率略降 |
| 61-80（中度） | "不太舒服，想休息一下" | 操作变慢，容易出错 |
| 81-100（重度） | "......"（沉默） | 强制休息，可能引发事故 |

### 5.2 忠诚度系统

**数值模型**（内部，不显示）：

```
忠诚度变化（每日）：
  - 工资按时发放：+0.1/天
  - 工资拖欠：-1.0/天
  - 事故发生（该员工涉及）：-5.0/次
  - 连续工作 > 10天无休息：-1.0/天
  - 获得培训：+2.0/次
  - 职位晋升：+5.0/次
  - 特殊事件（剧情）：±10.0
```

**惯性修正**（v2.0 新增）：
忠诚度有惯性系数 **0.15**——历史低忠诚度会使涨薪效果打折扣，员工需要时间重新信任你。

```
当日忠诚变化 = 理论变化 × (1 - 0.15) + 30天忠诚均值 × 0.15 × 0.1
```

**遗留问题**：当忠诚度 < 30 持续 5 天 → 员工获得"离职倾向"标记。即使后续忠诚度恢复，仍有 10% 概率在 30 天内主动离职。该标记可通过持续 30 天高忠诚度（>70）消除。

**核心体验**：长期压榨员工 → 即使今天涨工资，员工仍然半信半疑。历史伤害需要时间愈合，"过去的选择"在人事系统中尤为明显。

忠诚度影响：
  90-100：效率+10%，拒绝离职，积极加班
  70-89：正常效率，正常状态
  50-69：效率-10%，可能抱怨，拒绝加班
  30-49：效率-25%，可能罢工，准备离职
  0-29：强制离职（"xx留下了辞职信..."）

**行为流露对照表**：

| 忠诚区间 | 对话示例 | 行为表现 |
|----------|----------|----------|
| 90-100（忠诚） | "放心，有我在。" | 主动加班，事故时积极处理 |
| 70-89（正常） | "好的，我知道了。" | 正常工作 |
| 50-69（冷淡） | "嗯。"（敷衍） | 下班就走，事故时抱怨 |
| 30-49（不满） | "工资什么时候发？" | 可能罢工，事故时推卸责任 |
| 0-29（敌对） | "我不干了。" | 离职 |

## 六、招聘与流失系统

### 6.1 招聘

```
触发条件：线路扩张、员工离职、玩家主动招聘
招聘渠道：
  - 社区推荐：（免费，但技能随机）冷却30天
  - 广告招聘：（500沙币，技能较好）冷却15天
  - 猎头推荐：（2000沙币，高技能概率）冷却60天

新员工属性：
  - 年龄：20-50岁随机
  - 技能：1-3级随机（受渠道影响）
  - 潜力：1-4级随机
  - 初始忠诚：50
  - 初始疲劳：0
```

### 6.2 流失

```
触发条件：
  - 忠诚度 < 30：离职概率 10%/天
  - 忠诚度 < 0：立即离职
  - 特殊事件：剧情安排的离职/退休
  - 年龄 > 65：退休概率 1%/月

离职后果：
  - 该岗位空缺，效率下降
  - 可能需要调整其他员工岗位
  - 剧情触发（如果离职员工是核心角色）
```
