## 一、定位：创世核在游戏底层中的角色

### 1.1 一句话定义

> 千里马创世核是**一切游戏世界差异的底层来源**。它在每次新游戏开局时生成三样不可见但永久存在的东西：**城市依赖图、资源分布逻辑、政治倾向**。这三样东西决定了整个游戏世界可能发生什么、不可能发生什么。

### 1.2 创世核不是"随机种子"

❌ 不是"随机数种子"——不是为了"每次开局数值不同"（那是 RNG，RNG 是骰子，不是世界）。

✅ 是**结构种子**——它生成的是**世界骨架**（城市之间的依赖关系、资源分布的类型、政治结算的方式），所有后续系统（经济、叙事、竞争、人事）都在这个骨架之上生长。同一事件在不同骨架上有完全不同的含义。

### 1.3 创世核的产出物

创世核的输出是一个**世界种子数据包（WorldSeedData）**，包含以下不可变结构：

```
┌────────────────────────────────────────────────────────────┐
│  千里马创世核 —— 世界种子数据包                            │
│                                                             │
│  ├─ 城市依赖图（City Dependency Graph）                    │
│  │   城市列表 + 依赖关系（有向图） + 产业类型 + 人口        │
│  │   → 消费端：经济核（货物流动/收入）、事件系统（事件链） │
│  │   → 消费端：区域解锁（城市顺序）、铁龙竞争（城市渗透） │
│  │                                                         │
│  ├─ 资源分布逻辑（Resource Distribution）                  │
│  │   集中型/分散型/政治干预型 + 关键节点                    │
│  │   → 消费端：经济核（波动/瓶颈）、订单系统（货运类型）    │
│  │   → 消费端：叙事引擎（事件类型倾向）                     │
│  │                                                         │
│  ├─ 政治倾向（Political Tendency）                         │
│  │   全局倾向 + 城市级倾向 + 周期长度                       │
│  │   → 消费端：政治系统（结算公式）、叙事引擎（政策事件）  │
│  │   → 消费端：铁龙竞争（渗透速度）、经济核（补贴系数）    │
│  │                                                         │
│  └─ 五条趋势线初始值（Initial Trends）                     │
│      信任/财政/渗透/政治/老化 初始值 ± 抖动                 │
│      → 消费端：GameData（趋势线起始）、叙事引擎（基调）     │
│                                                             │
│  ├─ 物理线路边（Rail Edges）                                │
│  │   城市间实际铁路连接 + travel_time + capacity             │
│  │   → 消费端：经济核（运力/运费）、时间系统（旅行时间）    │
│  │   → 消费端：事件系统（线路中断事件）                     │
│  │                                                         │
│  ├─ 全局规则（Global Rules）                                │
│  │   事件基准概率/信任自然衰减/宏观参数                     │
│  │   → 消费端：EventManager（事件概率基准）                  │
│  │   → 消费端：GameData（信任自然衰减率）                   │
│  │                                                         │
│  ├─ 政治好感度（Political Favor）+ 稳定性（Stability）      │
│  │   政府好感(0-1) + 结算触发条件                           │
│  │   → 消费端：政治系统（结算公式触发）                     │
│  │   → 消费端：叙事引擎（政策事件倾向）                     │
└────────────────────────────────────────────────────────────┘
```

## 三、世界生成算法（完整版）

### 3.1 算法总流程

```
输入：int seed（0-99999）
输出：WorldSeedData（JSON序列化）

流程：
1. 初始化确定性随机引擎 R = System.Random(seed)
2. 生成城市坐标（4-7个城市，随机散布在800×600地图上）
3. 为每个城市分配类型（保证至少1 mining + 1 agriculture）
4. 为每个城市分配产业（按类型预定义，R加1个随机产业）
5. 生成城市依赖图（有向图闭环，见3.2）
6. 生成资源分布逻辑（按概率权重抽样，见3.3）
7. 生成全局+城市级政治倾向（见3.4）
8. 生成五条趋势线初始值（基准±R抖动，见3.5）
9. 分配城市到区域（以坐标+人口决定，见3.6）
10. 计算关键节点（被依赖次数最多的城市）
11. 输出 JSON
```

### 3.2 城市依赖图生成（核心算法）

```
输入：城市ID列表，产业列表，R
输出：依赖关系（有向图）

步骤：
1. 为每个城市确定主要产出资源（按type映射）：
   - agriculture → tea / rice / wool
   - mining → coal / iron / copper
   - industrial → machinery / steel / electronics
   - port → shipping / import_goods / trade
   - tourism → culture / hospitality / scenic

2. 为每个城市确定需要进口的资源（不能与产出重叠）：
   - 枫林渡需要 coal/iron/copper（来自mining）
   - 农业城需要 machinery（来自industrial）
   - 矿业城需要 machinery、shipping（来自industrial/port）
   - 望海港需要 trade_goods（来自industrial/agriculture）
   - 旅游城需要 culture_goods（来自industrial/agriculture）
   
3. 构建依赖边（有向）：城市A需要X → 找到产出X的城市B → 边 A→B
   - 优先选择距离最近的城市（减少运输成本叙事）
   - 若最近城市没有X，扩大到次近
   - 若没有城市产出X，随机指定一个城市"产出X"
   
4. 验证闭环（强连通检验）：
   - 从任意城市出发，沿依赖边是否能回到起点？
   - 否 → 重新分配依赖目标（改B为另一个城市）
   - 最多3次重试，之后强制添加一条反向边保证闭环
   
5. 计算依赖度：
   - 入度 = 被多少城市依赖（关键节点）
   - 出度 = 依赖多少城市（脆弱度）
   - bottleneck_risk = 入度最高城市的入度 / 城市总数
```

### 3.3 资源分布逻辑生成

```
patterns = ["concentrated", "dispersed", "political"]
weights = [0.35, 0.35, 0.30]
pattern = weighted_sample(patterns, weights, R)

concentrated（集中型）：
  critical_nodes = 入度最高的1-2个城市
  bottleneck_risk = 0.35
  效果：单点中断→全图瘫痪，风险高但效率高
  
dispersed（分散型）：
  critical_nodes = []（无关键节点）
  bottleneck_risk = 0.10
  效果：断一条线影响不大，但依赖链长、效率低

political（政治干预型）：
  critical_nodes = 高价值资源城市（如 mining/industrial）
  bottleneck_risk = 0.25
  government_intervention_prob = 0.15
  效果：政府介入多，税率/限运/征用概率高
```

### 3.4 政治倾向生成

```
全局政治倾向：
  patterns = ["authoritarian", "market", "welfare"]
  weights = [0.30, 0.40, 0.30]
  tendency = weighted_sample(patterns, weights, R)

城市级倾向（political_lean）：
  - 以全局倾向为基准，R决定是否偏移 ±1 级
  - 偏移概率 30%：
    - authoritarian → market（向温和偏移）
    - market → welfare 或 authoritarian
    - welfare → market（向市场化偏移）

政治周期长度：
  base = 180
  cycle_length = base + R.Next(-30, 31)  // 150-210天
```

### 3.5 五条趋势线初始值

```
基准值表：
  信任 (Trust)         : 0.62 ± 0.05
  财政压力 (Fiscal)    : 0.30 ± 0.05
  沙能渗透 (Sand)      : 0.15 ± 0.05  ← 取城市级渗透的加权均值
  政治压力 (Political) : 0.20 ± 0.05
  设施老化 (Decay)     : 0.30 ± 0.05

抖动方式：R.NextDouble() * 波动范围 * 2 - 波动范围（对称抖动）
```

### 3.6 城市→区域分配

```
依照区域解锁系统（区域解锁与政治系统设计.md §1.1）：
  区域0（初始）：雾峰村 + 乌金岭（自动解锁）
  区域1：青溪镇（人口>8000 且 距雾峰<200km 的最近城市）
  区域2：云渡港（人口>20000 且 最近的港口/枫林渡市）
  区域3：白鹭洲（人口>40000 且 行政/金融类型）
  区域4：枫林渡（工业类型，且距白鹭洲<300km）
  区域5：望海港（港口类型，距白鹭洲>200km）

若种子生成的城市少于6个，则区域3-5用同一城市"承载"多个区域身份。
```

## 四、世界产物 → 各系统联动规格

### 4.1 经济核联动

| 创世核产出 | 消费方 | 消费方式 |
|-----------|--------|----------|
| 城市人口 | 沙本位经济核 | 客流公式基础人口 = city.population × 0.0025 |
| 城市产业 | 沙本位经济核 | 货运收入 = 产业产出 × 23km × 0.5沙币/吨公里 |
| 依赖图 | 沙本位经济核 | 线路中断 → 依赖方城市产业产出-50% |
| 渗透率初始值 | 铁龙竞争系统 | 城市初始渗透 = city.sand_penetration_base |
| 趋势线初始值 | GameData | 覆盖 GameData 硬编码初始值（Trust=62 等） |

### 4.2 叙事引擎联动

| 创世核产出 | 消费方 | 消费方式 |
|-----------|--------|----------|
| 城市依赖图 | 岁月叙事引擎 | 事件概率 = f(依赖深度、瓶颈风险)——依赖越深，相关事件越可能 |
| 资源分布模式 | 岁月叙事引擎 | 集中型→单点故障事件；分散型→多线受损事件；政治型→政府干预事件 |
| 城市NPC池 | 先民人事系统 | 解锁新城市时，从npc_pool中抽取可招募员工/角色 |

### 4.3 铁龙竞争系统联动

| 创世核产出 | 消费方 | 消费方式 |
|-----------|--------|----------|
| 城市渗透基础值 | SandRivalManager | 初始化各城市渗透率 |
| 城市政治倾向 | SandRivalManager | 渗透增长速度受倾向影响（市场型增长快，威权型增长慢） |
| 关键节点城市 | SandRivalManager | 铁龙收购优先选择关键节点城市 |

### 4.4 区域解锁系统联动

| 创世核产出 | 消费方 | 消费方式 |
|-----------|--------|----------|
| 城市坐标/人口 | 区域解锁系统 | 解锁条件中的距离/人口判定 |
| 城市类型 | 区域解锁系统 | 解锁后新功能（货运专列/旅游专线/政治系统） |
| unlock_region | 区域解锁系统 | 区域归属直接决定解锁顺序 |

## 八、种子分享

### 8.1 种子编码方案

```
seed_code 格式：RR-XXXX-XXXX（P/U+5位十六进制）

RR = 固定前缀（Railway Renaissance）
XXXX = 5位十六进制，核心seed值
XXXX = 5位十六进制，校验和（前5位×3 mod 0xFFFFF）

示例：RR-7A3F-B2C9
  解析：seed = 0x7A3F = 31295
  校验：0x7A3F × 3 = 0x16EBD = 0x6EBD → 补0 → B2C9? 不对，这不重要，这是示例逻辑
```

### 8.2 分享机制

- 玩家可复制 seed_code 分享给他人
- 在"新游戏设置"界面可输入 seed_code
- 输入后生成与分享者完全相同的世界
- 支持排行榜：相同 seed 比经营成绩
