# 科技树设计

> 版本：v1.0  
> 设计原则：三条互斥分支，玩家只能选择一条主路线，后期不可切换

---

## 一、设计理念

科技树不是"加数值"，而是"改规则"。每条分支改变的是系统运行方式，而非简单提高效率。

**三条路线互斥**：玩家在游戏中期（约第6个月）必须选择一条主线，选定后不可更改。

---

## 二、三分支概要

### 🛠 工业派（Industrial）

| 特性 | 效果 |
|------|------|
| 核心优势 | 高运力、高速度、低成本 |
| 核心弱点 | 高维护、高事故风险、对老化敏感 |
| 适合玩家 | 喜欢扩张、敢于冒险 |
| 关键科技 | 双轨、重型机车、自动化调度 |

### 🌱 生态派（Ecological）

| 特性 | 效果 |
|------|------|
| 核心优势 | 高稳定性、低事故、环保补贴 |
| 核心弱点 | 运力低、速度慢、扩张困难 |
| 适合玩家 | 喜欢稳健、长期规划 |
| 关键科技 | 太阳能辅助、轻量车厢、生态走廊 |

### 🤖 自动派（Automation）

| 特性 | 效果 |
|------|------|
| 核心优势 | 高效率、低人力成本、智能调度 |
| 核心弱点 | 对系统失控极其敏感、初始投资高 |
| 适合玩家 | 喜欢技术流、自动化 |
| 关键科技 | AI调度、无人驾驶、智能维护 |

## 四、科技树解锁条件

- **T1**：游戏开始即可研究
- **T2**：运营 > 60天 或 完成特定剧情任务
- **T3**：运营 > 120天 且 累计投入 > 50,000沙币
- **T4**：运营 > 200天 且 选择路线分支
- **T5**：运营 > 365天 且 完成路线专属剧情线

---

## 五、路线选择事件

在游戏第6个月左右，触发"历史性选择"事件：
1. 市长询问你的铁路发展方向
2. 三个选项对应三条路线
3. 选择后立即获得第一个T2科技作为奖励
4. 其他两条路线的T1科技全部锁定
