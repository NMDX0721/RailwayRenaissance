## 二、逐条详情

### G1 城市渗透初始值从种子读取
- **来源**：铁龙竞争系统 §5.1；SandRivalManager.cs
- **设计**：每城渗透 = seed.cities[id].sandPenetrationBase（雾峰0.15/乌金岭0.20/青溪0.25/云渡0.35…）
- **现状**：SandRivalManager.Initialize() 硬编码 4 城（wufeng/kuangqu/qingshi/hekou）
- **状态**：⏳ Layer5 编码中（general-8）

### G2 初始趋势线从种子覆盖
- **来源**：沙本位经济核 §0.6；GameData.cs
- **设计**：Trust/Fiscal/Sand/Political/Decay 初始值 = seed.initialTrends.*（×100 换算 GameData 整数）
- **现状**：GameData 硬编码 Trust=62、TrainCondition=70
- **状态**：⏳ Layer5 编码中

### G3 城市→区域解锁（RegionUnlockManager）
- **来源**：区域解锁与政治系统设计 §1.1
- **设计**：6 区域，由 seed.cities[].unlockRegion 决定解锁顺序；解锁条件（运营天数/资金/信任/剧情）
- **现状**：完全无代码
- **依赖**：L1 数据已有（unlockRegion 字段），需新类 + 接入经营场景
- **优先级**：P0（无区域系统则扩张玩法缺失）

### G4 城市人口→客流基准
- **来源**：千里马创世核 §4.1
- **设计**：客流公式基础人口 = city.population × 0.0025（雾峰 8000→20人基准）
- **现状**：GameData.CalculateDailyPassengers 固定 PopulationFactor=8000
- **依赖**：L5 注入 + 经济核修改

### G5 城市产业→货运收入
- **来源**：千里马创世核 §4.1；跨系统联动公式 §六
- **设计**：货运收入 = 产业产出 × 23km × 0.5沙币/吨公里；产业类型决定货物
- **现状**：收入只含客运（CalculateRevenue 仅 dailyPassengers×票价×趟数）
- **依赖**：L5 + 经济核收入扩展

### G6 依赖图中断→产业产出-50%
- **来源**：千里马创世核 §4.1；沙本位经济核 §0.12
- **设计**：城市A依赖B的煤炭→A-B线中断→A工业产出-50%、居民现金流受损
- **现状**：无线路中断概念（线路只有一个抽象状态）
- **依赖**：L5 + 经济核事件扩展

### G7 关键节点城市→铁龙收购优先
- **来源**：铁龙竞争系统 §2.6
- **设计**：criticalNodes（入度最高城市）是铁龙收购优先目标
- **现状**：SandRivalManager.CheckForAction 只按渗透率选城市
- **依赖**：L5 + 铁龙决策树修改

### G8 城市政治倾向→渗透增速
- **来源**：千里马创世核 §4.3
- **设计**：市场型城市渗透增速快、威权型慢（市场+30%、威权-20%）
- **现状**：DailyUpdate 固定 +0.0015/天
- **依赖**：L5 + SandRivalManager

### G9 资源分布 pattern→事件概率
- **来源**：千里马创世核 §4.2
- **设计**：集中型→单点故障事件概率↑；分散型→多线受损；政治型→政府干预
- **现状**：EventManager 事件概率全来自 events.json 固定字段
- **依赖**：L5 + EventManager

### G10 订单类型受城市产业影响
- **来源**：千里马创世核 §5.2；OrderManager.cs
- **设计**：城市 industries → 订单类型池（矿业城→煤炭货运单；茶乡→茶叶客运单）
- **现状**：OrderManager 生成订单只按 type 随机，与城市无关
- **依赖**：L5 + OrderManager

### G11 城市 npc_pool→招募角色池
- **来源**：千里马创世核 §4.2；先民人事系统 §六

- **现状**：CrewManager 固定 5 员工，无招募
- **依赖**：L5 + CrewManager 招募系统

### G12 政治倾向+stability→结算公式

- **现状**：无政治系统代码
- **依赖**：政治系统（未建）+ L5 数据传递

### G13 storyTags→叙事引擎基调
