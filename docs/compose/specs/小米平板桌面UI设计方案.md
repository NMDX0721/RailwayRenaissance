# 小米平板桌面 UI 设计方案（模拟经营主界面）

> 关联：世界观扩展设定.md §8（科技硬件史）、GameMainUI.cs（现有毛胚）
> 目标：模拟经营主界面 = 岁月的小米平板系统桌面（澎湃32·朝鲜特供版），科技感 + 代入感
> 更新：2026-09-10 App矩阵重设计（系统/本土化/第三方三分法；归途+媒姬百科定名）

---

## 一、设计原则（依据澎湃设计理念 + 游戏像素风）

| 维度 | 决策 | 理由 |
|------|------|------|
| 屏幕 | **16:9 横屏**（平板横置） | 用户明确；全屏时状态栏/任务栏固定于上下 |
| 字体 | **Zpix 像素字体**（主） | 与游戏风格统一，不引入 MiSans 避免撕裂；排版层级/图标承担"科技感" |
| 视觉风格 | 澎湃"电影感锁屏 + 居中大时钟 + 模糊层级" → **像素化演绎** | 锁屏居中大时钟、壁纸半透明模糊层、桌面卡片圆角小部件 |
| 朝鲜特供 | 锁屏扫脸 → "主体护目镜"式扫脸动画（像素风） | 呼应澎湃扫脸/AI 动态壁纸，但带朝鲜审查味 |
| 状态信息 | 顶部状态栏（时间/日期主体历/信号/电量） | 平板常态，增强真实感 |

| App | 命名逻辑 | 交互功能 |

## 三、界面结构（上→下）

### 1. 锁屏（进入模拟经营前的过渡）
- **背景**：江南水乡壁纸（主角设定的，非出厂主体塔剪影）→ 半透明深蓝罩（夜间）
- **居中大时钟**（像素大字 26:13）：当前时间 + 日期（主体历 105 年 1 月 1 日 风格）
- **扫脸提示**：中央一个"取景框"(圆角矩形 + 四角标) + "已识别 ×××" → 点击/回车解锁
  - 像素风眼球扫动动画（一条像素光带从左到右扫过取景框）
  - 解锁后桌面淡入
- **底部**：一行小字 "澎湃OS 32 · DPRK Edition"（版号彩蛋）

### 2. 桌面（模拟经营主界面）
- **壁纸**：江南水乡（同一张，锁屏解锁后无缝延续）
- **顶部状态栏**：左＝时间+日期（主体历）、右＝信号图标+电量+"阿里郎内网"字样（呼应 Mirae 内网）
- **桌面网格**：3 行 × 5 列（16:9 横屏合适；澎湃支持网格+无字模式）
- **App 图标矩阵**：

| # | App | 类型 | 状态 | 说明 |

| 3 | **媒姬百科** | 第三方 | 占位 | 铁路知识百科（角色/列车/历史/术语） |

| 5 | **音乐** | 系统 | 占位 | BGM/歌曲播放器 |

### 3. 打开 App（当前仅 RDA 可交互）
- 点击 RDA → App 窗口弹出（窗口化：标题栏 + 内容区）
- 其他 App → 短暂"选中高亮"后弹轻提示（如"该应用暂未接入"或专属台词）
- 岁月投影浮于桌面一角，可点击交互

## 四、交互细节
- 锁屏扫脸：空格/点击 → 光带扫动 0.6s → 桌面淡入
- 桌面图标：hover 放大 1.1x（像素保持 crisp）+ 名称上浮
- App 点击反馈：按压变暗 + 角标跳动
- 状态栏时间实时更新（秒级刷新）
- 岁月投影：Idle 状态微动（呼吸/眨眼），点击触发对话

## 五、实施范围（代码）
- **重写 GameMainUI.cs**：BuildDocument 保留（Canvas/sortingOrder 200），BuildUI 全面重构为上述平板 UI
