# 小米平板桌面 UI 设计方案（模拟经营主界面）

> 关联：世界观扩展设定.md §8（科技硬件史）、GameMainUI.cs
> 目标：模拟经营主界面 = 岁月的小米平板系统桌面（澎湃32·朝鲜特供版），科技感 + 代入感
> 版本：v2.0（2026-09-17 全量重写：App命名对齐架构决策 + 功能性规格扩充）

---

## 一、设计原则

| 维度 | 决策 | 理由 |
|------|------|------|
| 屏幕 | **16:9 横屏**（平板横置） | 用户明确 |
| 字体 | **Zpix 像素字体**（主） | 与游戏风格统一 |
| 视觉风格 | 澎湃液态玻璃 → **像素化演绎** | 半透明面板+渐变色图标+微交互动画 |
| 朝鲜特供 | 锁屏扫脸 → "主体护目镜"式扫脸动画 | 呼应澎湃扫脸+朝鲜审查味 |
| 状态信息 | 顶部状态栏（时间/日期/信号/电量） | 平板常态 |

## 二、App 分类体系

App 分三类，命名风格和交互深度完全不同：

### A. 系统自带App（小米真名，功能直白）

命名参考小米真实App：两字为主，功能直白。

| App | 命名来源 | 交互功能 | 优先级 |
|-----|---------|---------|--------|
| **相册** | 小米相册 | CG鉴赏 + 风景场景鉴赏 + 角色立绘收集 | P1 |
| **音乐** | 小米音乐 | BGM播放器（播放/暂停/上下曲/音量/歌名滚动） | P1 |
| **笔记** | 小米笔记 | 书签 + 运营统计 + 成就里程碑 + 待办清单 + 快速笔记 | P1 |
| **设置** | 小米设置 | 备份恢复/音量/显示/系统信息/应用管理（彩蛋） | ✅已实现基础版 |
| **浏览器** | 小米浏览器 | 嘉颖徐基金网站（下载RDA APK入口） | P1 |
| **安全中心** | 小米安全中心 | 扫描动画→"系统安全·无异常"，偶尔"检测到未知AI信号·已忽略"暗示岁月 | P1 |
| **米家** | 米家App | 0721载具状态（沙量/电量/里程）+ 维护记录 + 沙子价格 | P1 |
| **应用商店** | 小米应用商店 | 白名单App列表（铁路工具/教育软件），底部"本商店仅提供经审核应用"横幅 | P1 |

### B. 朝鲜本土化App（保留原名，有朝鲜特色功能）

| App | 原型 | 交互功能 | 优先级 |
|-----|------|---------|--------|
| **阿里郎商店** | 阿里郎手机品牌 | 白名单App列表+数字签名验证横幅+讽刺细节 | P1 |
| **未来网** | 朝鲜内联网Mirae | 内网浏览器（阿里郎新闻/USET门户/学校内网）+外网拦截 | P1 |

### C. 第三方App（嘉颖徐铁路基金开发/安装，商业软件品牌感）

命名逻辑=铁路行业专业工具软件品牌感（不是文艺名也不是功能直白名）。

| App | 全名 | 命名逻辑 | 交互功能 | 优先级 |
|-----|------|---------|---------|--------|
| **RDA** | 铁路行车调度助手·RDA（Railway Dispatch Assistant） | 双关：Ri Dispatch Algorithm（爷爷林悍的调度算法） | 经营主界面：调度/列车/员工/财务/线路管理 | P0 |
| **归途** | 归途（Return Journey） | 铁路术语"归途"=列车折返/回送；嘉颖徐命名："铁路最动人的不是出发，是回来" | 剧情回顾：章节列表/回看/CG回放/存档管理 | P0 |

### D. 其他元素

| 元素 | 说明 |
|------|------|
| **岁月** | 桌面AI投影（13岁少女形象），**不是App图标**，是常驻浮窗。点击触发对话 |
| **文件夹"铁路"** | 收纳 归途/媒姬百科/音乐 三个App |
| **Dock** | 常驻底栏：RDA / 归途 / 笔记 / 设置 |

## 四、App详细功能性规格

### 4.1 RDA（铁路行车调度助手）⭐ P0

**现实原型**：小米AI语音助手"小爱同学"（HyperOS深度整合）
**全名**：铁路行车调度助手·RDA（Railway Dispatch Assistant）
**来源**：嘉颖徐铁路基金内部开发，内网分发APK

#### 功能模块

| 模块 | 功能 | 描述 |
|------|------|------|
| **运营总览** | 每日报告 | 显示当日运营数据摘要（客流、收入、信任度变化趋势） |
| | 快捷操作 | 一键切换班次、一键维修、一键发车 |
| **调度面板** | 班次管理 | 查看/调整列车班次时刻表 |
| | 线路管理 | 查看已开通线路状态、规划新线路 |
| | 实时监控 | 当前运行列车位置、准点率 |
| **员工面板** | 人员列表 | 查看所有员工状态（技能/疲劳/满意度） |
| | 岗位调配 | 拖拽式岗位分配 |
| | 招募入口 | 进入招募界面 |
| **财务面板** | 收支报表 | 日/周/月收支明细 |
| | 资金余额 | 当前资金+趋势图 |
| | 补贴状态 | 政府补贴发放情况 |
| **车辆面板** | 机车状态 | NF-5耕牛等机车的维护状态 |
| | 维护计划 | 预防性维护提醒 |
| **沙能分析** | 竞争态势 | 铁路vs沙能的数据趋势对比 |
| | 渗透率图 | 各城市沙能渗透率可视化 |

#### 交互设计

- 点击桌面RDA图标→弹出窗口（720×420）
- 窗口内为多Tab面板（运营/调度/员工/财务/车辆/沙能）
- 首次打开→用户名输入界面（叙事：嘉颖徐基金要求实名注册）
- 版本号显示在设置页："RDA v1.0.0 · 嘉颖徐铁路基金"

### 4.2 归途（Return Journey）⭐ P0

**现实原型**：小米相册的章节浏览模式
**来源**：嘉颖徐铁路基金开发，铁路术语"归途"=列车折返/回送

#### 功能模块

| 模块 | 功能 | 描述 |
|------|------|------|
| **章节列表** | 已完成章节 | 按时间排列所有已解锁的剧情章节 |
| | 未解锁章节 | 显示"???"占位，提示解锁条件 |
| **剧情回看** | 重看对话 | 选择任意已解锁章节，从头回看 |
| | 跳转选择 | 可跳过已读对话（快速回看） |
| **CG回放** | 已解锁CG | 按章节/场景分类的CG图片浏览 |
| | CG详情 | 点击CG全屏查看+场景描述 |
| **存档管理** | 自动存档 | 显示当前自动存档状态 |
| | 手动存档 | 1个手动存档槽 |
| | 存档对比 | 并排对比两个存档的差异 |

#### 交互设计

- 点击桌面归途图标→弹出窗口
- 左侧：章节时间线列表（可滚动）
- 右侧：选中章节的详情/CG/对话回看
- 底部：存档管理入口

### 4.10 计算器 ⭐ P1

**现实原型**：小米计算器
**真实功能**：基础计算、科学计算、汇率转换、单位换算、房贷计算

#### 功能模块

| 模块 | 功能 | 描述 |
|------|------|------|
| **基础计算** | 四则运算 | 标准计算器功能 |
