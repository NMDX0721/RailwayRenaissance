# 教程与新手引导设计

> 版本：v1.0  
> 设计原则：不打断沉浸感，剧情驱动的引导

---

## 一、引导策略

**不采用传统弹窗教程**，而是通过剧情和NPC对话自然引导玩家。

### 1.1 序章中的隐式引导

| 序章场景 | 引导内容 | 方式 |
|---------|---------|------|
| 老陈电话 | 介绍铁路现状 | 剧情对话 |
| 巡视线路 | 展示机车、轨道、车站 | 场景描述+对话 |
| 员工集合 | 介绍5名员工和岗位 | 角色对话 |
| 查看机车 | 了解车辆状态系统 | NPC解释+操作提示 |
| 第一班车 | 学习发车流程 | 任务引导+老陈指导 |

### 1.2 经营初期的引导

| 游戏内条件 | 触发内容 | 引导方式 |
|-----------|---------|---------|
| 第1天开始 | 老陈介绍每日流程 | 对话+界面高亮 |
| 首次分配人员 | 老陈建议"安全优先配置" | 推荐方案+解释 |
| 首次发车 | 张工讲解检查流程 | 任务提示 |
| 首次故障 | 张工指导维修 | 紧急事件+引导 |
| 首次亏损警告 | 老陈提醒"该去见市长了" | 剧情推进 |
| 首次沙能事件 | 岁月提供背景信息 | AI对话 |

## 二、界面引导

### 2.1 渐进式信息展示

| 阶段 | 可见信息 | 隐藏信息 |
|------|---------|---------|
| 第1-7天 | 资金、信任、车况、客流 | 沙能渗透、政治压力、趋势线 |
| 第8-30天 | + 沙能渗透、员工满意度 | 设施老化率、政治倾向 |
| 第31-90天 | + 趋势线图表 | 远期预测 |
| 第91天+ | 全部开放 | 无 |

### 2.2 高亮提示

- 新功能解锁时，对应按钮会有脉冲动画
- 可交互的NPC有特殊标记
- 重要新闻有特殊边框

---

## 三、失败容错

### 3.1 破产保护

- 首次破产时，触发"老陈的最后一笔积蓄"事件（获得10,000沙币紧急资金）
- 第二次破产时，触发"市政府救助"事件（需要签署苛刻条件）
- 第三次破产 = Game Over

### 3.2 剧情兜底

- 如果玩家长时间不推进剧情，关键NPC会主动联系
- 主线剧情有"自动推进"机制（30天无进展→NPC催促）
