## 九、序章→经营过渡技术方案

### 9.1 数据传递流程

```
VN系统结束
    ↓
VNManager 调用 SceneManager.LoadScene("StationSlice_V1")
    ↓
GameData.Initialize() 读取 VN 系统传递的初始状态
    ↓
初始状态 = 基础值 + 序章选择影响
    ↓
经营模式开始
```

### 9.2 序章选择对经营的影响

| 序章选择 | 影响 |
|---------|------|
| 维修方式：张工维修 | 机车状态+75，资金-500 |
| 维修方式：自己动手 | 机车状态+70，资金-0，首班车推迟 |
| 维修方式：先检查 | 机车状态+72，资金-200 |
| 首班车：保守一趟 | 收入+420，村民信任+0.02 |
| 首班车：直接两趟 | 收入+840，机车状态-3，村民信任+0.03 |

### 9.3 过渡界面

```
全屏黑底白字：
  "第一章·启程"
  下方小字："点击任意位置开始经营"
  
点击后 → 淡出 → 淡入至 StationSlice_V1 场景
```
