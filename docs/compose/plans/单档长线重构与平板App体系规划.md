## 二、平板App体系（定稿）

### 2.1 App分类原则

App分三类，命名风格和交互深度完全不同：

| 类别 | 命名规律 | 来源 | 交互深度 |
|------|---------|------|---------|
| **系统自带** | 小米真名（相册/音乐/笔记/设置） | 澎湃32预装 | 全功能交互 |
| **朝鲜本土化** | 朝鲜品牌名（阿里郎/未来网/白头疫苗） | 特供版预装 | 可交互（有朝鲜特色功能） |
| **第三方** | 商业软件品牌感（RDA/归途/媒姬百科） | 嘉颖徐基金/APK安装 | 全功能交互 |

### 2.2 系统自带App（小米真名）

| App | 交互功能 |
|-----|---------|
| **相册** | CG鉴赏 + 风景场景鉴赏 |
| **音乐** | BGM/歌曲播放器 |
| **笔记** | 书签 + 运营统计 + 成就里程碑（自然融合，像真实笔记本） |
| **设置** | 备份恢复/音量/系统信息 |
| **浏览器** | 可访问嘉颖徐基金网站（下载RDA APK） |
| **安全中心** | 扫描→"系统安全·无异常"，偶尔"检测到未知AI信号·已忽略"（暗示岁月） |
| **米家** | 0721载具状态（沙量/电量/里程）+ 维护记录 |
| **应用商店** | 白名单App列表，底部"本商店仅提供经审核应用"横幅 |

### 2.3 朝鲜本土化App

| App | 原型 | 交互功能 |
|-----|------|---------|
| **阿里郎商店** | 阿里郎手机品牌 | 白名单App+数字签名验证横幅 |
| **未来网** | 朝鲜内联网Mirae | 内网浏览器（阿里郎新闻/USET门户） |
| **白头疫苗** | 朝鲜SiliVaccine | 扫描→"系统安全"，偶尔"检测到AI信号·已忽略" |

### 2.4 第三方App（嘉颖徐基金开发/安装）

| App | 命名逻辑 | 交互功能 |
|-----|---------|---------|
| **RDA** | 铁路行业术语+缩写，双关李式调度算法 | 经营主界面（调度/列车/员工/财务） |
| **归途** | 铁路术语"归途"（列车折返/回送）= 主角归乡 | 剧情回顾（章节列表/回看/CG回放） |
| **媒姬百科** | 仿维基百科，铁路知识百科全书 | 角色/列车/历史/术语百科全书 |

### 2.5 站长日志的归宿

站长日志不是一个独立App，而是**打散到各个App**：

| 原站长日志内容 | 归入的App | 说明 |
|--------------|----------|------|
| 成就/里程碑 | **笔记** | 自然融合，像笔记本里的里程碑记录 |
| CG鉴赏 | **相册** | 按剧情时间线排列 |
| 音乐 | **音乐** | 独立播放器 |
| 故事章节 | **归途** | 章节列表/回看 |
| 风景场景 | **相册** | 风景专辑 |
| 角色/列车图鉴 | **媒姬百科** | 百科全书式呈现 |
| 书签 | **笔记** | "第X话读到XX" |
| 运营统计 | **笔记** | 运营周报/数据面板 |

### 2.6 桌面布局

- **Dock**：RDA / 归途 / 笔记 / 设置
- **文件夹**：「铁路」收纳 归途/媒姬百科/音乐
- **小组件**：「今日线路」运营概览
- **岁月**：桌面角落AI投影，非App图标

## 三、归途 App 设计（剧情回顾）

**命名**：「归途」—— 铁路术语"归途"（列车从终点站返回起点站的过程），同时也是主角的故事主题。

**功能**：
- 章节列表：已解锁话数（亮灯）/ 未解锁（暗色）
- 章节回看：选中章节 → 播放该话剧情
- CG回放：已解锁CG的回顾

**UI参考**：蔚蓝档案 Main Story 界面
- 左栏：当前Volume大卡片（平行四边形/斜切票根 + 背景图 + 标题）
- 右栏：章节列表面板（半透明旧玻璃质感 + 信号灯选中）

## 四、媒姬百科 App 设计（铁路百科）

**命名**：「媒姬百科」—— 仿维基百科的铁路知识百科全书。

**内容分类**：
- **人物**：林彪悍、老陈、嘉颖徐、员工团队、岁月
- **车辆**：NF-5耕牛、SY-22灰雀、0721号沙子飞猪号
- **机构**：金日成综合大学、嘉颖徐铁路基金、USET
- **技术**：沙能技术、李式调度算法(RDA)、澎湃32
- **地理**：雾峰村、平壤、边境线
- **历史**：铁路大废线时间线、沙能时代编年

每条百科词条有：标题、摘要、详细内容（随剧情解锁）、配图（如有）
