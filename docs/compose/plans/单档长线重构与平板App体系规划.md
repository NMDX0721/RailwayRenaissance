## 二、站长日志 → 平板「站务手记」App（重新设计）

**不要机械映射**。站长日志不是一个"功能菜单"，而是一个**站长的个人手记本**——打开它，感觉像翻开一本皮面笔记本，记录着铁路复兴路上的点点滴滴。

### 2.1 设计理念：一本手记，而非一个菜单

- 首页：一页泛黄的笔记本纸，标题「雾峰村线站务手记」
- 内容以"条目"形式呈现，而非标签页
- 每个条目打开像翻开新的一页

### 2.2 内容组织

| 手记条目 | 本质 | 来源 |
|---------|------|------|
| **里程碑** | 成就列表 | 从原有成就页改造，每条成就像"已完成的任务"打勾 |
| **回忆相册** | CG 鉴赏 | 按剧情时间线排列，翻开一张图就是一页回忆 |
| **留声机** | 音乐鉴赏 | 保留独立播放器，风格改为"旧式留声机" |
| **故事集** | 剧情回顾 | 已解锁的故事章节，点开回看 |
| **风景集** | 场景鉴赏 | 去过的地方，站台/路线/村庄 |
| **图鉴** | 角色/列车档案 | 解锁的角色/列车信息 |
| **📌 书签** | 阅读位置 | 手动书签 + 自动书签 |
| **📊 运营数据** | 统计 | 线路数据：运营天数/收入/客流/货运量 |

### 2.3 与平板体系的关系

- 音乐 → 可以从「手记」打开，也有独立桌面「音乐」App 入口
- 图鉴 → 可以从「手记」打开，也有独立桌面「列车图鉴」App 入口
- 书签 → 在手记内作为独立页，不单独上桌面

## 三、主线剧情 → 平板「归乡」App（独立应用）

**主线剧情不是一个"功能入口"，而是一个可触摸的叙事应用。**

### 3.1 设计理念

- 桌面图标：`归`（汉字"归乡"的归）
- 打开后显示一条**铁路线地图**——当前章节位置以发光站台标记
- 已解锁话数：亮灯站台；未解锁：暗色站台
- 点击亮灯站台 → 进入剧情回看
- 当前进行中的话：站台闪烁，标记"继续"

### 3.2 优势

- 取代当前 "事务→剧情→Main Story" 三层入口，改为直接桌面打开
- 融合铁路意象（一条铁路线 = 剧情进度条）
- 平板系统的"应用"概念，让剧情变成"你正在追的故事"

### 3.3 与现有 MainStoryUI 的关系

- MainStoryUI 当前实现保留（独立 UIDocument、DontDestroyOnLoad）
- 「归乡」App 做一层包装：打开 → 显示铁路线地图 → 点击站台 → 调现有 MainStoryUI 或直接播剧情
- 未来可取代 MainStoryUI

## 四、岁月差分清单（按需，不强制 16 张）

### 4.1 核心必备（9 张）

| # | 表情 | 说明 | 口癖/场景 |
|---|------|------|----------|
| 1 | normal | 日常待机 | 手持平板，自然的平静表情 |
| 2 | smile | 微笑 | 常用，轻扬嘴角 |
| 3 | **smug** | **得意自夸** | **招牌表情**——"我可是高性能AI！" 歪嘴笑、昂下巴 |
| 4 | curious | 好奇 | 歪头、眼神向上，探查新事物 |
| 5 | excited | 兴奋 | 眼睛放光，咧嘴大笑，数据抢答 |
| 6 | sad | 悲伤/孤独 | "……二十三年了。终于有人和我说话了。" |
| 7 | gentle | 温柔陪伴 | 眼神柔和——"但我会陪着您的。" |
| 8 | serious | 认真/坚定 | 承诺、关键时刻——"放心，我会把您安全送到！" |
| 9 | surprised | 惊讶 | 嘴巴微张——"咦？！" |

| # | 表情 | 说明 |
|---|------|------|
| 10 | wink | 俏皮眨眼——"夸夸我嘛" |
