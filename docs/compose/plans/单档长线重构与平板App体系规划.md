## 三、后话（记入，等基础设施丰富后再实现）

### 3.1 启动游戏 = 启动平板锁屏

- 当前标题界面（TitleScene）→ 改为平板锁屏直接进入游戏
- 标题界面臃肿内容（设置/日志/成就等）→ 拆分到平板各 App 内
- 设置 → 平板「设置」App
- 站长日志 → 平板「日志」App
- 音乐鉴赏 → 平板「音乐」App
- 背景/CG 鉴赏 → 平板「相册」App
- 版本号/调试 → 平板「设置」→ 关于平板

### 3.2 沉浸式改造原则

- 一切功能以平板 App 为入口，UI Toolkit 全屏桌面
- 运营/剧情/图鉴/设置/日志 全部是"应用"
- 标题界面仅保留最低限度的启动画面（品牌露出 + 平板锁屏背景）

### 3.3 新角色差分规则

- 不强制 16 张，按需允许变动（本次已记录）
- 核心角色（岁月/林彪悍/嘉颖徐/老陈）保持 16 张基础；配角 4-8 张即可
