- [ ] **Step 2: 扩展 GetRankName 映射表**

找到 `GetRankName` 方法（约 70-90 行），将等级映射从 0-5 扩展为 0-7。

**职级速查表：**

| 等级 | driving | repair | management | service | freight |
|------|---------|--------|------------|---------|---------|
| 0 | 未培训 | 未培训 | 未培训 | 未培训 | 未培训 |
| 1 | 学习司机 | 学徒工/Auszubildender | 係員/Clerk | 实习员/Trainee | 装卸工 |
| 2 | 副司机 | 初级技工/Geselle | 主任/Attendant | 乘务员/Conductor | 货运员 |
| 3 | 司机 | 中级技工 | 師範/Duty Officer | 列车长/Train Captain | 货运调度 |
| 4 | 指导司机 | 高级技工 | 助役/Deputy Master | 乘务主任/Chief Conductor | 货运主管 |
| 5 | 高级指导司机 | 技师/Meister | 職場長/Station Master | 乘务队长/Conductor Captain | 货运经理 |
| 6 | 首席指导司机 | 高级技师 | 統括長/Regional Manager | 首席乘务长/Chief Steward | 货运总监 |
| 7 | 特级指导司机 | 特级技师/Obermeister | 本部長/Director | 乘务总长/Inspector General | 货运总长 |

**代码修改模式：** 在现有的 switch 或 if-else 链中：
```csharp
public static string GetRankName(string skillName, int level)
{
    level = Mathf.Clamp(level, 0, 7);  // 原为 0-5，改为 0-7

    // 原有等级 0-5 的映射不变，追加 6-7 级
    if (level == 6) {
        switch (skillName) {
            case "driving":    return "首席指导司机";
            case "repair":     return "高级技师";
            case "management": return "統括長";
            case "service":    return "首席乘务长";
            case "freight":    return "货运总监";
        }
    }
    if (level == 7) {
        switch (skillName) {
            case "driving":    return "特级指导司机";
            case "repair":     return "特级技师";
            case "management": return "本部長";
            case "service":    return "乘务总长";
            case "freight":    return "货运总长";
        }
    }
    // ... 原有 0-5 级映射保持不变
}
```
