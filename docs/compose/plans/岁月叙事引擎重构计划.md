# 岁月叙事引擎重构计划

> 计划版本：v2.0（审计修复版）  
> 状态：规划中  
> 当前代码状态：⚠️ VN 引擎基础可用（VNManager/DialogueBox/JSONParser），AI 叙事层完全未编码  
> 审计修复：GAP1-GAP12 全部修复（详见 §六）

---

## 一、重构目标

岁月叙事引擎是"**世界在说话**"的系统——它读取世界种子、趋势线、角色关系，生成匹配当前世界状态的事件。重构完成后，它应：

1. **模板化叙事可运行**——阶段1：基于世界状态匹配模板，参数化生成新闻/对话/事件
2. **与创世核联动**——城市依赖图/资源分布/政治倾向直接驱动叙事可能性
3. **与现有系统集成**——挂接 GameData.AdvanceDay、VNManager、RegionUnlockManager、EventManager、OrderManager
4. **叙事事件效果落地**——每个叙事事件产生可度量的游戏状态变化（信任/资金/渗透）
5. **可扩展**——阶段2/3 可插入 LLM 而不改架构
6. **岁月角色活起来**——好感度/记忆解锁/双 AI 线可运行

## 二、任务层级

### Layer 1：叙事引擎核心数据模型（N1）

**目标**：定义 NarrativeContext、StoryPossibility、NarrativeTemplate、NarrativeEvent 等核心数据结构。

| 子任务 | 内容 | 产出 |
|--------|------|------|
| 1.1 NarrativeContext | 世界状态快照：趋势线/阈值/角色状态/最近事件/种子数据/已解锁区域/疲劳触发 | 数据结构 |
| 1.2 StoryPossibility | 故事可能性：模板ID/匹配分数/冷却/条件 | 数据结构 |
| 1.3 NarrativeTemplate | 叙事模板：type/conditions/template/parameters/effects（含 effects 的资金/信任/渗透/疲劳变化） | 数据结构 + JSON |
| 1.4 NarrativeEvent | 叙事事件产出：effect 类型/目标系统/内容/影响的数值变化 | 数据结构 |
| 1.5 CharacterState | 角色状态：好感度/疲劳/忠诚/记忆/最近对话/NPC 疲劳触发标志 | 数据结构 |
| 1.6 ThresholdEvent | 阈值事件：趋势线/阈值方向/严重度 | 枚举+结构 |

**验证**：JSON 序列化/反序列化通过；NarrativeEvent 含 effects 字段

### Layer 3：模板化叙事引擎（NarrativeEngine）

**目标**：NarrativeEngine 主入口 + StoryEvaluator + TemplateFiller + 事件效果应用。

| 子任务 | 内容 | 算法 |
|--------|------|------|
| 3.1 NarrativeEngine 主入口 | CheckForEvent(context) → 产出 NarrativeEvent（含 effects） | 主调度 |
| 3.2 StoryEvaluator | 评估可能性：遍历模板→conditions 匹配→排序→冷却（按世界状态，非纯时序） | 多条件加权 |
| 3.3 TemplateFiller | 替换占位符：{city}/{player}/{value}/{cityName} 等 | 正则替换 |
| 3.4 模板 JSON 加载 | 从 Resources/ 加载 narrative_templates.json（格式按 §3.1 现有设计） | Resources.Load |
| 3.5 事件效果应用 | ApplyEffects(NarrativeEvent) → 修改 GameData 信任/资金/渗透/疲劳 | 数值应用 |

**验证**：给定 NarrativeContext → 输出匹配的叙事文本 + 效果（信任/资金变化实际生效）
**GAP2 修复**：3.5 新增事件效果应用
**GAP4 修复**：删除原 3.5 冷却系统（合并到 6.3）
**GAP9 修复**：模板 JSON 格式明确采用 §3.1 现有结构
