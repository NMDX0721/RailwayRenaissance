# 千里马创世核重构计划

> 计划版本：v2.0  
> 状态：规划中  
> 分工：此计划定义任务层级，AI 逐步执行

---

## 一、重构目标

千里马创世核是**一切游戏世界差异的底层来源**。重构完成后，它应：

1. **作为独立模块**——可被其他系统依赖，不依赖其他系统
2. **确定性随机**——同一 seed 产生完全相同的世界
3. **完整可编码**——所有字段、算法、约束在文档中可直接转为 C# 代码
4. **可验证**——每个种子可通过 7 项验证
5. **可扩展**——新增种子无需修改算法

## 二、任务层级

### Layer 1：世界种子数据模型（T16.1）

**目标**：定义 `WorldSeedData` 的完整字段、类型、约束、JSON 序列化。

#### 1.1 城市数据（含城市模板，江南诗意命名体系）

从现有世界观文档提取 7 个城市模板，按铁路线从山到海的顺序排列，名字体现江南地域特征与产业类型：

| 城市 | 类型 | 人口 | 产业 | 渗透基准 | 所属区域 | 意象说明 |
|------|------|------|------|---------|---------|---------|
| **雾峰村** | agriculture | 8000 | 茶叶、旅游 | 0.15 | 0 | 常年多雾的山村，茶乡，主角故乡（已定，不可改） |
| **乌金岭** | mining | 4000 | 煤炭、矿石 | 0.20 | 0 | 乌金=煤的雅称，岭=山区矿产，矿区意象 |
| **青溪镇** | industrial | 12000 | 制造、轻工 | 0.25 | 1 | 青溪=清水，江南制造业小镇 |
| **云渡港** | port | 25000 | 港口、贸易 | 0.35 | 2 | 云渡=诗意，内河港，烟波浩渺 |
| **白鹭洲** | administrative | 50000 | 行政、金融、教育 | 0.40 | 3 | 白鹭=江南常见水鸟，洲=文明荟萃之地，省城 |
| **枫林渡** | industrial | 35000 | 重工、化工 | 0.30 | 4 | 枫林=层林尽染，渡=工业渡口，重工业区 |
| **望海港** | port | 40000 | 国际贸易、航运 | 0.50 | 5 | 望海=面朝大海，海港终局，铁路终点 |

**命名规律**：山→岭→溪→渡→洲→渡→港，字面即可读出地理变迁。每个名字的偏旁部首暗示产业特征（山/石=矿业，溪/氵=水运，洲/土=城市，渡/舟=交通，港/水=海港）。

**沿途小站**（非独立城市模板，仅出现在主线线路上）：
- 茶山（8km，茶叶集散地）
- 松桥（15km，会让站，已废弃）

**生成规则**：种子从模板池中抽样 4-7 个城市，允许对人口/产业做±20%抖动。雾峰村和乌金岭始终在种子中（主线剧情需要）。

#### 1.2 依赖图（有向图结构）

从原始AI对话记录 L1479/L1539：地图表示为 Graph（adj list），城市为节点，边带时长/成本/单轨双轨标记。

```
字段：
  dependencies: {
    imports: ["城市:资源"],    // 进口依赖，城市A需要城市B的资源X
    exports: ["城市:资源"]     // 出口，自动匹配进口
  }

约束：
  - 有向图必须强连通（从任意城市出发可回到起点）
  - 入度最高的城市 = 关键节点（bottleneck_risk 来源）
  - 依赖深度（入度/城市总数）→ bottleneck_risk
```

#### 1.3 资源分布（3种模式）

| 模式 | 概率 | 关键节点 | 瓶颈风险 | 额外效果 |
|------|------|----------|---------|---------|
| concentrated | 35% | 1-2个 | 0.35 | 单点故障→全图瘫痪 |
| dispersed | 35% | 0 | 0.10 | 断线影响小，效率低 |
| political | 30% | 高价值资源城市 | 0.25 | 政府干预概率 0.15 |

#### 1.4 政治倾向（4层结构）

```
全局倾向：authoritarian / market / welfare（概率 30%/40%/30%）
城市级倾向：全局±1级偏移（30%概率偏移）
政治周期长度：180±30天（基准 150-210）
政治好感度 favor：0-1，初始 0.5（受玩家行为影响）
稳定性 stability：0-1，初始 0.6（触发结算条件的阈值）
```

**政治结算触发**（来自原始AI对话记录 L3084-3117）：
- `stability < 0.6` 且 `favor < 0.3` → 触发威权结算（强制征用、收入-20%）
- `stability < 0.6` 且 `favor > 0.7` → 触发福利结算（补贴+50%，运输时间+10%）
- `stability > 0.8` 且 `favor > 0.5` → 市场结算（自由竞争，价格浮动）

#### 1.5 物理铁路边

从原始AI对话记录 L1539：边带 travel_time（分钟）、capacity（容量/趟）、track_type（单轨/双轨）。

```
rail_edges: [
  { from: "wufeng", to: "kuangqu", travel_time: 45, capacity: 30, track_type: "single" },
  ...
]
```

**生成算法**：Kruskal 最小生成树 + 20%随机额外边（保证图连通且有趣）。

#### 1.6 全局规则

| 规则 | 默认值 | 用途 |
|------|--------|------|
| incident_base_chance | 0.005 | 每日事件基准概率 |
| trust_natural_decay | 0.0002 | 信任自然衰减/天 |
| fiscal_growth_base | 0.001 | 财政压力自然增长/天 |
| max_repair_cost_multiplier | 2.0 | 最大维修成本倍率 |
| subsidy_base | 8000 | 基础补贴/月（与经济核对齐） |

#### 1.7 五条趋势线初始值

| 趋势 | 基准 | 抖动范围 | 种子影响因素 |
|------|------|---------|-------------|
| trust | 0.62 | ±0.05 | 城市类型加权（农业高、工业低） |
| fiscal_pressure | 0.30 | ±0.05 | 资源分布（集中型低、分散型高） |
| sand_penetration | 0.15 | ±0.05 | 城市渗透基准的加权均值 |
| political_pressure | 0.20 | ±0.05 | 政治倾向（威权高、福利低） |
| infrastructure_decay | 0.30 | ±0.05 | 随机，与城市繁荣度负相关 |

#### 1.8 元数据 + 故事层

```
seed_id: "seed_001"
name: "雾峰标准开局"
version: "v3.0"
seed_code: "RR-7A3F-B2C9"
year: 2076                // 游戏开始年份

```

**故事层**（新增于 v3.0）：每个城市关联 `npc_pool`（角色池）和 `story_tag`（剧情标签），供叙事引擎和先民人事系统使用。

### Layer 2：确定性生成算法（T16.2）

**目标**：`WorldGenerator.Generate(int seed)` 的完整算法，含伪代码。

#### 2.1 城市生成（4-7个城市）

```
输入：int seed，城市模板列表
输出：城市列表（含类型/人口/坐标/产业）

1. R = System.Random(seed)
2. 必然选择：雾峰村(agriculture) + 矿区镇(mining)（主线剧情需要）
3. 从剩余模板中随机选 2-5 个城市（按权重加权）
4. 为每个城市分配人口（基准值 ± R.Next(-20%, 21%)）
5. 为每个城市分配坐标（随机散布在 800×600 地图上，避免重叠）
6. 为每个城市生成人口增长率（与产业正相关，agriculture > industrial > mining）
7. 返回城市列表
```

#### 2.2 依赖图生成（有向图强连通闭环）

```
1. 为每个城市确定主要产出资源（按 type 映射）
2. 为每个城市确定需求资源（不能与产出重叠）
3. 构建依赖边：城市A需要X → 找到产出X的城市B → 边 A→B
4. 优先选择距离最近的城市（减少运输成本叙事）
5. 强连通检验（Kosaraju 算法）：
   - 从任意城市出发 DFS，记录完成顺序
   - 反转图，按完成顺序再次 DFS
   - 若所有城市在同一 SCC → 通过
   - 否则 → 重新分配依赖目标（最多3次重试）
6. 计算入度/出度/关键节点
```

#### 2.3 资源分布生成

```
pattern = weighted_sample(["concentrated", "dispersed", "political"], [0.35, 0.35, 0.30], R)
if concentrated: critical_nodes = 入度最高的1-2个城市
if dispersed: critical_nodes = []
if political: critical_nodes = 高价值资源城市 + government_intervention_prob = 0.15
```

#### 2.4 政治倾向生成

```
全局倾向 = weighted_sample(["authoritarian", "market", "welfare"], [0.30, 0.40, 0.30], R)
城市级倾向：以全局倾向为基准，30%概率偏移±1级
政治周期长度 = 180 + R.Next(-30, 31)
favor = 0.5 + R.NextDouble() * 0.2 - 0.1  // 0.4-0.6
stability = 0.6 + R.NextDouble() * 0.2 - 0.1  // 0.5-0.7
```

#### 2.5 铁路边生成（MST + 随机边）

```
1. 计算城市间欧几里得距离矩阵
2. 用 Kruskal 算法生成最小生成树（MST）
3. 额外随机添加 20% 边（使图有趣）
4. 每条边赋值 travel_time = 距离 * 0.5（分钟/像素）
5. 每条边赋值 capacity = 城市类型系数 * 30（基准30人/趟）
6. 每条边赋值 track_type = 单轨（默认，玩家可升级为双轨）
```

#### 2.6 趋势线生成

```
每条趋势线：基准值 + R.NextDouble() * 波动范围 * 2 - 波动范围（对称抖动）
波动范围：±0.05（5%）
```

#### 2.7 全局规则生成

```
按种子+难度查表：
  - 简单难度：incident_base_chance *= 0.8, subsidy_base *= 1.5
  - 普通难度：不变
  - 困难难度：incident_base_chance *= 1.2, subsidy_base *= 0.7
```

#### 2.8 种子注入

```
WorldSeedData → 各系统：
  1. GameData.InitializeIfNeeded(): 覆盖趋势线初始值
  2. SandRivalManager.Initialize(): 城市渗透初始值（替代硬编码）
  3. EventManager.Initialize(): 事件基准概率
  4. OrderManager.Initialize(): 城市产业影响订单类型
  5. 区域解锁系统：城市区域归属
  6. 先民人事系统：城市NPC池
  7. 叙事引擎：政治倾向基调
```

### Layer 4：种子编解码与分享（T16.4）

```
编码格式：RR-XXXXX-YYYYY
  RR = 固定前缀
  XXXXX = 5位十六进制（核心seed值，0x00000-0xFFFFF）
  YYYYY = 5位十六进制（校验和 = XXXXX × 3 mod 0xFFFFF）

解码：校验验证 → 提取 seed 值 → WorldGenerator.Generate(seed)
```

## 三、执行顺序

```
T16.1 Layer 1 数据模型  →  T16.2 Layer 2 生成算法  →  T16.3 Layer 3 预设种子
                                                              ↓
                      T16.5 Layer 5 联动接口  ←  T16.4 Layer 4 编解码
```

依赖关系：1→2→(3,4)→5（4 和 3 可并行）
预计总工时：Layer 1 约 2d，Layer 2 约 3d，Layer 3 约 1d，Layer 4 约 0.5d，Layer 5 约 1d
