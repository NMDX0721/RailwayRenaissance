> **For agentic workers:** Use compose:subagent or compose:execute to implement this plan task-by-task.

```csharp
// 替换硬编码的"Microsoft YaHei"
string GetFontName()
{

        return "Microsoft YaHei";
    return "Arial"; // fallback
}
```

## 🎯 执行顺序

### Phase 1: 素材生成（用户执行）
1. 使用PROMPT_LIST.md中的提示词生成通用面板背景
2. 使用PROMPT_LIST.md中的提示词生成输入框背景
3. 确认button_primary.png和title_logo.png可继续使用

### Phase 2: 素材导入（代码执行）
1. 将新素材放入Assets/Resources/UI/Login/
2. 配置sprite导入设置（textureType=8, spriteMode=1）
3. 验证Resources.Load可正确加载

### Phase 3: 代码重构（代码执行）
1. 创建LoginUIConfig.cs配置文件
2. 重构LoginManager.cs，使用配置常量
3. 修正所有元素坐标到精确位置
4. 修复字体兼容性问题

### Phase 4: 验证（用户+代码）
1. Unity Play Mode测试登录界面
2. 检查所有元素位置是否正确
3. 检查输入框无分隔线瑕疵
4. 检查Logo正确显示在面板上方
5. 测试登录/注册/自动登录三个界面切换

## ⚠️ 已知风险

1. **面板底部超出屏幕**：面板Y=-40，高度1200，底部Y=-640，超出屏幕底部Y=-540约100px。可接受，因为面板底部通常没有重要元素。
2. **Logo接近屏幕顶部**：Logo顶部Y=+530，屏幕顶部Y=+540，仅留10px边距。如果Logo生成尺寸有误差可能被裁切。
3. **字体兼容性**：Microsoft YaHei在非Windows系统上不可用，需要fallback。
