**关键代码**：
```csharp
// VNManager.cs 中新增
private void HandleSpecialCommand(string command)
{
    switch (command)
    {
        case "TRANSITION_TO_GAMEPLAY":
            StartCoroutine(TransitionToGameplay());
            break;
    }
}

private IEnumerator TransitionToGameplay()
{
    // 1. 构建 VNExitData
    VNExitData data = new VNExitData();
    data.startMoney = 40000 + CalculateStoryGrants();
    data.startTrust = 60;
    data.startTrainCondition = 70 + GetRepairBonus();
    data.playerAlias = GameConfig.Load().PlayerDisplayName;
    
    // 2. 保存到 PlayerPrefs
    string json = JsonUtility.ToJson(data);
    PlayerPrefs.SetString("VNExitData", json);
    PlayerPrefs.Save();
    
    // 3. 加载经营场景
    AsyncOperation asyncLoad = SceneManager.LoadSceneAsync("StationSlice_V1");
    while (!asyncLoad.isDone) yield return null;
}
```

**提给AI的提示词**：
> 在 Assets/Scripts/VN/VNManager.cs 中新增 t:"special" 指令处理。当 text="TRANSITION_TO_GAMEPLAY" 时，构建 VNExitData 结构体，保存到 PlayerPrefs，然后 SceneManager.LoadScene("StationSlice_V1")。需要新增 VNExitData 和 CrewData 结构体定义。

**关键公式**（来自 跨系统联动公式.md）：
```csharp
// 每日客流
int dailyPassengers = Mathf.FloorToInt(
    basePopulation * 0.001f * 
    (0.5f + trust * 0.005f) * 
    seasonModifier * 
    (1f - sandPenetration) * 
    (1f + conductorLevel * 0.03f)
);

// 日收入
int dailyIncome = dailyPassengers * 35 * 4; // 4趟单程

// 日燃料费
float dailyFuel = 58.5f * 92f / 100f * (1f + (100f - trainCondition) / 200f);
int dailyFuelCost = Mathf.RoundToInt(dailyFuel * 15f);

// 日工资
int dailySalary = 90000 / 30; // 安全优先配置，月薪90k

// 日净收入
int dailyNet = dailyIncome - dailyFuelCost - maintenanceCost - dailySalary;
```

**提给AI的提示词**：
> 重构 Assets/Scripts/GameData.cs。将每日结算逻辑改为基于 跨系统联动公式.md 的公式。初始资金从 GameConfig 读取（普通=40,000）。新增剧情补贴系统（StoryGrant），通过 CompleteStoryGrant(id) 方法注入资金。保留现有的4种策略（调度/人员/维护/服务/外事）但让其影响公式中的系数。
